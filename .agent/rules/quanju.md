# Error Prevention & Resilience (不报错/防错逻辑)
针对当前项目环境，你必须遵循以下防御性编程规则：
- **严禁静默失败**：所有可能失败的模块（如网络请求、npm 脚本执行、文件读写）必须包含完善的 try-except 逻辑，并明确输出错误信息，严禁“不报错但无结果”的情况。
