# 微博热点文章自动生成与发布系统

## 项目概述

本系统实现了一个完整的微博热点文章自动生成与发布流程，包含三个主要模块：

1. **微博热点抓取模块**：从微博平台获取热门话题和相关微博内容，并存储到数据库中
2. **文章自动生成模块**：基于热点话题和微博内容，调用AI模型生成高质量文章
3. **微信公众号上传模块**：将生成的文章自动上传到微信公众号草稿箱

## 系统架构

```
微博热点抓取 → 数据库存储 → 文章自动生成 → 微信公众号上传
```

## 功能特点

- 自动抓取微博热门话题和相关微博内容
- 支持多种AI模型（OpenAI、百度文心一言、本地模型）生成文章
- 可自定义提示词模板，针对不同类型的话题生成不同风格的文章
- 自动将生成的文章上传到微信公众号草稿箱
- 完善的日志记录和错误处理机制
- 灵活的配置系统，可根据需要调整各模块参数

## 安装说明

### 环境要求

- Python 3.8+
- MySQL 5.7+

### 安装步骤

1. 克隆或下载本项目到本地

2. 安装依赖包

```bash
pip install -r requirements.txt
```

3. 配置数据库

- 创建MySQL数据库
- 修改`config.py`中的数据库配置

4. 配置API密钥

- 修改`config.py`中的微博API配置
- 修改`config.py`中的AI模型配置
- 修改`config.py`中的微信公众号配置

## 使用方法

### 启动系统

```bash
python main.py
```

### 自定义提示词模板

在`prompts`目录下创建或修改提示词模板文件，可以针对不同类型的话题设置不同的提示词模板。

默认提示词模板为`prompts/default_prompt.json`，可以参考该文件的格式创建新的模板。

### 查看生成的文章

生成的文章保存在`articles`目录下，以Markdown格式存储。

### 查看日志

系统日志保存在`logs`目录下，可以查看系统运行状态和错误信息。
