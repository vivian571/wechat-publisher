# Open Interpreter 故障排除指南

## 🔍 常见问题和解决方案

### 问题 1：连接错误 (Connection Error)

**错误信息**：
```
litellm.InternalServerError: OpenAIException - Connection error
[WinError 10054] 远程主机强迫关闭了一个现有的连接
```

**原因**：
- 网络代理干扰
- VPN 软件冲突
- 防火墙阻止
- 临时网络波动

**解决方案**：

#### 方案 1：运行诊断脚本（推荐）
```powershell
.\diagnose_api.ps1
```

#### 方案 2：清除代理设置
```powershell
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null
$env:ALL_PROXY = $null
.\start_interpreter.ps1
```

#### 方案 3：使用无代理启动脚本
```powershell
.\start_interpreter_no_proxy.ps1
```

#### 方案 4：关闭 VPN 和代理软件
1. 关闭所有 VPN 软件
2. 关闭代理软件（Clash、V2Ray 等）
3. 重新启动 Open Interpreter

---

### 问题 2：API Key 无效

**错误信息**：
```
Authentication error
Invalid API key
```

**解决方案**：

1. **验证 API Key**：
   - 访问 https://open.bigmodel.cn/
   - 登录账号
   - 检查 API Key 是否正确

2. **更新配置文件**：
   ```powershell
   notepad .\glm4.yaml
   ```
   
   修改 `api_key` 字段：
   ```yaml
   api_key: "your-new-api-key-here"
   ```

3. **检查 API 配额**：
   - 登录智谱 AI 控制台
   - 查看剩余配额
   - 如需充值，访问充值页面

---

### 问题 3：角色特点不明显

**现象**：
- AI 回答太温和
- 没有体现角色特点
- 风格不符合预期

**解决方案**：

1. **增强角色描述**：
   编辑 `glm4.yaml`，在 `custom_instructions` 中添加更多细节

2. **提高温度参数**：
   ```yaml
   temperature: 0.8  # 增加创造性
   ```

3. **在提问时强化角色**：
   ```
   > 呈序，用你的风格审查这段代码
   > 以你的毒舌风格评价这个设计
   ```

4. **切换到其他角色测试**：
   ```powershell
   .\switch_role.ps1
   ```

---

### 问题 4：回答太短或不完整

**现象**：
- 回答被截断
- 代码不完整
- 解释过于简略

**解决方案**：

1. **增加 max_tokens**：
   编辑 `glm4.yaml`：
   ```yaml
   max_tokens: 2000  # 增加到 2000
   ```

2. **在提问时要求详细**：
   ```
   > 详细解释这个概念，包括原理和示例
   > 提供完整的代码实现，包含注释
   ```

3. **分步骤提问**：
   ```
   > 第一步：解释基本概念
   > 第二步：提供代码示例
   > 第三步：说明注意事项
   ```

---

### 问题 5：代码执行失败

**错误信息**：
```
Code execution failed
Permission denied
```

**解决方案**：

1. **检查安全模式**：
   确保 `safe_mode: "ask"` 已设置

2. **审查代码后再运行**：
   - 仔细阅读生成的代码
   - 确认代码安全性
   - 输入 `y` 批准运行

3. **检查权限**：
   - 以管理员身份运行 PowerShell
   - 检查文件/文件夹权限

4. **检查依赖**：
   ```powershell
   pip install -r requirements.txt
   ```

---

### 问题 6：启动失败

**错误信息**：
```
ModuleNotFoundError
ImportError
```

**解决方案**：

1. **激活虚拟环境**：
   ```powershell
   .\venv\Scripts\activate
   ```

2. **重新安装依赖**：
   ```powershell
   pip install --upgrade open-interpreter
   pip install litellm
   ```

3. **检查 Python 版本**：
   ```powershell
   python --version  # 应该是 3.8+
   ```

4. **重新创建虚拟环境**：
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   pip install open-interpreter
   ```

---

### 问题 7：中文乱码

**现象**：
- 输出显示乱码
- 文件保存后乱码

**解决方案**：

1. **设置 PowerShell 编码**：
   ```powershell
   [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
   ```

2. **使用 UTF-8 编码保存文件**：
   - 在编辑器中选择 UTF-8 编码
   - 保存时选择 UTF-8 (无 BOM)

3. **检查系统区域设置**：
   - 控制面板 > 区域 > 管理
   - 更改系统区域设置为中文

## 🔄 完全重置

如果所有方法都失败，尝试完全重置：

```powershell
# 1. 备份配置
Copy-Item .\glm4.yaml -Destination .\glm4.yaml.backup

# 2. 删除虚拟环境
Remove-Item -Recurse -Force .\venv

# 3. 重新创建虚拟环境
python -m venv venv

# 4. 激活虚拟环境
.\venv\Scripts\activate

# 5. 安装依赖
pip install open-interpreter

# 6. 恢复配置
Copy-Item .\glm4.yaml.backup -Destination .\glm4.yaml

# 7. 测试启动
.\start_interpreter.ps1
```
