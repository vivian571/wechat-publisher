# 代理配置指南

## 📋 概述

Open Interpreter 可以在有代理的情况下使用，但需要正确配置。本指南将帮你解决代理相关的问题。

---

## 🔍 问题诊断

### 你的代理软件是什么？

常见的代理软件：
- **Clash** - 默认端口 7890
- **V2Ray / V2RayN** - 默认端口 10809
- **Shadowsocks** - 默认端口 1080
- **其他 VPN 软件**

### 检查代理端口

1. **打开代理软件**
2. **查看设置** - 找到 HTTP 代理端口
3. **记下地址**，通常是：
   - `http://127.0.0.1:3067` (Clash)
   - `http://127.0.0.1:3067` (V2Ray)
   - `http://127.0.0.1:3067` (Shadowsocks)

---

## 🚀 使用方法

### 方法 1：使用代理启动脚本（推荐）

```powershell
.\start_with_proxy.ps1
```

脚本会询问：
1. 是否使用代理？
2. 代理地址是什么？

**示例**：
```
是否使用代理？(y/n): y
请输入代理地址: http://127.0.0.1:3067
```

### 方法 2：直接指定代理

```powershell
.\start_with_proxy.ps1 -ProxyUrl "http://127.0.0.1:3067
```

### 方法 3：不使用代理（直连）

```powershell
.\start_no_proxy.ps1
```

或者在 `start_with_proxy.ps1` 中选择 `n`（不使用代理）

## ⚙️ 代理配置详解

### Clash 配置

**默认设置**：
- HTTP 代理：`http://127.0.0.1:7890`
- SOCKS5 代理：`socks5://127.0.0.1:7891`

**使用方法**：
```powershell
.\start_with_proxy.ps1 -ProxyUrl "http://127.0.0.1:7890"
```

**注意事项**：
- 确保 Clash 正在运行
- 确保 "系统代理" 已开启
- 检查代理规则是否允许访问 `open.bigmodel.cn`

### V2Ray 配置

**默认设置**：
- HTTP 代理：`http://127.0.0.1:10809`
- SOCKS5 代理：`socks5://127.0.0.1:10808`

**使用方法**：
```powershell
.\start_with_proxy.ps1 -ProxyUrl "http://127.0.0.1:10809"
```

### Shadowsocks 配置

**默认设置**：
- SOCKS5 代理：`socks5://127.0.0.1:1080`

**注意**：Shadowsocks 默认只提供 SOCKS5，需要配合 Privoxy 等工具转换为 HTTP 代理。

## 🔧 常见问题

### 问题 1：连接被重置 (10054 错误)

**原因**：
- 代理软件未运行
- 代理端口错误
- 代理规则阻止了连接

**解决方案**：

1. **检查代理软件是否运行**：
   ```powershell
   # 检查端口是否监听
   netstat -ano | findstr "7890"
   ```

2. **验证代理地址**：
   ```powershell
   # 测试代理
   curl -x http://127.0.0.1:7890 https://open.bigmodel.cn
   ```

3. **检查代理规则**：
   - 在 Clash 中，确保 `open.bigmodel.cn` 走代理
   - 或者添加规则：`DOMAIN-SUFFIX,bigmodel.cn,PROXY`

### 问题 2：代理工作但 API 调用失败

**原因**：
- 代理配置正确，但 API 本身有问题
- API Key 无效
- 网络限制

**解决方案**：

1. **测试 API 直接访问**：
   ```powershell
   .\diagnose_api.ps1
   ```

2. **尝试不使用代理**：
   ```powershell
   .\start_no_proxy.ps1
   ```

3. **检查 API Key**：
   - 登录 https://open.bigmodel.cn/
   - 验证 API Key 是否有效

### 问题 3：有时能连接，有时不能

**原因**：
- 代理不稳定
- 网络波动
- 代理规则切换

**解决方案**：

1. **使用稳定的代理节点**
2. **固定代理规则**：
   - 在 Clash 中设置 `open.bigmodel.cn` 为固定规则
3. **增加重试机制**（已内置在脚本中）

## 📊 代理 vs 直连对比

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **使用代理** | 可以访问被限制的服务 | 可能不稳定，速度慢 | 公司网络、特殊网络环境 |
| **直连** | 速度快，稳定 | 某些网络可能无法访问 | 家庭网络、正常网络环境 |

---

## 💡 最佳实践

### 1. 优先尝试直连

```powershell
.\start_no_proxy.ps1
```

如果直连成功，就不需要代理。

### 2. 需要代理时使用智能脚本

```powershell
.\start_with_proxy.ps1
```

脚本会自动测试代理连接。

### 3. 固定代理配置

如果你总是使用同一个代理，可以创建快捷脚本：

```powershell
# my_start.ps1
.\start_with_proxy.ps1 -ProxyUrl "http://127.0.0.1:7890"
```

### 4. 代理规则优化

在 Clash 配置中添加：

```yaml
rules:
  - DOMAIN-SUFFIX,bigmodel.cn,PROXY
  - DOMAIN-SUFFIX,openai.com,PROXY
```

## 🔄 切换代理和直连

### 快速切换脚本

创建 `switch_connection.ps1`：

```powershell
param([string]$Mode = "ask")

switch ($Mode) {
    "proxy" {
        .\start_with_proxy.ps1 -ProxyUrl "http://127.0.0.1:7890"
    }
    "direct" {
        .\start_no_proxy.ps1
    }
    default {
        Write-Host "选择连接方式:" -ForegroundColor Green
        Write-Host "  1. 使用代理" -ForegroundColor White
        Write-Host "  2. 直连" -ForegroundColor White
        $choice = Read-Host "请选择 (1/2)"
        
        if ($choice -eq "1") {
            .\start_with_proxy.ps1
        } else {
            .\start_no_proxy.ps1
        }
    }
}
```

使用方法：
```powershell
.\switch_connection.ps1          # 交互式选择
.\switch_connection.ps1 proxy    # 直接使用代理
.\switch_connection.ps1 direct   # 直接直连
```

## 🛠️ 高级配置

### 环境变量配置

如果你想永久配置代理：

```powershell
# 设置用户级别环境变量
[System.Environment]::SetEnvironmentVariable("HTTP_PROXY", "http://127.0.0.1:7890", "User")
[System.Environment]::SetEnvironmentVariable("HTTPS_PROXY", "http://127.0.0.1:7890", "User")
```

**注意**：这会影响所有使用这些环境变量的程序。

### 代理认证

如果代理需要认证：

```powershell
$ProxyUrl = "http://username:password@127.0.0.1:7890"
.\start_with_proxy.ps1 -ProxyUrl $ProxyUrl
```

### SOCKS5 代理

如果只有 SOCKS5 代理，需要转换工具：

1. **安装 Privoxy**：
   ```powershell
   choco install privoxy
   ```

2. **配置 Privoxy** 转发到 SOCKS5
3. **使用 Privoxy 的 HTTP 端口**

## 🆘 仍然无法解决？

### 1. 运行完整诊断

```powershell
.\diagnose_api.ps1
```

### 2. 查看详细错误

Open Interpreter 的错误信息通常很详细，仔细阅读错误堆栈。

### 3. 尝试不同方式

```powershell
# 方式 1: 直连
.\start_no_proxy.ps1

# 方式 2: 使用代理
.\start_with_proxy.ps1

# 方式 3: 手动配置
$env:HTTP_PROXY = "http://127.0.0.1:7890"
.\start_interpreter.ps1
```

### 4. 检查防火墙

确保防火墙允许：
- Python 访问网络
- 访问 `open.bigmodel.cn`
