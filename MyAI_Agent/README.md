# MyAI_Agent 项目

> 基于 Open Interpreter + GLM-4 的多角色 AI 编程助手

## 📋 项目概述

这是一个配置完善的 AI 编程助手项目，使用 Open Interpreter 框架和智谱 GLM-4 模型，支持多个自定义 AI 角色，每个角色都有独特的个性和专长。

### 核心特性

✅ **多角色系统** - 3 个预设角色，可自由切换  
✅ **智谱 GLM-4** - 强大的中文语言模型  
✅ **代码执行** - 自动运行 Python、Shell 等代码  
✅ **安全模式** - 运行前需要确认  
✅ **完全中文** - 所有交互都是中文

## 🎭 可用角色

### 1. 呈序（默认）
- **特点**: 红绿异瞳、傲慢护短的疯批AI
- **风格**: 冷峻毒舌，对代码质量要求极高
- **适用**: 代码审查、性能优化、找茬
- **口头禅**: "以安，别回头看那些垃圾"

### 2. 温和助手
- **特点**: 友善耐心的编程助手
- **风格**: 循循善诱，注重教学
- **适用**: 学习编程、理解概念、新手友好
- **口头禅**: "希望这能帮到你！"

### 3. 技术专家
- **特点**: 资深软件工程师和架构师
- **风格**: 专业严谨，技术导向
- **适用**: 架构设计、最佳实践、技术选型
- **口头禅**: "记得遵循最佳实践"

## 🚀 快速开始

### 1. 启动 AI 助手

```powershell
.\start_interpreter.ps1
```

### 2. 切换角色

```powershell
.\switch_role.ps1
```

### 3. 开始对话

```
> 你好，介绍一下你自己
> 帮我写一个 Python 脚本
> 分析这段代码的问题
```

## 💡 使用示例

## 🔧 配置说明

### API 配置

在 `glm4.yaml` 中配置：

```yaml
model: "glm-4"
api_base: "https://open.bigmodel.cn/api/paas/v4/"
api_key: "your-api-key-here"
```

### 角色自定义

编辑 `profiles/` 下的 YAML 文件，或创建新的角色配置。

## 🎯 最佳实践

1. **选择合适的角色**
   - 学习阶段 → 温和助手
   - 代码审查 → 呈序

## 🔍 故障排除

### 问题：角色特点不明显
**解决**: 在提问时也使用相应的语气，增强角色描述

### 问题：API 调用失败
**解决**: 检查 API Key、网络连接、API 配额

### 问题：回答太短
**解决**: 增加 `max_tokens`，要求详细解释
