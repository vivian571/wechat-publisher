## 🎯 ShareX 功能介绍

ShareX 是一款功能强大的免费开源截图和录屏工具。

### 主要功能

1. **截图功能**
   - 全屏截图
   - 窗口截图
   - 区域截图
   - 滚动截图

2. **录屏功能**
   - 屏幕录制（视频）
   - GIF 录制
   - 自定义录制区域
   - 支持音频录制

3. **编辑功能**
   - 图片编辑器
   - 添加文字、箭头、标注
   - 模糊、高亮等效果

4. **分享功能**
   - 自动上传到云端
   - 支持多种图床
   - 生成分享链接

## ⌨️ 常用快捷键

安装完成后，ShareX 的默认快捷键：

### 截图快捷键
- `Print Screen` - 全屏截图
- `Ctrl + Print Screen` - 窗口截图
- `Alt + Print Screen` - 区域截图
- `Shift + Print Screen` - 自定义区域截图

### 录屏快捷键
- `Shift + Ctrl + Print Screen` - 开始/停止屏幕录制
- `Ctrl + Shift + G` - 开始/停止 GIF 录制

### 其他快捷键
- `Ctrl + Shift + U` - 打开上传历史
- `Ctrl + Shift + S` - 打开 ShareX 主窗口

**注意**：你可以在 ShareX 设置中自定义所有快捷键。

## 🚀 快速开始

### 1. 首次启动

安装完成后：
1. 在开始菜单搜索 "ShareX"
2. 首次运行会显示欢迎界面
3. 建议先浏览一下设置选项

### 2. 录制屏幕

**方法 1：使用快捷键**
1. 按 `Shift + Ctrl + Print Screen` 开始录制
2. 选择录制区域（或按 Enter 录制全屏）
3. 再次按 `Shift + Ctrl + Print Screen` 停止录制
4. 视频会自动保存

**方法 2：使用主界面**
1. 打开 ShareX 主窗口
2. 点击左侧 "捕获" > "屏幕录制"
3. 选择录制区域
4. 点击停止按钮结束录制

### 3. 录制 GIF

1. 按 `Ctrl + Shift + G` 开始 GIF 录制
2. 选择录制区域
3. 再次按快捷键停止
4. GIF 会自动生成并保存

### 4. 查看录制文件

**默认保存位置**：
```
C:\Users\你的用户名\Documents\ShareX\Screenshots\
```

**快速访问**：
- 右键点击系统托盘的 ShareX 图标
- 选择 "打开" > "截图文件夹"

## ⚙️ 推荐设置

### 1. 设置录屏质量

1. 打开 ShareX 主窗口
2. 点击 "任务设置" > "屏幕录制器"
3. 选择录制器：
   - **FFmpeg** - 高质量，推荐
   - **GIF** - 适合制作动图

4. 调整视频设置：
   - 编码器：x264
   - 质量：High
   - 帧率：30 FPS

### 2. 设置保存位置

1. 打开 "应用程序设置"
2. 点击 "路径" 标签
3. 自定义截图和录屏保存位置

### 3. 自定义快捷键

1. 打开 "热键设置"
2. 找到你想修改的功能
3. 双击快捷键列
4. 按下新的快捷键组合

## 💡 实用技巧

### 技巧 1：录制指定窗口

1. 按 `Shift + Ctrl + Print Screen`
2. 在弹出的菜单中选择 "窗口录制"
3. 点击要录制的窗口

### 技巧 2：添加水印

1. 打开 "任务设置" > "图像" > "水印"
2. 启用水印功能
3. 自定义水印文字或图片

### 技巧 3：自动上传

1. 打开 "目标设置"
2. 选择上传服务（如 Imgur、Google Drive 等）
3. 配置账号信息
4. 截图/录屏后自动上传并复制链接

### 技巧 4：OCR 文字识别

1. 截图后
2. 右键点击图片
3. 选择 "OCR" 识别图片中的文字

## 🔧 常见问题

### Q1: 录屏没有声音？
**解决方案**：
1. 打开 "任务设置" > "屏幕录制器"
2. 检查 "音频源" 设置
3. 选择正确的音频设备

### Q2: 快捷键不工作？
**解决方案**：
1. 检查是否有其他软件占用了快捷键
2. 在 ShareX 设置中重新分配快捷键
3. 确保 ShareX 在后台运行

### Q3: 录制的视频文件太大？
**解决方案**：
1. 降低录制帧率（如改为 24 FPS）
2. 调整视频质量设置
3. 使用更高效的编码器

### Q4: 如何录制鼠标点击效果？
**解决方案**：
1. 打开 "任务设置" > "屏幕录制器"
2. 启用 "显示鼠标点击"
3. 自定义点击效果样式
