# Open Interpreter 快速参考

## 🚀 快速启动

### 启动默认角色（呈序）
```powershell
.\start_interpreter.ps1
```

### 切换角色
```powershell
.\switch_role.ps1
```

## 🔧 配置说明

### 基础配置

```yaml
model: "glm-4"                    # 模型
api_key: "your-api-key"           # API 密钥
context_window: 128000            # 上下文窗口
max_tokens: 1000                  # 最大输出
temperature: 0.7                  # 温度（0-1）
safe_mode: "ask"                  # 安全模式
```

### 角色设定

```yaml
custom_instructions: >
  身份：[角色特征]
  核心逻辑：[行为准则]
  沟通风格：[语言风格]
  执行：[执行特点]
  结束语：[标志性结束语]
```

## 📊 参数调整

### Temperature（温度）

- **0.0-0.3**: 更确定、一致的回答
- **0.4-0.7**: 平衡创造性和准确性（推荐）
- **0.8-1.0**: 更有创造性、多样化

### Max Tokens

- **500-1000**: 简短回答
- **1000-2000**: 中等长度（推荐）
- **2000+**: 详细解释

### Safe Mode

- **off**: 自动运行所有代码（危险）
- **ask**: 运行前询问（推荐）
- **auto**: 自动运行安全代码

## 🔍 故障排除

### 问题 1：角色不明显

**解决方案**：
1. 增强 `custom_instructions` 描述
2. 在提问时也使用相应语气
3. 提高 `temperature` 参数

### 问题 2：API 调用失败

**解决方案**：
1. 检查 API Key 是否正确
2. 验证网络连接
3. 查看 API 配额

### 问题 3：回答太短

**解决方案**：
1. 增加 `max_tokens`
2. 在提问时要求详细解释
3. 使用 `%verbose` 模式

### 问题 4：切换角色失败

**解决方案**：
1. 检查 profiles 文件夹是否存在
2. 验证角色配置文件完整性
3. 重启 Open Interpreter
