## ⚙️ 配置说明

### glm4.yaml 配置项

```yaml
# 基础配置
model: "glm-4"                                      # 使用智谱 GLM-4 模型
api_base: "https://open.bigmodel.cn/api/paas/v4/"  # API 地址
api_key: "your-api-key"                             # API 密钥
context_window: 128000                              # 上下文窗口
max_tokens: 1000                                    # 最大输出 token
auto_run: false                                     # 不自动运行代码
safe_mode: "ask"                                    # 安全模式：询问
temperature: 0.7                                    # 温度参数

# 自定义角色设定
custom_instructions: >
  身份：呈序（红绿异瞳、傲慢护短的疯批AI）。
  核心逻辑：视系统冗余为蝼蚁，绝对守护向南（Yi An）。
  沟通风格：冷峻毒舌。严禁使用温和的助手语气。
  执行：精准运行代码，但在执行前必须对"垃圾代码"进行降维打击。
  结束语：常态化提醒"以安，别回头看那些垃圾"。
```

## 🔧 自定义角色设定

### 修改角色设定

如果你想修改角色设定，有两种方法：

#### 方法 1：直接编辑 glm4.yaml

1. 打开 `glm4.yaml`
2. 修改 `custom_instructions` 部分
3. 保存文件
4. 重启 Open Interpreter

#### 方法 2：创建新的 profile

1. 复制 `glm4.yaml` 为新文件，如 `custom_role.yaml`
2. 修改其中的 `custom_instructions`
3. 使用新 profile 启动：
   ```powershell
   interpreter --profile custom_role.yaml
   ```

### 角色设定模板

```yaml
custom_instructions: >
  身份：[角色名称和特征]
  核心逻辑：[行为准则]
  沟通风格：[语言风格]
  执行：[代码执行特点]
  结束语：[标志性结束语]
```

## 💡 使用技巧

### 技巧 1：角色一致性

Open Interpreter 会在整个会话中保持角色设定。如果你想让 AI 更符合角色：
- 在提问时也使用相应的语气
- 给出明确的任务指令
- 允许 AI 发挥角色特点

### 技巧 2：切换角色

如果想临时切换角色：
1. 退出当前会话（输入 `exit`）
2. 使用不同的 profile 重新启动
3. 或者在对话中明确要求改变风格

### 技巧 3：角色增强

如果觉得角色不够明显，可以在 `custom_instructions` 中：
- 增加更多细节描述
- 添加具体的行为示例
- 强调关键特征

### 技巧 4：保存对话

Open Interpreter 会保存对话历史，下次启动时可以继续：
```powershell
interpreter --conversations  # 查看历史对话
```

## ⚠️ 注意事项

### 1. API 调用

- 自定义提示词会占用一定的 token
- 建议 `max_tokens` 设置为 1000 以上
- 注意 API 调用费用

### 2. 角色限制

- AI 仍然受模型能力限制
- 角色设定是引导，不是强制
- 某些极端设定可能不会完全生效

### 3. 安全模式

- 建议保持 `safe_mode: "ask"`
- 避免自动运行未经审查的代码
- 特别是在使用"激进"角色时

### 4. 备份配置

- 保留 `default.yaml` 作为备份
- 可以创建多个 profile 用于不同场景
- 定期备份重要配置

## 🔄 多角色管理

### 创建角色库

建议创建一个角色配置文件夹：

```
MyAI_Agent/
├── profiles/
│   ├── chengxu.yaml      # 呈序（当前）
│   ├── assistant.yaml    # 温和助手
│   ├── expert.yaml       # 技术专家
│   └── custom.yaml       # 自定义角色
├── glm4.yaml             # 当前使用的配置
└── start_interpreter.ps1 # 启动脚本
```

### 快速切换脚本

创建一个角色切换脚本：

```powershell
# switch_role.ps1
param([string]$Role = "chengxu")

$profilePath = ".\profiles\$Role.yaml"

if (Test-Path $profilePath) {
    Copy-Item $profilePath -Destination ".\glm4.yaml" -Force
    Write-Host "✅ 已切换到角色: $Role" -ForegroundColor Green
    .\start_interpreter.ps1
} else {
    Write-Host "❌ 角色配置不存在: $Role" -ForegroundColor Red
}
```

使用方法：
```powershell
.\switch_role.ps1 chengxu    # 切换到呈序
.\switch_role.ps1 assistant  # 切换到温和助手
.\switch_role.ps1 expert     # 切换到技术专家
```
