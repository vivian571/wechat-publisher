## 🎯 项目简介

**OmniPublish** 是一个全平台内容发布自动化系统,帮助技术创作者实现"一次编写,到处发布"。

### 核心特性

✅ **一键多平台发布**: 支持 Dev.to、Hashnode、Medium、掘金、微信公众号等  
✅ **智能图片处理**: 自动上传图床,解决外链图片问题  
✅ **SEO 优化**: 自动注入 canonical URL,避免重复内容惩罚  
✅ **CI/CD 集成**: Git Push 自动触发发布  
✅ **状态追踪**: 记录每篇文章在各平台的发布状态

## 🚀 5 分钟快速开始

### 步骤 1: 准备 API 凭证

#### 国际平台

| 平台 | 获取方式 | 文档链接 |
|------|---------|---------|
| **Dev.to** | Settings → Extensions → Generate API Key | [链接](https://dev.to/settings/extensions) |
| **Hashnode** | Developer Settings → Personal Access Tokens | [链接](https://hashnode.com/settings/developer) |
| **Medium** | Settings → Integration tokens | [链接](https://medium.com/me/settings) |

#### 国内平台

| 平台 | 获取方式 |
|------|---------|
| **掘金** | 登录后,F12 → Network → 复制 Cookie |
| **微信公众号** | 公众平台 → 开发 → 基本配置 → AppID & AppSecret |

### 步骤 2: 配置图床

**推荐**: Cloudflare R2 (免费额度大,无出站费用)

1. 访问 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. 创建 R2 存储桶
3. 生成 API Token
4. 配置自定义域名 (可选)


## 🔧 配置 GitHub Actions

### 步骤 1: 创建工作流文件

```bash
mkdir -p .github/workflows
```

复制以下内容到 `.github/workflows/publish.yml`:

```yaml
name: OmniPublish Auto Publish

on:
  push:
    branches: [main]
    paths:
      - 'articles/**/*.md'
  workflow_dispatch:

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: |
          pip install -r requirements.txt
          playwright install chromium
      - run: python main.py --mode auto
        env:
          DEVTO_API_KEY: ${{ secrets.DEVTO_API_KEY }}
          HASHNODE_TOKEN: ${{ secrets.HASHNODE_TOKEN }}
          # ... 其他环境变量
```

### 步骤 2: 配置 Secrets

1. 进入仓库 **Settings** → **Secrets and variables** → **Actions**
2. 点击 **New repository secret**
3. 添加以下 Secrets:
   - `DEVTO_API_KEY`
   - `HASHNODE_TOKEN`
   - `MEDIUM_TOKEN`
   - `JUEJIN_COOKIE`
   - `WECHAT_APPID`
   - `WECHAT_SECRET`
   - `R2_ACCOUNT_ID`
   - `R2_ACCESS_KEY`
   - `R2_SECRET_KEY`

## 🐛 常见问题

### Q1: 图片上传失败怎么办?

**A**: 检查图床配置是否正确:

```bash
# 测试 R2 连接
python -c "
from utils.r2_client import CloudflareR2Client
import os

client = CloudflareR2Client(
    account_id=os.getenv('R2_ACCOUNT_ID'),
    access_key=os.getenv('R2_ACCESS_KEY'),
    secret_key=os.getenv('R2_SECRET_KEY'),
    bucket=os.getenv('R2_BUCKET_NAME')
)

print('✅ R2 连接成功')
"
```

### Q2: 掘金发布失败 (403 错误)?

**A**: Cookie 已过期,需要更新:

```bash
# 1. 登录掘金 (https://juejin.cn)
# 2. F12 → Network → 刷新页面
# 3. 找到任意请求,复制 Cookie 请求头
# 4. 更新 .env 文件:
#    JUEJIN_COOKIE="sessionid=xxx; sessionid_ss=xxx"
```

### Q3: 微信公众号图片显示失败?

**A**: 微信不支持外链图片,必须上传到微信素材库:

```python
# 检查微信适配器是否正确上传图片
# 查看日志: .omnipublish/logs/publish_*.log
```

### Q4: GitHub Actions 执行超时?

**A**: 优化工作流配置:

```yaml
# 增加超时时间
jobs:
  publish:
    timeout-minutes: 30  # 默认 360 分钟
```
