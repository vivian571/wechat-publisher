## 环境准备

### 系统要求

| 组件 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **操作系统** | Linux / macOS / Windows | Ubuntu 22.04 LTS |
| **Python** | 3.10+ | 3.11+ |
| **内存** | 1 GB | 2 GB |
| **磁盘** | 500 MB | 2 GB |
| **网络** | 稳定互联网连接 | 10 Mbps+ |

### 依赖安装

#### 1. Python 环境
```bash
# 检查 Python 版本
python --version  # 应显示 3.10 或更高

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate
```

#### 2. 安装依赖包
```bash
# 安装核心依赖
pip install -r requirements.txt

# 安装 Playwright 浏览器
playwright install chromium
```

#### 3. 验证安装
```bash
# 运行测试脚本
python -c "import httpx, frontmatter, playwright; print('✅ 所有依赖安装成功')"
```

## 本地部署

### 1. 克隆项目
```bash
git clone https://github.com/yourname/omnipublish.git
cd omnipublish
```

### 2. 配置环境变量
```bash
# 复制示例配置文件
cp .env.example .env

# 编辑配置文件
nano .env
```

**.env 文件示例**:
```bash

HASHNODE_TOKEN=your_hashnode_token
HASHNODE_PUBLICATION_ID=your_publication_id
MEDIUM_TOKEN=your_medium_token
```

## CI/CD 部署

### GitHub Actions 配置

#### 1. 创建工作流文件
```yaml
# .github/workflows/publish.yml

name: OmniPublish Auto Publish

on:
  push:
    branches: [main]
    paths:
      - 'articles/**/*.md'
  workflow_dispatch:
    inputs:
      article_path:
        description: '指定要发布的文章路径'
        required: false

jobs:
  publish:
    runs-on: ubuntu-latest
    
    steps:
      - name: 📥 Checkout 代码
        uses: actions/checkout@v4
        with:
          fetch-depth: 2  # 获取最近 2 次提交,用于检测新增文章
      
      - name: 🐍 设置 Python 环境
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
          cache: 'pip'
      
      - name: 📦 安装依赖
        run: |
          pip install -r requirements.txt
          playwright install --with-deps chromium
      
      - name: 🚀 发布文章
        env:
          DEVTO_API_KEY: ${{ secrets.DEVTO_API_KEY }}
          HASHNODE_TOKEN: ${{ secrets.HASHNODE_TOKEN }}
          HASHNODE_PUBLICATION_ID: ${{ secrets.HASHNODE_PUBLICATION_ID }}
          MEDIUM_TOKEN: ${{ secrets.MEDIUM_TOKEN }}
          JUEJIN_COOKIE: ${{ secrets.JUEJIN_COOKIE }}
          WECHAT_APPID: ${{ secrets.WECHAT_APPID }}
          WECHAT_SECRET: ${{ secrets.WECHAT_SECRET }}
          R2_ACCOUNT_ID: ${{ secrets.R2_ACCOUNT_ID }}
          R2_ACCESS_KEY: ${{ secrets.R2_ACCESS_KEY }}
          R2_SECRET_KEY: ${{ secrets.R2_SECRET_KEY }}
          R2_BUCKET_NAME: ${{ secrets.R2_BUCKET_NAME }}
          R2_PUBLIC_URL: ${{ secrets.R2_PUBLIC_URL }}
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
          CANONICAL_BASE_URL: ${{ secrets.CANONICAL_BASE_URL }}
        run: |
          if [ -n "${{ github.event.inputs.article_path }}" ]; then
            python main.py --file "${{ github.event.inputs.article_path }}"
          else
            python main.py --mode auto
          fi
      
      - name: 📊 上传发布报告
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: publish-report-${{ github.run_number }}
          path: .omnipublish/report.json
          retention-days: 30
      
      - name: 📢 发送 Telegram 通知
        if: failure()
        uses: appleboy/telegram-action@master
        with:
          to: ${{ secrets.TELEGRAM_CHAT_ID }}
          token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          message: |
            ❌ OmniPublish 发布失败
            
            仓库: ${{ github.repository }}
            分支: ${{ github.ref_name }}
            提交: ${{ github.sha }}
            作者: ${{ github.actor }}
            
            查看详情: ${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}
```

#### 2. 配置 GitHub Secrets

进入仓库设置: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

添加以下 Secrets:
- `DEVTO_API_KEY`
- `HASHNODE_TOKEN`
- `HASHNODE_PUBLICATION_ID`
- `MEDIUM_TOKEN`
- `JUEJIN_COOKIE`
- `WECHAT_APPID`
- `WECHAT_SECRET`
- `R2_ACCOUNT_ID`
- `R2_ACCESS_KEY`
- `R2_SECRET_KEY`
- `R2_BUCKET_NAME`
- `R2_PUBLIC_URL`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `CANONICAL_BASE_URL`

#### 3. 触发发布

**自动触发**:
```bash
# 创建新文章
echo "---
title: 测试文章
tags: [test]
---
# 内容
" > articles/test.md

# 提交并推送
git add articles/test.md
git commit -m "新增文章: 测试文章"
git push origin main
```

**手动触发**:
1. 进入 **Actions** 标签页
2. 选择 **OmniPublish Auto Publish** 工作流
3. 点击 **Run workflow**
4. (可选) 输入文章路径
5. 点击 **Run workflow** 确认

## 配置管理

### config.yaml 结构

```yaml
# 全局配置
global:
  canonical_base_url: "https://myblog.com"
  retry_times: 3
  retry_delay: 5
  log_level: "INFO"
  
  # 国内平台随机延时范围 (秒)

# 图床配置
image_storage:
  provider: "cloudflare_r2"
  
  cloudflare_r2:
    account_id: "${R2_ACCOUNT_ID}"
    access_key_id: "${R2_ACCESS_KEY}"
    secret_access_key: "${R2_SECRET_KEY}"
    bucket_name: "${R2_BUCKET_NAME}"
    public_url: "${R2_PUBLIC_URL}"
  
  # 备用图床 (可选)
  aliyun_oss:
    enabled: false
    endpoint: "oss-cn-hangzhou.aliyuncs.com"
    access_key_id: "${OSS_ACCESS_KEY}"
    access_key_secret: "${OSS_SECRET_KEY}"
    bucket_name: "omnipublish"

# 平台配置
platforms:
  # 国际平台
  devto:
    enabled: true
    api_key: "${DEVTO_API_KEY}"
    priority: 1
  
  hashnode:
    enabled: true
    access_token: "${HASHNODE_TOKEN}"
    publication_id: "${HASHNODE_PUBLICATION_ID}"
    priority: 2
  
  medium:
    enabled: false
    integration_token: "${MEDIUM_TOKEN}"
    priority: 3
  
  # 国内平台
  juejin:
    enabled: true
    cookie: "${JUEJIN_COOKIE}"
    priority: 4
  
  wechat:
    enabled: true
    appid: "${WECHAT_APPID}"
    secret: "${WECHAT_SECRET}"
    priority: 5
  
  csdn:
    enabled: false
    cookie: "${CSDN_COOKIE}"
    priority: 6

# 通知配置
notifications:
  telegram:
    enabled: true

    chat_id: "${TELEGRAM_CHAT_ID}"
  
  email:

    username: "${EMAIL_USERNAME}"
    password: "${EMAIL_PASSWORD}"
    to_address: "your@email.com"
```

### 配置加载

```python
# utils/config_loader.py

import yaml
import os
from pathlib import Path

class ConfigLoader:
    """配置加载器"""
    
    def __init__(self, config_path: str = "config.yaml"):
        self.config_path = Path(config_path)
        self.config = self._load_config()
    
    def _load_config(self) -> dict:
        """加载配置文件"""
        with open(self.config_path, 'r', encoding='utf-8') as f:
            config = yaml.safe_load(f)
        
        # 替换环境变量
        return self._replace_env_vars(config)
    
    def _replace_env_vars(self, obj):
        """递归替换环境变量"""
        if isinstance(obj, dict):
            return {k: self._replace_env_vars(v) for k, v in obj.items()}
        elif isinstance(obj, list):
            return [self._replace_env_vars(item) for item in obj]
        elif isinstance(obj, str) and obj.startswith('${') and obj.endswith('}'):
            env_var = obj[2:-1]
            return os.getenv(env_var, '')
        else:
            return obj
    
    def get(self, key_path: str, default=None):
        """获取配置值 (支持点号路径)"""
        keys = key_path.split('.')
        value = self.config
        
        for key in keys:
            if isinstance(value, dict) and key in value:
                value = value[key]
            else:
                return default
        
        return value
```

## 故障排查

### 常见问题

#### 1. API Key 无效

**症状**:
```
❌ Dev.to: HTTP 401: Unauthorized
```

**解决方案**:
```bash
# 检查环境变量
echo $DEVTO_API_KEY

# 重新生成 API Key
# 访问: https://dev.to/settings/extensions
```

#### 2. 图片上传失败

**症状**:
```
❌ 上传图片失败: Connection timeout
```

**解决方案**:
```bash
# 检查网络连接
curl -I https://assets.yourdomain.com

# 检查 R2 配置
python -c "from utils.r2_client import CloudflareR2Client; client = CloudflareR2Client(...); print('✅ R2 连接成功')"
```

#### 3. Cookie 过期

**症状**:
```
❌ 掘金: HTTP 403: Forbidden
```

**解决方案**:
```bash
# 1. 打开浏览器,登录掘金
# 2. 打开开发者工具 (F12)
# 3. 切换到 Network 标签页
# 4. 刷新页面
# 5. 找到任意请求,复制 Cookie 请求头
# 6. 更新 .env 文件中的 JUEJIN_COOKIE
```

#### 4. Playwright 浏览器未安装

**症状**:
```
playwright._impl._api_types.Error: Executable doesn't exist
```

**解决方案**:
```bash
# 安装浏览器
playwright install chromium

# 或安装所有浏览器
playwright install
```
