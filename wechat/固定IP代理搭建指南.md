# 固定 IP 代理服务搭建指南

如果你厌倦了每次网络变动都要去微信公众平台修改 IP 白名单，最根本的解决方法是使用一个**固定出口 IP**。

本指南提供三种方案，推荐方案一（最稳定、性价比最高）。

---

## 方案一：购买云服务器搭建（推荐）

这是最专业、最稳定的方案。你购买一台拥有固定公网 IP 的云服务器（VPS），并在上面运行一个简单的代理程序。

### 1. 购买云服务器

你可以选择国内或国外的云服务商。因为微信 API 在国内访问更快，且不涉及翻墙，**推荐购买国内大厂的“轻量应用服务器”**，价格通常在 20-50 元/月。

*   **腾讯云**：[轻量应用服务器 (Lighthouse)](https://cloud.tencent.com/product/lighthouse)
*   **阿里云**：[轻量应用服务器 (SAS)](https://www.aliyun.com/product/swas)
*   **华为云**：[云耀云服务器 (HECS)](https://www.huaweicloud.com/product/hecs.html)

**购买建议：**
*   **地域**：选择离你近的（如上海、北京、广州）。
*   **镜像**：选择 **Ubuntu 20.04/22.04** 或 **Debian 10/11**（本教程基于此）。
*   **配置**：最低配置即可（1核 1G 内存），带宽 3M 以上足矣。

### 2. 一键搭建代理服务

购买并登录服务器后（使用 SSH 工具或网页控制台），运行我为你准备的脚本：

1.  **上传脚本**：
    将项目中的 `wechat/setup_proxy_server.sh` 文件上传到服务器，或者直接在服务器上创建该文件：
    ```bash
    nano setup_proxy_server.sh
    # 将 setup_proxy_server.sh 的内容复制进去，按 Ctrl+O 保存，Ctrl+X 退出
    ```

2.  **运行脚本**：
    ```bash
    sudo bash setup_proxy_server.sh
    ```

3.  **按提示操作**：
    *   输入用户名（例如：`wechat`）
    *   输入密码（建议复杂一点，防止被扫爆）
    *   输入端口（默认 `3128`，记得在云服务商的防火墙/安全组放行此端口）

### 3. 获取配置

脚本运行成功后，会显示类似如下信息：

```
=== 代理搭建成功！ ===
请在您的本地电脑修改 .env 文件：

WECHAT_PROXY_URL=http://wechat:your_password@123.45.67.89:3128
```

### 4. 本地配置

回到你的本地电脑（运行 `wechat_publisher.py` 的地方）：

1.  打开 `.env` 文件。
2.  添加或修改 `WECHAT_PROXY_URL`：
    ```bash
    WECHAT_PROXY_URL=http://wechat:your_password@123.45.67.89:3128
    ```
3.  登录微信公众平台 -> 设置与开发 -> 基本配置 -> IP白名单，将 `123.45.67.89` 添加进去。

## 方案二：购买现成的代理 IP 服务

如果你不想维护服务器，可以购买第三方的代理 IP 服务。但要注意：

*   **必须购买“独享固定 IP”**：普通的动态代理 IP 会变，无法解决白名单问题。
*   **必须支持长效静态**：IP 不能几天就变一次。
*   **成本较高**：高质量的独享静态 IP 价格通常比一台入门级 VPS 还要贵。

**推荐服务商：**
*   **青果网络**、**芝麻代理**、**品易** 等国内代理商提供的“独享静态代理”。
*   购买后，你会直接获得一个代理地址（如 `http://ip:port`），直接填入 `.env` 即可。

---

## 方案三：使用家里的宽带（不推荐）

如果你的家庭宽带恰好有公网 IP（现在很少见），你可以：
1.  在路由器上设置端口映射。
2.  在电脑上运行代理软件（如 CCProxy）。
3.  但这依然无法解决 ISP 定期更换 IP 的问题，除非你配合 DDNS（动态域名），但微信白名单只支持 IP，不支持域名，所以此方案**不可行**。

---

## 总结

最省心、一劳永逸的方法是 **方案一**。
花 30 元买一台腾讯云轻量服务器，不仅可以做代理解决微信白名单问题，还可以用来挂载脚本、搭建个人博客等，物超所值。
