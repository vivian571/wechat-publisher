### 原因分析
1. **代理不稳定**：端口 3067 的代理连接被重置
2. **Unsplash API 调用失败**：无法通过代理访问
3. **Pexels API 也失败**：备用方案也无法工作

### 解决方案

#### 方案 1：使用直连（推荐）

如果你的网络可以直接访问 Unsplash/Pexels：

```powershell
# 清除代理
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null

# 重启程序
python wechat_publisher.py
```

#### 方案 2：使用稳定的代理

切换到 Clash 的标准端口：

```powershell
# 设置 Clash 代理
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"

# 重启程序
python wechat_publisher.py
```
