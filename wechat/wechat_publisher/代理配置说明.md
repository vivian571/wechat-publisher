# WeChat Publisher 代理配置说明

## 问题背景

`wechat_publisher.py` 在下载图片时遇到代理连接错误：
```
ProxyError('Unable to connect to proxy', ConnectionResetError(10054, '远程主机强迫关闭了一个现有的连接。'))
```

## 解决方案

已修改代码，创建了两个独立的 `requests.Session`：

### 1. `self.session` - 微信 API 专用（禁用代理）
- 用于所有微信 API 请求
- **禁用代理**，确保使用真实 IP
- 避免微信 API 的 IP 白名单问题

### 2. `self.image_session` - 图片下载专用（使用代理）
- 用于所有图片下载操作
- **启用系统代理**，支持通过代理访问外网图片
- 自动读取系统代理设置

## 修改内容

### 1. 初始化两个 Session（第 206-222 行）

```python
# 创建两个 session：一个用于微信 API（禁用代理），一个用于图片下载（使用代理）
self.session = requests.Session()
self.session.proxies = {'http': None, 'https': None}
self.session.trust_env = False  # 禁用代理

self.image_session = requests.Session()
self.image_session.trust_env = True  # 启用系统代理
```

### 2. 修改图片下载代码

以下方法中的图片下载已改为使用 `self.image_session`：

- `_get_remote_image_as_temp_file()` - 第 85 行
- `_get_image_from_keyword()` - 第 113 行
- `_check_image_url_valid()` - 第 128 行
- `_get_local_image_path()` - 第 447 行

## 使用方法

### 方法 1：使用系统代理（推荐）

如果你的系统已经配置了代理（如 Clash、V2Ray），程序会自动使用：

```powershell
# 确保代理软件正在运行
# 直接运行程序
python wechat_publisher.py
```

### 方法 2：临时设置代理

在运行程序前设置环境变量：

```powershell
# PowerShell
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"
python wechat_publisher.py
```

### 方法 3：不使用代理

如果不需要代理，确保代理软件已关闭，或清除代理环境变量：

```powershell
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null
python wechat_publisher.py
```

## 故障排除

### 问题 1：仍然出现代理错误

**原因**：代理软件未运行或端口错误

**解决**：
1. 确认代理软件正在运行
2. 检查代理端口是否正确
3. 测试代理连接：
   ```powershell
   curl -x http://127.0.0.1:7890 https://www.google.com
   ```

### 问题 2：微信 API 报 IP 白名单错误

**原因**：微信 API 请求使用了代理 IP

**解决**：
- 这个问题已通过 `self.session` 禁用代理解决
- 如果仍然出现，检查是否有全局代理设置

### 问题 3：图片下载超时

**原因**：代理不稳定或网络问题

**解决**：
1. 切换代理节点
2. 增加超时时间（已设置为 30 秒）
3. 尝试不使用代理

## 技术细节

### Session 配置对比

| 特性 | self.session | self.image_session |
|------|-------------|-------------------|
| 用途 | 微信 API 请求 | 图片下载 |
| 代理 | 禁用 | 启用 |
| trust_env | False | True |
| 影响的请求 | get_access_token, upload_media, create_draft | 所有图片下载 |

### 代理检测逻辑

`requests` 库的代理检测顺序：
1. `session.proxies` 显式设置
2. 环境变量 `HTTP_PROXY` / `HTTPS_PROXY`
3. 系统代理设置（Windows）

通过设置 `trust_env=True`，`image_session` 会自动读取环境变量和系统代理。
