### 2. 图片获取优先级

**封面图获取流程：**
1. **Pexels API**（优先）
   - 使用 `PEXELS_API_KEY`
   - 高质量图片
   - 免费额度充足

2. **Unsplash 官方 API**（备用）
   - 使用 `UNSPLASH_ACCESS_KEY`
   - 当 Pexels 失败时自动切换
   - 每小时 50 次请求限制

3. **文字描述**（最后）
   - 当所有 API 都失败时
   - 使用生动的文字描述

## 🎯 工作流程

### 当程序处理文章时：

1. **检测图片链接**
   - GitHub 项目预览卡片
   - GitHub 作者头像
   - 其他图片链接

2. **验证图片有效性**
   - 检查链接是否可访问
   - 检查内容类型

3. **失效图片替换**
   - 提取图片描述中的关键词
   - 调用 Unsplash API 搜索图片
   - 如果 Unsplash 失败，调用 Pexels API
   - 如果都失败，使用文字描述

4. **封面图获取**
   - 优先使用 Pexels API
   - Pexels 失败时使用 Unsplash API
   - 都失败时使用文字描述

## 🔍 测试方法

### 测试 Unsplash API

运行以下 Python 代码测试：

```python
import os
import requests
from dotenv import load_dotenv

load_dotenv()

access_key = os.getenv('UNSPLASH_ACCESS_KEY')
api_url = "https://api.unsplash.com/search/photos"
headers = {
    'Authorization': f'Client-ID {access_key}',
    'Accept-Version': 'v1'
}
params = {
    'query': 'technology',
    'per_page': 1
}

response = requests.get(api_url, headers=headers, params=params)
print(f"状态码: {response.status_code}")
print(f"响应: {response.json()}")
```
