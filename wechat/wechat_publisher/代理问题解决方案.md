# WeChat Publisher 代理问题最终解决方案

## 问题现状

程序已经实现了自动代理检测，但仍然出现连接错误：
```
ProxyError('Unable to connect to proxy', ConnectionResetError(10054, '远程主机强迫关闭了一个现有的连接。'))
```

## 根本原因

1. **代理不稳定**：检测到的代理端口 (3067) 可能不稳定或配置不正确
2. **HTTPS 代理问题**：某些代理对 HTTPS 连接的处理有问题
3. **代理规则**：代理软件可能没有正确配置 GitHub/Unsplash 的路由规则

## 🔧 解决方案

### 方案 1：设置环境变量（推荐）

在启动程序前设置代理环境变量：

```powershell
# 设置 Clash 代理
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"

# 然后启动程序
python wechat_publisher.py
```

### 方案 2：使用直连（最简单）

如果你在国内可以直接访问 GitHub，关闭代理：

```powershell
# 关闭代理软件（Clash/V2Ray）
# 或者清除代理环境变量
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null

# 启动程序
python wechat_publisher.py
```

### 方案 3：修改代理软件配置

在 Clash 配置中添加规则，确保 GitHub 和 Unsplash 走代理：

```yaml
rules:
  - DOMAIN-SUFFIX,github.com,PROXY
  - DOMAIN-SUFFIX,githubassets.com,PROXY
  - DOMAIN-SUFFIX,unsplash.com,PROXY
  - DOMAIN-SUFFIX,githubusercontent.com,PROXY
```

### 方案 4：创建启动脚本

创建 `start_with_proxy.ps1`：

```powershell
# 设置代理
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"

Write-Host "✅ 已设置代理: $env:HTTP_PROXY" -ForegroundColor Green

# 启动程序
python wechat_publisher.py
```

使用方法：
```powershell
.\start_with_proxy.ps1
```

## ⚠️ 常见问题

### Q1: 为什么检测到代理但还是连接失败？

**A**: 可能原因：
1. 代理软件配置了规则，某些域名不走代理
2. 代理端口不稳定
3. HTTPS 证书验证问题

**解决**：
- 使用环境变量显式指定代理
- 或者使用直连

### Q2: 微信 API 报 IP 白名单错误

**A**: 这是因为使用了代理IP。

**解决**：
- 代码已经将微信 API 请求设置为直连
- 如果仍然出现，检查是否有全局代理设置

### Q3: 图片下载很慢

**A**: 代理速度问题。

**解决**：
- 切换代理节点
- 或者使用直连（如果网络允许）
