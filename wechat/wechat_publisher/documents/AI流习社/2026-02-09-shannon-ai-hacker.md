## 上手操盘：别废话，看它怎么动起来
安装过程极度丝滑，只要你有 Python 环境和对应的 API Key，剩下的就是交给它的 Agent 引擎。

```bash
# 克隆仓库并安装依赖
git clone https://github.com/example/shannon
cd shannon
pip install -r requirements.txt
# 启动你的自主黑客助手
python main.py --target example.com --autonomous
```
