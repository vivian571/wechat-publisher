# 提示词图片策略更新说明

## 更新日期
2025-12-29

## 更新原因
Unsplash API (`source.unsplash.com`) 已不可用，所有请求返回 503 错误。

## 更新内容

### 1. 开源智核提示词

**原策略：三级图片优先级**
1. GitHub 项目预览卡片
2. GitHub 作者/组织头像
3. ~~Unsplash 关键词图片~~ ❌

**新策略：**
1. GitHub 项目预览卡片（保留）
2. GitHub 作者/组织头像（保留）
3. **省略图片或使用文字描述** ✅

**替代方案：**
- 用**加粗的场景描述**来营造视觉感
- 用**比喻性语言**来增强画面感
- 示例："想象一下，当你打开终端，看到绿色的成功提示一行行滚动而过，那种掌控感就像是…"

### 2. AI流习社提示词

**原策略：**
- 全文必须包含**三张** Unsplash 图片 ❌

**新策略：**
- 使用**生动的文字描述**来营造视觉感 ✅
- 用**场景化语言**、**比喻**和**具体细节**来增强文章的画面感

**具体建议：**

#### 惊艳开局
- ~~配图：Unsplash (chaos, overwhelmed, deadline)~~
- **视觉化建议**：用生动的场景描写来营造混乱、压力的氛围
- 示例：描述凌晨的办公室、堆积如山的需求文档、闪烁的截止日期提醒等

#### 深度拆解
- ~~配图：Unsplash (automation, efficiency, workflow)~~
- **视觉化建议**：用流程图式的文字描述或比喻性语言来展现自动化的流畅感
- 示例："就像一条训练有素的流水线"、"如同指挥家挥动指挥棒"

#### 价值升华
- ~~配图：Unsplash (community, growth, future)~~
- **视觉化建议**：用展望性的语言来描绘未来场景
- 示例："想象一下，当你的团队不再被琐事困扰，每个人都能专注于创造价值…"

## 技术说明

### 为什么不使用 Unsplash？

1. **API 不可用**：`source.unsplash.com` 返回 503 错误
2. **官方已弃用**：Unsplash 已停止支持随机图片 API
3. **替代方案不稳定**：其他图片 API 也存在类似问题

### 为什么不使用 Pexels？

虽然 Pexels API 可用，但：
1. **需要 API Key**：增加配置复杂度
2. **有请求限制**：免费版有调用次数限制
3. **不适合提示词**：提示词应该是通用的，不依赖特定 API

### 最佳实践

**文字描述的优势：**
- ✅ 不依赖外部服务
- ✅ 更灵活，可以精确控制
- ✅ 增强文章的文学性
- ✅ 避免图片加载失败

**示例对比：**

❌ **使用图片：**
```markdown
![混乱的办公室](https://source.unsplash.com/800x600/?chaos,office)
```

✅ **使用文字描述：**
```markdown
凌晨3点的办公室，显示器的蓝光映照着疲惫的脸庞。桌上堆积如山的需求文档，
屏幕右下角闪烁着"距离截止日期还有2小时"的红色提醒。这是每个打工人都
经历过的噩梦时刻。
```

## 迁移指南

### 对于已生成的文章

如果文章中包含 Unsplash 图片链接：
1. **保留链接**：程序会自动检测失效链接
2. **自动替换**：程序会使用 Pexels API 获取封面图
3. **手动优化**：可以手动将图片链接替换为文字描述

### 对于新文章

使用更新后的提示词，AI 会自动：
1. 使用文字描述代替图片
2. 增强场景化语言
3. 提升文章的文学性和画面感

## 未来规划

- 测试其他图片 API（如 Pixabay）

## 总结

通过这次更新，我们：
1. ✅ 移除了对不可用 API 的依赖
2. ✅ 提升了文章的文学性
3. ✅ 增强了提示词的通用性
4. ✅ 避免了图片加载失败的问题

**核心理念**：用文字的力量创造画面，而不是依赖外部图片。
