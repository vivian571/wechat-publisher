# WeChat Publisher 代理配置说明

## 问题背景

`wechat_publisher.py` 在下载图片时遇到代理连接错误：
```
ProxyError('Unable to connect to proxy', ConnectionResetError(10054, '远程主机强迫关闭了一个现有的连接。'))
```

## 解决方案

已修改代码，创建了两个独立的 `requests.Session`：

### 1. `self.session` - 微信 API 专用（默认禁用代理，可选固定IP代理）
- 用于所有微信 API 请求
- **默认禁用代理**，使用本机网络，避免使用不稳定代理导致IP变动
- **支持配置固定代理**，通过 `WECHAT_PROXY_URL` 环境变量指定，用于解决本机IP变动问题

### 2. `self.image_session` - 图片下载专用（使用代理）
- 用于所有图片下载操作
- **启用系统代理**，支持通过代理访问外网图片
- 自动读取系统代理设置

## 修改内容

### 1. 初始化两个 Session（第 206-222 行）

```python
# 创建两个 session：一个用于微信 API（禁用代理），一个用于图片下载（使用代理）
self.session = requests.Session()
# ...
# 检查是否配置了微信API专用代理（用于固定IP）
wechat_proxy = os.getenv('WECHAT_PROXY_URL')
if wechat_proxy:
    self.session.proxies = {'http': wechat_proxy, 'https': wechat_proxy}
    self.session.trust_env = True 
else:
    # 默认禁用代理,确保微信API请求使用真实IP而非系统代理IP
    self.session.proxies = {'http': None, 'https': None}
    self.session.trust_env = False  # 忽略环境变量中的代理设置

self.image_session = requests.Session()
self.image_session.trust_env = True  # 启用系统代理
```

### 2. 修改图片下载代码

以下方法中的图片下载已改为使用 `self.image_session`：

- `_get_remote_image_as_temp_file()` - 第 85 行
- `_get_image_from_keyword()` - 第 113 行
- `_check_image_url_valid()` - 第 128 行
- `_get_local_image_path()` - 第 447 行

## 使用方法

### 场景 1：解决本机IP变动问题（推荐）

如果你的本机公网IP经常变动，导致需要频繁修改微信白名单，可以使用固定IP的代理服务器。

1. **购买或搭建一个固定IP的代理服务**（如 HTTP 代理或 Socks5 代理）。
2. 在 `.env` 文件中添加配置：

```bash
# 格式: http://user:pass@ip:port 或 socks5://user:pass@ip:port
WECHAT_PROXY_URL=http://your_static_proxy_ip:port
```

3. 将该代理服务器的 IP 地址添加到微信公众号后台的白名单中（只需添加一次）。

### 场景 2：使用系统代理（图片下载）

如果你的系统已经配置了代理（如 Clash、V2Ray），程序会自动使用它来下载图片：

```powershell
# 确保代理软件正在运行
# 直接运行程序
python wechat_publisher.py
```

### 场景 3：临时设置代理

在运行程序前设置环境变量：

```powershell
# PowerShell
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"
python wechat_publisher.py
```

## 常见代理地址

| 代理软件 | HTTP 代理地址 |
|----------|--------------|
| Clash | `http://127.0.0.1:7890` |
| V2Ray | `http://127.0.0.1:10809` |
| Shadowsocks | `http://127.0.0.1:1080` (需配合 Privoxy) |
