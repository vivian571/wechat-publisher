## ⚠️ 当前问题

### 代理连接不稳定

**现象**：
```
ProxyError: 远程主机强迫关闭了一个现有的连接
Pexels API 请求失败
Unsplash API 请求失败
```

**原因**：
- 代理端口 3067 不稳定
- API 调用通过代理时连接被重置

**影响**：
- 无法自动下载封面图
- 文章不会被创建为草稿

## 🔧 解决方案

### 方案 A：使用直连（推荐）

```powershell
# 清除代理
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null

# 重启程序
python wechat_publisher.py
```

### 方案 B：使用稳定代理

```powershell
# 使用 Clash 标准端口
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"

# 重启程序
python wechat_publisher.py
```
