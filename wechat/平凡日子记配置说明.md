# 平凡日子记公众号配置说明

## ⚠️ 重要发现

程序日志显示：**"账户 '平凡日子记' 未配置"**

这意味着虽然你创建了"平凡日子记"文件夹和文章，但程序无法发布，因为缺少公众号配置。

## 📝 需要配置的内容

### 在 `.env` 文件中添加：

```env
# 公众号: 平凡日子记
WECHAT_ACCOUNT_平凡日子记_APP_ID=你的APP_ID
WECHAT_ACCOUNT_平凡日子记_APP_SECRET=你的APP_SECRET
```

### 如何获取 APP_ID 和 APP_SECRET？

1. 登录微信公众平台
2. 进入 **设置与开发** → **基本配置**
3. 找到 **开发者ID(AppID)** 和 **开发者密码(AppSecret)**
4. 复制到 `.env` 文件中

## ⚠️ 常见问题

### Q1: 我没有"平凡日子记"公众号怎么办？

**选项 A**: 如果你有这个公众号，按上述步骤配置即可。

**选项 B**: 如果你想测试，可以暂时使用其他已配置的公众号：
- 将文章移动到 `documents/AI流习社/` 或其他已配置的文件夹

**选项 C**: 如果你不需要发布，只是想生成文章：
- 文章已经生成在 `documents/平凡日子记/` 文件夹中
- 你可以手动复制内容到公众号后台

### Q2: 配置后文章会自动发布吗？

**不会**。程序只会：
1. 将文章保存为**草稿**
2. 你需要手动登录公众号后台
3. 在草稿箱中找到文章
4. 手动点击"发布"

### Q3: 图片会自动处理吗？

**会**。程序会：
1. 检测文章中的 `unsplash://` 图片链接
2. 调用 Unsplash API 搜索图片
3. 下载图片并上传到微信素材库
4. 替换文章中的图片链接
