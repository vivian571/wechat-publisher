## 0. 快速认识这个“赛博侦探”

### 📌 项目是什么？
**Maigret** 是一款顶级开源的公开情报（OSINT）收集工具。它能通过用户名（Username）自动化地搜索社交媒体、论坛、博客、甚至是一些极其冷门的专业网站。它不仅仅是查找账户是否存在，还会智能提取页面上的头像、个人简介、位置等信息，生成一份详细的“数字画像”。

### ❓ 为什么会有这个项目？
因为信息是碎片的。一个人可能在微博叫“张三”，在 GitHub 叫“ZhangSan_Dev”，在某个游戏社区又叫“ZhangSan_Gamer”。Maigret 的诞生是为了把这些碎片拼成一张完整的拼图，帮助安全研究员、记者或普通人识别潜在的网络诈骗或进行背景调查。

### 🛠️ 怎么样运行运用项目？
1. **环境准备**：需要 Python 3.8+。
2. **一键安装**：`pip install maigret`。
3. **开启搜寻**：在终端输入 `maigret <用户名>`，然后看着屏幕上飞速跳出的“Found”列表。

## 2. 核心逻辑：特征匹配与概率聚合 (Probabilistic Aggregation)

### 底层逻辑本质：
Maigret 的本质是 **“大规模分布式网页探测” (Massive Parallel Web Probing)**。
1. **特征提取**：它不是盲目搜索，而是预存了 3000 多个平台的注册验证逻辑。
2. **多重验证**：通过 HTTP 状态码、页面关键字和正则表达式，判断该用户名是否真的属于同一人。
3. **关联分析**：如果多个网站出现了相同的头像或独特的简介，它的置信度就会直线上升。
