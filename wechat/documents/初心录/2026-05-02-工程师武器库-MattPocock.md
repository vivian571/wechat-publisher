## 0. 解锁 Claude 的“工程级”战力

### 📌 项目是什么？
**Matt Pocock's Skills** 是一个开源的工程实践配置库，专门用于增强 Claude 大模型（特别是其 Projects 功能）在代码开发中的表现。它由一系列高度精炼的 Markdown 文档组成，涵盖了从 TypeScript 最佳实践到高效测试的各路“潜规则”。

### ❓ 为什么会有这个项目？
因为普通大模型的原生回复往往太“AI 味”了——喜欢客套、喜欢过度解释、且不懂得特定项目的代码规范。Matt Pocock 作为一个顶级工程师，他发现通过提供一套结构化的“知识资产（Skills）”，可以让 AI 的工程直觉瞬间提升到 P8 级水平，减少 90% 的低级错误和无效对话。

### 🛠️ 怎么样运行运用项目？
1. **获取源码**：直接从 GitHub `git clone` 下来。
2. **按需取用**：根据你当前的任务，比如你要写测试，就打开 `testing.md`；你要写 TS，就打开 `typescript.md`。
3. **注入上下文**：将这些文件的内容直接粘贴到 Claude 网页版的 **"Project Instructions"** 或者是 VS Code 插件的 **"Custom Instructions"** 框里。

```markdown
# Role: 顶级全栈工程师 (Total Recall Mode)
# Principles:
1. **Never Assume**: 如果需求不清晰，必须先提问，严禁盲目猜测。

```
