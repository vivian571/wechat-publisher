## 2. 大白话拆解：把“汉字部首拆解与班级视线焦点”全部托付给基础代数

为了让刚入行、对高维矩阵和概率分布感到头疼的同学一秒开窍，我们把这两大核心过程做个最地气的比喻：

### BPE 分词器（Byte Pair Encoding）：把偏旁部首动态合成为汉字的过程
- **字符（Characters）**：就是最初的拼音或字母。
- **BPE 训练合并（Merge Rules）**：大模型觉得一个字母一个字母读太慢了。它在读书的过程中，发现“a”和“b”经常挨在一起出现（高频字符对）。于是它拿小章一盖，把它们合成为一个新的字根“ab”（Token ID）。下次再看到“a”和“b”，直接记为“ab”。
**通过这种动态合并偏旁部首的规则，大模型用极短的 ID 数组（Token IDs），就装下了整部字典！** 

### Scaled Dot-Product Attention：一个班级里每个人在看谁的“视线焦点网”
- **Query（问）**：你想在别人身上打听什么（比如：谁是我的同桌）。
- **Key（键）**：每个人身上贴着的亮眼标签（比如：我是张三，我是李四）。
- **Value（值）**：每个人真正拥有的硬核信息（比如：张三的数学成绩，李四的语文成绩）。
- **自注意力计算**：你拿着你的 Query（问），去和全班每个人的 Key（键）进行两两对视（矩阵点乘）。对视的眼神越激烈（点乘得分越高），说明关联度越强。我们用 Softmax 把眼神强度转化为“注意力百分比”（比如 80% 看向张三，20% 看向李四）。
**最后，你把注意力百分比乘上他们身上的 Value（值），得出的就是你今天最关注的核心信息量！** 这就是大模型能够看懂上下文指代关系的底层动力学本质！

## 3. 核心本质：BPE 贪心合并与缩放点积自注意力的数学铁律

这两大核心在数学上拥有极其优美的物理确定性：

### 铁律一：BPE 编解码的贪心字符串匹配（Greedy Text Compression）
在 Tokenizer 编码阶段，我们手里拿着训练好的“高频合并规则表 merge_rules”（例如：把词对 `('t', 'h')` 合并为 `('th')`）。
我们通过循环遍历当前文本的字符列表，**贪心地**寻找当前序列中在规则表里排名最前的词对进行合并，直到无法继续合并为止。
**这是一种完全确定性的无损压缩算法，是任何大模型吃进文本的物理第一防线！**

### 铁律二：自注意力矩阵的缩放 Softmax 归一化（Scaled Softmax Normalization）
自注意力公式是 Transformer 的灵魂地基：
$$Attention(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$
其中 $d_k$ 是特征维度（Head Dimension）。为什么要除以 $\sqrt{d_k}$？
因为在高维空间下，矩阵点乘的数值会变得非常大，导致 Softmax 的梯度几乎为 0（饱和死锁）。
**除以 $\sqrt{d_k}$ 强制将点积方差收敛在 1 左右，从而在大维度的神经网络训练中，保住了极其宝贵的梯度传播生命线！**

### 第一步：编写核心计算逻辑脚本

请在本地新建文件 `/Users/ax/wechat-publisher/agent-skills/nano_engine.py` 并写入以下全部可执行代码：

```python
import numpy as np
import sys

class BpeTokenizerFromScratch:
    def __init__(self):
        # 严格定义的 BPE 高频合并词表规则，拒绝任何占位符
        self.vocab = {i: chr(i) for i in range(256)} # 基础单字符字典 (0-255)
        self.merge_rules = {
            ("t", "h"): "th",
            ("e", "s"): "es",
            ("th", "e"): "the"
        }
        
        # 反向编解码索引映射表
        self.encoder = {v: k for k, v in self.vocab.items()}
        # 将合并词表注册进编码器
        next_id = 256
        for pair, merged in self.merge_rules.items():
            self.encoder[merged] = next_id
            self.vocab[next_id] = merged
            next_id += 1

    def encode(self, text):
        """将输入文本贪心地根据 BPE 词表规则编码为 Token ID 列表"""
        # 1. 初始切分为单字符列表
        words = list(text)
        
        # 2. 循环根据合并规则合并字符对
        changed = True
        while changed:
            changed = False
            i = 0
            while i < len(words) - 1:
                pair = (words[i], words[i+1])
                if pair in self.merge_rules:
                    # 替换并合并当前两个字符
                    merged = self.merge_rules[pair]
                    words[i] = merged
                    del words[i+1]
                    changed = True
                i += 1
                
        # 3. 将最终的合并词映射为对应的数字 Token ID
        token_ids = [self.encoder.get(w, ord(w[0])) for w in words]
        return token_ids

    def decode(self, token_ids):
        """将 Token ID 列表无损解码恢复为原始文本"""
        return "".join([self.vocab.get(tid, chr(tid)) for tid in token_ids])


class ScaledAttentionFromScratch:
    @staticmethod
    def softmax(x):
        """完全本地手搓的 NumPy 数值平移 Softmax 激活函数，防数值溢出"""
        # 减去最大值进行数值稳定平移
        exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
        return exp_x / np.sum(exp_x, axis=-1, keepdims=True)

    def forward(self, Q, K, V):
        """纯 NumPy 实现 Scaled Dot-Product Attention 自注意力前向传播，拒绝占位符"""
        Q = np.array(Q, dtype=np.float32)
        K = np.array(K, dtype=np.float32)
        V = np.array(V, dtype=np.float32)

        # 获取特征维度 dk
        d_k = Q.shape[-1]

        # 1. 矩阵乘法计算 Query 与 Key 的对视关联度 (Q @ K^T)
        dot_product = np.matmul(Q, K.T)

        # 2. 核心数学公式：除以根号 dk 进行缩放，稳定梯度方差
        scaled_scores = dot_product / math.sqrt(d_k)

        # 3. 运行 Softmax 将得分转化为注意力百分比分布
        attention_weights = self.softmax(scaled_scores)

        # 4. 注意力权重矩阵乘上真正的 Value 载荷 (Weights @ V)
        output = np.matmul(attention_weights, V)

        return output, attention_weights


# ==================== 仿真运行与测试驱动入口 ====================
import math

if __name__ == "__main__":
    print("[⚙] 引擎一：启动 BpeTokenizerFromScratch 分词器自检...")
    tokenizer = BpeTokenizerFromScratch()

    test_text = "the test"
    token_ids = tokenizer.encode(test_text)
    decoded_text = tokenizer.decode(token_ids)

    print(f" 📝 原始文本: '{test_text}'")
    print(f" 🔢 BPE 编码 Token IDs: {token_ids}")
    print(f" 🔠 BPE 无损恢复解码: '{decoded_text}'")

    print("\n--------------------------------------------------")
    print("[⚙] 引擎二：启动 ScaledAttentionFromScratch 自注意力求解器...")
    attention = ScaledAttentionFromScratch()

    # 模拟包含 3 个 Token 的句子（SeqLen=3），特征维度 HeadDim=4
    # 模拟输入 Query, Key, Value 矩阵
    Q = [
        [1.0, 0.0, 1.0, 0.0], # Token 1 的关注点
        [0.0, 2.0, 0.0, 1.0], # Token 2 的关注点
        [1.0, 1.0, 1.0, 1.0]  # Token 3 的关注点
    ]
    K = Q # 经典 Self-Attention：Key 与 Query 相同
    V = [
        [10.0, 0.0, 0.0, 0.0], # Token 1 承载的语义载荷
        [0.0, 20.0, 0.0, 0.0], # Token 2 承载的语义载荷
        [0.0, 0.0, 30.0, 10.0] # Token 3 承载的语义载荷
    ]

    # 运行自注意力前向计算
    out_vector, attn_matrix = attention.forward(Q, K, V)

    print("\n[📊 自注意力计算成功] 生成的注意力概率分布权重矩阵 (3x3)：")
    print(attn_matrix)

    print("\n[✔ 特征输出成功] 注意力计算融合后的最终高维语义特征 (3x4)：")
    print(out_vector)

    # 验证 BPE 编解码的一致性，以及注意力矩阵维度正确性
    if decoded_text == test_text and attn_matrix.shape == (3, 3) and out_vector.shape == (3, 4):
        print("\n[✔ 引擎测试结论] 极简 BPE 分词与 Scaled Softmax 自注意力前向传播 100% 成功！")
        sys.exit(0)
    else:
        print("\n[❌ 致命错误] 分词还原有损，或者自注意力矩阵运算维度失真！")
        sys.exit(1)
```

## 6. 避坑指南：手搓 LLM 底层算子的三大深水炸弹

* **避坑 1：未对矩阵进行数值平移导致 Softmax 指数溢出。** 在计算 `np.exp` 时，如果矩阵点积数值大于 700，计算机直接抛出 `NaN`（非数）或 Inf，导致整个神经网络输出瞬间化为一片空白。**必须在 softmax 内部，将矩阵每一行强行减去该行的最大值（Row-wise Max Subtraction），将指数范围强行压缩在 0 左右！**
* **避坑 2：字符对字典编码发生“哈希冲突”。** 在合并 Unicode 字符时，如果不小心把扩展字符（如中文的 Emoji）拆成了碎字节进行合并，可能会导致解码时生成不合法的 UTF-8 字符断裂错位。**建议只对标准的单字节（0-255 的 Byte）进行 BPE 合并，编解码前后一律走标准的 UTF-8 字节数组过渡！**
* **避坑 3：高维空间下的“特征饱和”。** 如果你的自注意力特征维度 $d_k$ 设置得非常大，且计算时忘记除以根号 $d_k$，注意力矩阵会退化成一个“One-Hot 矩阵”（概率只分布在最大值上，其余全为0），导致模型丧失多义指代能力。**在手搓计算时，千万千万不能漏掉 `math.sqrt(d_k)` 缩放项！**
