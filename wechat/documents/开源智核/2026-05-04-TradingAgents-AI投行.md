## 0. 快速认识这个“虚拟 AI 投行”

### 📌 项目是什么？
**TradingAgents** 并不是一个简单的选股器，它是一个完整的“金融决策委员会”。它把 AI 分裂成不同的角色：有的负责看宏观指标，有的负责盯技术面，有的负责做量化回测，还有一个“首席风险官”负责一票否决。这些 Agent 聚在一起“开会”，通过辩论得出最终的买卖指令。

### ❓ 为什么会有这个项目？
因为单一 AI 模型在金融市场极易发生“过拟合”或“幻觉”。在震荡市，看多和看空往往都有道理。TradingAgents 的诞生是为了利用 **“群体智慧” (Wisdom of Crowds)**。通过不同立场的 Agent 相互博弈，能极大地过滤掉虚假信号，捕捉到那些隐藏在噪音中的确定性机会。

### 🛠️ 怎么样运行运用项目？
1. **环境接入**：支持 Binance、Binance US 以及传统券商接口（如 Alpaca）。
2. **定义策略**：在 `agents/` 目录下配置不同角色的提示词逻辑。
3. **开启演化**：运行 `python main.py`，你就能在控制台看到多头和空头 Agent 正在进行激烈的逻辑交锋。

## 1. 痛点：为什么传统的量化策略正在失效？

量化交易已死？不，是传统的静态模型死了：
- 因子失效：所有人都在用的指标，就成了垃圾。
- 市场黑天鹅：突发新闻面前，传统算法只会傻跑。
**TradingAgents** 引入了 LLM 的理解力。它能读懂新闻，能理解情绪，甚至能理解对手盘的博弈心理。

## 2. 核心逻辑：多智能体强化学习与对冲辩论 (Hedging Debate)

### 底层逻辑本质：
TradingAgents 的本质是 **“博弈论在生成式 AI 中的应用”**。
1. **角色异构**：每个 Agent 的底层知识库和偏好不同，人为制造“观点分歧”。
2. **纳什均衡搜索**：通过多轮对话，系统尝试寻找一个让所有 Agent 都能接受的、风险最低的决策点。
3. **回测反馈**：每一次决策的盈亏都会回馈给 Agent，作为下次提示词优化的权重。

## 3. 手把手操作：3 分钟搭建你的“私人对冲基金”

### Step 1：数据订阅
接入 Alpha Vantage 或 Yahoo Finance 的实时 API 数据流。

### Step 2：组建“班子”
配置 3 个 Agent：
- **牛市倾向 Agent**：负责寻找上涨逻辑。
- **熊市倾向 Agent**：负责寻找做空理由。
- **风控主管 Agent**：负责检查最大回撤和仓位管理。

### Step 3：模拟盘运行
先在 Paper Trading 环境下运行一周。观察它们在突发利空时的辩论逻辑，如果逻辑没问题，再考虑实盘。
