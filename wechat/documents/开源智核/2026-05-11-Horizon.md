# Horizon 项目：你的智能新闻雷达，自动化信息工作流
你是否厌倦了每天被海量的新闻和信息淹没，难以找到真正有价值的内容？你是否梦想有一种工具，可以自动地为你筛选出最重要的新闻，并提供简洁的摘要？现在， Horizon 项目来了，它是一个 AI 驱动的新闻雷达，能够自动化你的信息工作流，让你轻松获取最有价值的信息。

## 痛点引入：信息过载的困境
在今天的信息时代，我们面临着一个严重的问题：信息过载。每天，成千上万的新闻、文章和帖子被发布到互联网上，如何从中找到真正有价值的信息成了一个挑战。我们可能会花费大量的时间浏览新闻网站、社交媒体和论坛，但仍然可能错过重要的信息。 Horizon 项目正是为了解决这个问题而诞生的。

## 核心拆解：Horizon 项目的工作原理
Horizon 项目的核心工作流包括以下几个步骤：
1. **Fetch**：从各种来源（如 Hacker News、RSS、Reddit、Telegram、GitHub）获取信息。
2. **Deduplicate**：去除重复的信息，确保每条信息只被处理一次。
3. **Score**：使用 AI 算法（如 Claude、GPT、Gemini、DeepSeek）对信息进行排名，评分范围为 0-10。
4. **Enrich**：对技术术语进行网络研究，提供更多的上下文信息。
5. **Summarize**：生成双语简介，帮助你快速了解信息的内容。
Horizon 项目使用 Python、uv 和 Docker 作为技术栈，确保了项目的稳定性和可扩展性。

## 实操指南：如何运行和使用 Horizon 项目
要运行 Horizon 项目，你可以按照以下步骤进行：
1. **安装**：使用命令行运行 `uv sync` 或 `docker-compose run --rm horizon`。
2. **设置**：运行 `uv run horizon-wizard` 进行初始设置。
3. **配置**：根据需要配置项目的参数，例如自定义阈值、评论摘要等。
4. **启动**：启动项目，Horizon 将开始自动化你的信息工作流。
