CloakBrowser 是一个基于 Chromium 的浏览器，它使用源码级别的指纹修复来躲过机器人检测。简单来说，它修改了浏览器的源码，使其看起来像是一个真正的用户，而不是机器人。它通过修改浏览器的行为、参数和指纹来实现这一点。例如，它可以修改浏览器的 User Agent、语言和时区等信息，使其看起来更加真实。

## 实操指南
要使用 CloakBrowser，首先你需要克隆它的 GitHub 仓库：
```bash
git clone https://github.com/CloakHQ/CloakBrowser.git
```
然后，你需要安装必要的依赖：
```bash
npm install
```
接下来，你可以使用以下命令来启动 CloakBrowser：
```bash
npm start
```
这将启动一个新的浏览器窗口，你可以使用它来访问任何网站，而不用担心被机器人检测。
