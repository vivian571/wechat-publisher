### 底层逻辑大拆解：Yazi 为什么能做到“快出残影”？

很多同学可能会问：“老师，为什么同样是终端文件浏览器，Yazi 就能比老牌的 ranger 或 mc 快这么多倍？”
答案在 Rust 的底层魔法和现代异步架构里。

1. **全异步任务调度（Non-blocking IO）：**
   传统的终端文件管理器是单线程的。当你进入一个包含一万个文件的文件夹时，它必须等这一万个文件的元数据（大小、时间等）全部读取完毕，才能渲染界面。此时界面就会出现明显的“卡顿”。
   Yazi 底层是纯异步的。它把读文件、算大小、解压文件等脏活累活全丢给后台的异步 worker。前端界面哪怕在一万个文件的目录里也是一瞬间秒开，完全不卡顿。
2. **终端 GPU 图像预览（Chafa & Kitty Graphic Protocol）：**
   普通的终端是不能显示图片的。要想预览图片，传统工具得调起一个外部看图软件。
   Yazi 实现了现代终端协议。它直接通过 Kitty 图像协议或 Chafa 字符画像素映射，在你的终端字符界面上**直接无损渲染出高清图片、PDF 的缩略图**。
   渲染速度极其逆天，不需要调任何外部软件，空格一下，图片瞬间呈现在终端方格里！

### 保姆级实操：三步让你的 macOS/Linux 终端武装到牙齿

我们以 macOS 为例，带你用最快速度跑通 Yazi！

#### 第一步：一键安装 Yazi 核心与预览依赖
1. Yazi 的安装极其简单，使用 Homebrew 可以直接一条命令搞定：
   ```bash
   brew install yazi ffmpeg sevenzip jq poppler fd ripgrep fzf zoxide
   ```
   *（注：后面那一串依赖包是 Yazi 的“黄金配角”，分别用于处理视频预览、压缩包预览、PDF预览、极速搜索和快速跳转。）*

#### 第二步：启动 Yazi 并熟悉核心快捷键
1. 在终端里，随手输入一个字母：
   ```bash
   y
   ```
   （或者输入完整命令 `yazi`），瞬间你会看到一个精致的、分成左中右三栏的终端面板！
2. 基础身法动作（VI 键位，完美符合程序员习惯）：
   - `k` / `j`：向上 / 向下移动光标。
   - `h` / `l`：向左（回到父目录）/ 向右（进入子目录或预览文件）。
   - `q`：退出 Yazi。

#### 第三步：极速文件操作绝招
1. **秒级定位（zoxide 联动）**：按 `z` 键，输入你想去的目录缩写，直接一步跨越到深层工作区。
2. **全局搜索（ripgrep 联动）**：按 `f` 键，输入文件内的任意关键词。Yazi 会瞬间在当前文件夹及子目录中，把所有包含该词的文件揪出来，并在右侧栏直接把匹配的那一行标红预览！

Yazi 的核心逻辑支持使用 Lua 语言编写自定义插件（比如自定义文件预览器、特定的快捷操作流）。

## Task:
协助用户编写用于 Yazi 的 Lua 脚本。

## Rules:

2. 提供清晰的配置修改说明，告知用户应该把 `.lua` 文件放进 `~/.config/yazi/plugins/` 目录的哪个位置。
3. 代码要写好完善的错误捕获，防止因为插件崩溃导致 Yazi 的终端界面死锁。

#### 🌟 优势角度：指尖飞舞的快感
对于资深终端党和 Vim 用户，Yazi 彻底打通了“文件操作”与“终端编辑”的隔阂。全键盘操作让思维不被打断，零鼠标交互极大地减轻了手腕的“鼠标手”负担。

对于习惯了直观“拖拽”文件夹的小白用户，满屏幕的快捷键（如 `y` 复制，`p` 粘贴，`d` 剪切，`v` 多选）具有非常高的记忆成本。一旦按错，可能会误删核心文件，因此新手需要一定时间的适应期。
