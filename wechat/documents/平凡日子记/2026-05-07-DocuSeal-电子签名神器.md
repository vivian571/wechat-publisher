#### 📍 预备动作：如何唤醒你的数字印章？

1.  **快速启动：** 强烈建议使用 Docker 部署，一行命令：`docker run -p 3000:3000 docuseal/docuseal`。
2.  **访问后台：** 浏览器打开 `localhost:3000`，设置管理员账号。
3.  **上传模版：** 把你常用的合同（比如租房合同、劳务协议）传上去。

---

#### 🔥 必杀技一：批量发送模式（专治「人多手杂」）

**适用场景：** 你要搞个线下活动，需要 50 个志愿者签免责协议。

**核心步骤：**

1.  **设定字段：** 在 PDF 上拖出“姓名”、“电话”、“签名”三个框。
2.  **生成链接：** 点击发送，选择“链接签署”。
3.  **群发：** 把这个链接发进群里。
4.  **坐收成果：** 后台会自动实时显示谁签了，谁还没签，一目了然。

---

#### 🔥 必杀技二：自动化提醒模式（专治「贵人多忘事」）

**适用场景：** 客户答应签合同，结果拖了三天没动静。

**核心步骤：**

1.  **开启通知：** 绑定你的邮件服务。
2.  **设定频率：** 勾选“如果 24 小时未签则自动重发提醒邮件”。
3.  **优雅催促：** 系统会替你当那个“恶人”，你只需要等结果。

---

#### 🔥 必杀技三：API 联动（专治「手动搬运」）

**适用场景：** 你有个个人网站，用户付完款自动给他在合同里填上名字并让他签名。

**核心步骤：**

1.  **调用 API：** 使用 DocuSeal 丰富的 API 接口。
2.  **预填数据：** 自动将用户信息填入 PDF 对应位置。
3.  **全自动闭环：** 整个过程你不需要点一下鼠标。
