## 3. 底层物理本质：文档提炼与模板融合的“两大核心机制”

为什么这套工具箱能够代替人类进行如此聪明的知识提炼？它在底层依赖于两个最基本的信息论本质：

### 本质一：TF-IDF（词频-逆文档频率）的简化“信息密度计算”
在不联网、不调用昂贵大模型 API 的前提下，AI 怎么知道一段话里哪句最重要？
`knowledge-work-plugins` 采用了一种极其精妙的**词频统计与关联度权重排序机制**。
它会首先静态扫描整篇文档，把“的、了、和”等没有任何信息量的无用停用词过滤掉。
接着，统计所有高频实词（如“自动化”、“部署”、“安全”）。
如果某句话里包含的高频实词密度最大，在数学上就代表这句话的**“信息承载量最大”**。通过对句子进行权重评分并逆向排序，就能以极高的精度提炼出文章的骨干摘要！

### 本质二：占位符变量拓扑替换（Placeholder Variable Topology）
CSV 文件本质上是一个结构化的二维关系矩阵（行代表记录，列代表属性）。
模板文件则是一个包含了特定插槽（例如 `{{UserName}}`）的文本图纸。
模板融合的本质，是通过建立一个**键值对字典映射（Key-Value Mapping）**，让解析器在微秒内静态遍历模板文本，将所有的占位符插槽，原位替换为当前行对应的强类型数值。这在编译层面上实现了绝对零偏差的定制化批量信息输出。

import sys
import os
import csv
import json
import collections
import re

# ==================== 工作流一：纯 Python 自动文档摘要特征提炼器 ====================
class DocumentSummarizer:
    def __init__(self, raw_text):
        self.raw_text = raw_text

    def extract_key_sentences(self, limit=3):
        """利用高频词频评分排序算法，在本地免 Token 提炼文档核心骨干摘要"""
        # 1. 以句号为分隔符，将长文切分成独立的句子列表，并清洗多余空格
        sentences = [s.strip() for s in self.raw_text.split("。") if s.strip()]
        if not sentences:
            return ["文档内容为空。"]

        # 2. 提取高频特征词汇（排除无价值的虚词和停用词，防干扰）
        words = []
        stop_words = {"的", "了", "和", "是", "在", "有", "我", "你", "他", "它", "我们", "你们", "他们", "这", "那", "之"}
        
        for sentence in sentences:
            # 去除句子中的标点符号
            clean_s = re.sub(r"[^\w\s]", "", sentence)
            # 采用双字滑动切片，模拟最轻量级的分词效果，拒绝任何外部包
            for i in range(len(clean_s) - 1):
                word = clean_s[i:i+2]
                if word not in stop_words and not word.isdigit():
                    words.append(word)

        # 统计频次
        word_frequencies = collections.Counter(words)
        if not word_frequencies:
            return sentences[:limit]

        # 3. 对句子进行重要度打分：句子包含的特征词频次越高，句子总得分越高
        sentence_scores = {}
        for idx, sentence in enumerate(sentences):
            score = 0
            for word, freq in word_frequencies.items():
                if word in sentence:
                    score += freq
            sentence_scores[idx] = score

        # 4. 提取得分最高的前 N 个核心句子
        top_indices = sorted(sentence_scores, key=sentence_scores.get, reverse=True)[:limit]
        # 按句子在文中的原始出场顺序进行重新排序，确保逻辑阅读连贯性
        top_indices.sort()
        
        # 重新补回句号输出
        return [sentences[i] + "。" for i in top_indices]


# ==================== 工作流二：CSV 数据与 Markdown 模板自动融合引擎 ====================
class CSVTemplateMerger:
    def __init__(self, csv_data):
        self.csv_data = csv_data

    def generate_markdown_notifications(self, template_str):
        """将结构化的 CSV 数据按行解析，并在微秒内塞入指定模板插槽中"""
        # 使用 Python 内置的 DictReader 精准按列名解析 CSV 字符串
        reader = csv.DictReader(self.csv_data.strip().split("\n"))
        notifications = []

        for row in reader:
            notification = template_str
            # 遍历 CSV 中的所有字段名，原位替换模板中的双大括号插槽 {{FieldName}}
            for key, val in row.items():
                placeholder = "{{" + key + "}}"
                notification = notification.replace(placeholder, val)
            notifications.append(notification)
            
        return notifications

## 6. 避坑指南：办公自动化开发的三个警钟

* **避坑 1：大文档切分时的“句号黑洞”。** 我们上面的摘要器使用了中文“。”作为切分边界。但如果在你的文档里，包含大量的英文缩写（如 `e.g.`、`U.S.` 等带点符号），或者包含大量的换行符没有清洗，简单的 split 会把一句话切得粉碎，导致语义彻底混乱。**在实际开发中，必须在切分前，使用正则表达式 `re.split(r'[。！\?\n]+', text)` 对常见的句子结束符进行联合切分，并清洗掉无用的短句！**
* **避坑 2：CSV 表格包含特殊字符导致的“替换崩塌”。** 如果你的 CSV 数据单元格里，刚好也包含了类似 `{{` 或者是特殊的 HTML/Markdown 标记（如逗号被直接写进数据列），使用 DictReader 可能会读取错位，或者在模板替换时发生多重嵌套污染，导致生成的信件出现严重的乱码。**请务必对 CSV 读入的字符串进行 HTML 实体转义（HTML Escape），将特殊符号过滤后再行融合！**
* **避坑 3：超大报表导致的“高频群发风控”。** 如果你的 CSV 里有上千条记录，你写了个循环直接调用 smtp 模块在 1 秒内批量发送 1000 封邮件，你的企业邮箱会在 10 秒内被网易、腾讯或谷歌直接判定为“垃圾邮件群发源”而强制封禁！**必须在发送循环中引入 `time.sleep(3)` 的合理延时，或者使用可靠的批量邮件队列通道（如 SendGrid/Mailgun）进行有序的流量塑形！**
