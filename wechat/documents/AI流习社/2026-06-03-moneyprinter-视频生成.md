### 底层逻辑大拆解：这台“视频印钞机”到底是怎么转的？

很多同学一听“一键生成视频”就觉得深不可测，是不是底层有个几百G的超级模型在跑？
其实不然！学生党也能一听就懂。
它的核心逻辑，说白了就是四个“打工人”在高度默契地接力跑：

1. **编剧担当（大语言模型 LLM）：** 
   你给它一个词，比如“熬夜的坏处”。LLM 瞬间在脑海中搜索，用最抓人的“黄金3秒法则”写出一段短小精悍的视频脚本。
2. **配音演员（TTS 语音合成系统）：** 
   拿到脚本后，TTS 引擎出场。它用极其逼真、带感情起伏的人声，把文字读出来，生成音频文件。
3. **视觉总监（视频素材检索匹配）：** 
   系统根据脚本里的关键词，在开源无版权的视频库（如 Pexels）里疯狂搜寻。比如提到“熬夜”，它就自动抓取“深夜玩手机”、“疲惫的脸”等高清片段。
4. **剪辑大师（FFmpeg 渲染合流）：** 
   最底层、最硬核的剪辑工程师。它把音频、视频片段、背景音乐以及根据音频时间戳自动生成的字幕（SRT），暴力拼接缝合在一起。

这四步一气呵成，全部在后台自动执行。你看到的，只是一条完美的短视频从进度条尽头诞生。

### 保姆级实操：三步跑通你的第一台“短视频发动机”

我们直接上干货，手把手教你如何在本地电脑上部署并跑通它！

#### 第一步：环境配置（基础底座）
MoneyPrinterTurbo 是基于 Python 开发的，所以你需要准备好 Python 环境：
1. 访问 Python 官网下载并安装 Python 3.10+。安装时务必勾选 **"Add Python to PATH"**。
2. 安装多媒体处理神器 FFmpeg。
   - **Windows 用户**：下载 FFmpeg 解压后，将其 `bin` 路径添加到系统环境变量 Path 中。
   - **macOS 用户**：直接在终端运行 `brew install ffmpeg`。

#### 第二步：源码下载与依赖安装
打开终端（Windows 的 cmd 或 macOS 的 Terminal），依次输入以下指令：
```bash
# 1. 克隆项目仓库
git clone https://github.com/harry0703/MoneyPrinterTurbo.git

# 2. 进入项目文件夹
cd MoneyPrinterTurbo

# 3. 安装依赖包
pip install -r requirements.txt
```

#### 第三步：一键配置与启动
1. 复制项目根目录下的 `config.example.yaml` 并重命名为 `config.yaml`。
2. 打开 `config.yaml`，填入你的大模型 API Key（比如 OpenAI、DeepSeek 或 DashScope），以及配音服务的配置。
3. 在终端运行启动命令：
   ```bash
   python webui.py
   ```
4. 终端会输出一个本地链接（通常是 `http://127.0.0.1:8501`）。复制到浏览器打开，就能看到酷炫的操作界面了！
5. 在界面上输入视频主题、选择配音风格和视频比例（如手机竖屏 9:16），点击 **“开始生成”**，剩下的交给 AI！

### 价值提示词：让 AI 变成爆款视频编剧

要想视频火，脚本必须骚。把这段系统提示词喂给你的大模型，让它写出来的脚本自带流量光环：

```markdown
# Role: 百万级短视频爆款文案专家

## Background:
你需要为短视频一键生成工具提供符合平台算法和用户心理的视频脚本。观众的注意力只有前3秒，文案必须极具冲突感和刺激性。

## Constraints:
1. 黄金3秒原则：开头第一句必须用悬念、痛点或惊人事实死死抓住观众，严禁无聊的自我介绍。
2. 节奏紧凑：使用极短句，多用动词，避免长篇大论。
3. 情绪价值：文案要能够唤起观众的情绪共鸣（如猎奇、焦虑、解压、愤怒或认同）。
4. 闭环输出：结尾必须有一个引导互动（如“关注我，下期更劲爆”、“你觉得呢？在评论区留下你的看法”）。

## Workflow:
- 输入一个主题后，生成约200-300字的旁白文案，并提供背景音乐风格建议（如：悬疑、欢快、史诗）。
```
