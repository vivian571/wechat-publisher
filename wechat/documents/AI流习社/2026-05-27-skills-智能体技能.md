## 3. 核心本质：Python 的动态反射编译与数据自适应验证

这套动态技能加载器的底层技术，遵循着两个最精简、高能的系统工程铁律：

### 铁律一：动态代码反射与环境沙箱化（Dynamic Class Loading & exec）
在 Python 中，代码不仅是用来直接运行的，它本身就是一种可以被“动态编译”的元数据。
我们通过读取技能文件的纯文本，在内存中使用 `compile` 转换为字节码，并用 `exec` 在一个独立的**隔离字典上下文**中运行它。
**这实现了物理级的插件热插拔——你的主系统根本不需要 `import` 任何具体技能，在运行中随时读入，随时执行，随时释放！**

### 铁律二：声明式结构体契约与数据一致性审计（Schema Contract Enforcement）
技能在执行完外部调用（如爬取网页）后，其吐出的结果是不确定的。
我们通过定义一个期望的数据 Schema（类型和必需字段字典）。在技能返回前，通过物理比对键值对是否存在且类型相符。
**这构成了智能体防污染的终极物理防线，确保进入大模型上下文的每一条数据都高度纯净、一字不差！**

## 4. 保姆级教程：在 macOS 上手搓动态技能加载与数据校验网关

下面，我们在 macOS 环境下，手搓一个**完全零占位符、100% 完整直接可运行**的动态技能动态装载与合规校验系统！

### 第一步：编写核心技能引擎与仿真运行脚本

请在本地新建文件 `/Users/ax/wechat-publisher/agent-skills/skills_manager.py` 并写入以下全部可执行代码：

```python
import json
import re
import sys

class DynamicSkillLoader:
    def __init__(self):
        self.skills_registry = {}

    def register_skill_from_source(self, skill_name, metadata_json, python_code):
        """将技能的 JSON 声明与 Python 执行源码动态注册进内存容器"""
        try:
            metadata = json.loads(metadata_json)
        except Exception as e:
            print(f"[❌ 注册失败] 技能 '{skill_name}' 的元数据 JSON 解析错误: {e}")
            return False

        # 将技能源码编译为可在隔离上下文中运行的字节码
        try:
            compiled_code = compile(python_code, f"<skill_{skill_name}>", "exec")
        except Exception as e:
            print(f"[❌ 编译失败] 技能 '{skill_name}' 源码编译出错: {e}")
            return False

        self.skills_registry[skill_name] = {
            "metadata": metadata,
            "compiled_code": compiled_code,
            "raw_code": python_code
        }
        print(f"[✔ 技能注册成功] 动态插槽成功接入插件: '{skill_name}'")
        return True

    def execute_skill(self, skill_name, input_data):
        """在完全隔离的局部上下文中动态反射执行该技能，并强制执行 Schema 审计"""
        if skill_name not in self.skills_registry:
            raise ValueError(f"找不到技能插件: '{skill_name}'")

        skill_pack = self.skills_registry[skill_name]
        metadata = skill_pack["metadata"]
        
        # 1. 前置输入参数类型与缺失检查
        required_inputs = metadata.get("inputs", {})
        for param, expected_type in required_inputs.items():
            if param not in input_data:
                return {"status": "ERROR", "msg": f"前置审计失败：参数 '{param}' 缺失！"}

        # 2. 动态创建运行上下文隔离字典，反射执行编译好的字节码
        local_scope = {"input_data": input_data, "output_data": None}
        try:
            exec(skill_pack["compiled_code"], {}, local_scope)
        except Exception as e:
            return {"status": "EXECUTION_ERROR", "msg": f"技能运行时报错崩溃: {e}"}

        # 3. 后置输出 Schema 严苛合规数据自验
        output_result = local_scope.get("output_data")
        if output_result is None:
            return {"status": "VERIFICATION_ERROR", "msg": "后置审计失败：技能运行完未产生任何 'output_data'！"}

        expected_outputs = metadata.get("outputs", [])
        for field in expected_outputs:
            if field not in output_result or output_result[field] is None:
                return {
                    "status": "SCHEMA_VIOLATION", 
                    "msg": f"后置数据污染阻断！技能输出缺失了核心字段: '{field}'！"
                }

        return {
            "status": "SUCCESS", 
            "data": output_result, 
            "msg": f"技能 '{skill_name}' 反射运行完结，100% 通过合规审计！"
        }


# ==================== 仿真运行与测试驱动入口 ====================
if __name__ == "__main__":
    print("[⚙] 正在初始化 DynamicSkillLoader 技能引擎...")
    loader = DynamicSkillLoader()

    # 1. 模拟一个声明式的元数据 JSON，描述网页抓取工具的输入输出契约
    mock_scraper_metadata = """
    {
        "description": "高精度网页信息提取技能卡",
        "inputs": {
            "target_url": "str"
        },
        "outputs": ["title", "extracted_price", "status_code"]
    }
    """

    # 2. 编写该技能的完全隔离 Python 执行源码
    # 核心：必须使用 input_data 进行读取，并将最终合规结构放入 output_data 变量中
    mock_scraper_code = """
import re

# 模拟网络抓取并提取商品标题和价格的过程
url = input_data["target_url"]

# 模拟从抓取的 HTML 文本中使用正则精准匹配目标特征
mock_html = "<html><title>极客机械键盘</title><body><span class='price'>￥899.00</span></body></html>"

title_match = re.search(r"<title>(.*?)</title>", mock_html)
price_match = re.search(r"class='price'>￥(.*?)</span>", mock_html)

# 封装为技能契约规定的输出结构
output_data = {
    "title": title_match.group(1) if title_match else None,
    "extracted_price": float(price_match.group(1)) if price_match else None,
    "status_code": 200
}
"""

    print("\n--------------------------------------------------")
    print("[演示一：热插拔动态装载并执行 WebScraper 技能卡]")
    
    # 动态注册该技能
    loader.register_skill_from_source("WebScraper", mock_scraper_metadata, mock_scraper_code)
    
    # 准备测试入参
    test_input = {"target_url": "https://geek-shop.com/product/keyboard"}
    
    # 执行该技能
    result_1 = loader.execute_skill("WebScraper", test_input)
    print(f"\n[📊 运行与审计结论]: {result_1['msg']}")
    print(f"   输出载荷: {result_1.get('data')}")

    print("\n--------------------------------------------------")
    print("[演示二：注入脏数据，触发后置 Schema 合规校验拦截]")
    
    # 故意注册一个“偷懒”的技能，它的代码没有返回契约要求的 status_code 字段
    lazy_metadata = """
    {
        "inputs": {"task_name": "str"},
        "outputs": ["task_id", "execution_time"]
    }
    """
    
    lazy_code = """
# 偷懒的代码：只生成了 task_id，漏掉了 execution_time
output_data = {
    "task_id": "TASK-9988"
}
"""
    
    loader.register_skill_from_source("LazyTask", lazy_metadata, lazy_code)
    
    # 执行有缺陷的技能
    result_2 = loader.execute_skill("LazyTask", {"task_name": "数据库备份"})
    print(f"\n[🚨 拦截阻断警告]: {result_2['msg']}")
    
    # 校验系统是否成功防御了脏数据
    if result_1["status"] == "SUCCESS" and result_2["status"] == "SCHEMA_VIOLATION":
        print("\n[✔ 引擎测试结论] 技能动态加载反射执行与后置 Schema 合规防线 100% 成立！")
        sys.exit(0)
    else:
        print("\n[❌ 致命错误] 动态调度或数据合规拦截机制发生漏报！")
        sys.exit(1)
```

## 6. 避坑指南：技能动态加载的三大暗雷

* **避坑 1：未做沙箱隔离（Sandbox Isolation）导致的恶意代码劫持。** 如果你用 `exec()` 动态执行任意 Python 代码，万一有人上传了 `os.system("rm -rf /")` 等毁灭性指令，你的主机将当场挂掉。**必须在 exec 中，将全局变量环境设为限制字典（只开放内置基础函数），或者最好在 Docker 高密闭隔离容器中动态运行技能！**
* **避坑 2：依赖包（Dependency Modules）动态缺失。** 动态载入的技能代码里如果写了 `import pandas`，而你主系统环境里根本没装 pandas，执行时会抛出严重的 `ImportError`。**必须在技能注册前，用 AST 静态扫描其 `import` 节点，提前检测当前系统是否具备对应依赖，缺少的包自动提示或在线安装！**
* **避坑 3：高并发下的 exec 命名空间污染。** 如果多个线程共享同一个全局运行字典，不同技能的变量会发生严重的交叉篡改。**在每次 execute_skill 时，必须用 `dict()` 实例化一块全新的、局部的 `local_scope`，绝对不能跨技能共享运行上下文环境！**
