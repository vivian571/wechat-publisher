## 0. 快速认识这个“蜂群指挥部”

### 📌 项目是什么？
**Ruflo** 是一个顶级的智能体编排平台，专门优化了对 Claude 模型（特别是 Claude Code/Codex）的支持。它能让你部署“分布式蜂群智能（Distributed Swarm Intelligence）”，让多个 Agent 像一支训练有素的军队一样，自动分工、协作并完成极其复杂的任务。

### ❓ 为什么会有这个项目？
现在的 AI 虽然聪明，但处理超大规模项目时还是会“顾此失彼”。就像你请了一个博士后，但他只有两只手。Ruflo 的诞生是为了把“博士后”克隆出 100 个，并给他们配上一套完美的指挥系统，解决大规模、长周期的企业级任务。

### 🛠️ 怎么样运行运用项目？
1. **获取通行证**：准备好 Anthropic 的 API Key。
2. **本地安装**：通过 `pip install ruflo` 获取指挥权。
3. **部署蜂群**：在配置文件中定义你的“蜂群策略（Swarm Policy）”，指定哪些 Agent 负责 RAG（搜索）、哪些负责执行、哪些负责最后的逻辑汇总。

## 2. 核心逻辑：分布式蜂群智能 (Swarm Intelligence)

### 底层逻辑本质：
Ruflo 的本质是 **“状态解耦与动态路由” (State Decoupling & Dynamic Routing)**。
1. **解耦**：每个 Agent 只负责自己那一亩三分地，不占用全局 Token。
2. **路由**：系统根据任务难度，自动决定是派出一个“小兵”还是启动一个“智囊团”。
这就像是互联网的分布式架构，极大地提高了系统的稳定性和吞吐量。

## 3. 手把手操作：3 分钟部署你的第一个“特工中队”

### Step 1：环境初始化
```bash
ruflo init --platform claude
```

### Step 2：定义“蜂群”画像
在 `swarm.json` 里写入：
- **Agent A (侦察兵)**：负责监控实时行情。
- **Agent B (分析师)**：负责对比历史数据。
- **Agent C (审核官)**：负责否定 A 和 B 的不合理方案。

### Step 3：开启“上帝模式”
```bash
ruflo up
```
你会看到终端里多个窗口并发闪烁，那是你的 AI 军队正在紧锣密鼓地为你搞钱/搞代码。
