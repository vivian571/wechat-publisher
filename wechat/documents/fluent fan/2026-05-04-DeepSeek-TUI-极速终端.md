## 0. 快速认识这个“终端极速版”

### 📌 项目是什么？
**DeepSeek-TUI** 是一个基于文本终端界面（TUI）的 DeepSeek 模型交互工具。它专门为开发者设计，能直接在你的命令行里调用 DeepSeek-V3 或 R1。它不仅支持流式输出，还能完美渲染代码高亮，甚至能一键把生成的代码存入本地。

### ❓ 为什么会有这个项目？
因为网页端太重了！在写代码写到一半时，切出去找浏览器是极大的干扰。DeepSeek-TUI 的诞生是为了实现 **“沉浸式 AI 协助”**。它轻量、稳定，不需要你为了问一个函数而打开占用几百兆内存的 Chrome 浏览器。

### 🛠️ 怎么样运行运用项目？
1. **获取秘钥**：去 DeepSeek 官网申请一个 API Key。
2. **一键安装**：通过 `pip install deepseek-tui`（或直接运行项目脚本）。
3. **极速发车**：在终端输入 `ds`，瞬间开启与地表最强国产大模型的对话。

## 1. 痛点：为什么网页版总是不顺手？

网页对话框在处理长代码时总是卡顿：
- 格式错乱：复制出来全是各种符号。
- 干扰太多：又是通知又是广告。
- 响应慢：网页加载就需要 5 秒。
**DeepSeek-TUI** 只有 0.1 秒的启动延迟，代码块自带“一键复制”到剪贴板功能。这才是程序员该有的节奏。

---

## 2. 核心逻辑：轻量化路由与异步渲染 (Lightweight Routing)

### 底层逻辑本质：
DeepSeek-TUI 的本质是 **“极简主义的 API 封装”**。
1. **路由**：直接对接 DeepSeek 的推理接口，去掉了所有前端冗余。
2. **渲染**：利用 `rich` 或 `prompt_toolkit` 库，在黑白终端里渲染出全色彩的代码高亮。
这不仅是为了好看，更是为了 **“极致的响应速度”**。

## 3. 手把手操作：1 分钟配置你的“终端战神”

### Step 1：配置环境变量
把你的 API Key 写入系统的 `.bashrc` 或 `.zshrc`：
`export DEEPSEEK_API_KEY="你的KEY"`

### Step 2：自定义主题
在配置文件里选一个“黑客绿”或者“深空灰”的主题。

### Step 3：开启“对话驱动开发”
一边写代码，一边在侧边栏终端问：“这段递归怎么优化？”
DeepSeek-TUI 的回复速度会让你怀疑它是不是就住在你电脑里。

4. **底层本质**: 请从内存分配或算法复杂度的角度，解释为什么要这样写。
