## 0. 让 AI 成为“网页冲浪王”

### 📌 项目是什么？
**Browserbase Skills** 是一个专门为 Claude 等 AI 智能体设计的 Web 浏览器交互工具包（SDK）。它将复杂的浏览器操作（如解析网页、点击按钮、处理异步加载）封装成了 AI 可以直接调用的“技能点”。

### ❓ 为什么会有这个项目？
现在的 AI 大多被困在“文本对话框”里。即使 AI 有了联网搜索能力，它也无法真的像人一样去“逛”网页——比如输入验证码、点击深度嵌套的菜单、或者在一个极其复杂的管理后台里执行任务。Browserbase 的出现，是为了让 AI 真正拥有“数字实体”的能力，能去任何人类能去的地方。

### 🛠️ 怎么样运行运用项目？
1. **注册获取 Token**：去 Browserbase 官网注册一个开发者账号并拿到 API Key。
2. **集成到项目**：通过 `npm install @browserbaseai/skills` 将其引入你的代码。
3. **注入技能**：在调用 Claude 模型时，将这个工具包挂载到它的 `tools` 列表里，Claude 就会在需要时自动开启一个云端 Chrome 浏览器去执行你的指令。

## 1. 痛点：AI 的网页访问其实很“脑残”

你是不是经常遇到这种尴尬：

或者它只能抓取静态 HTML，一遇到要登录、要点按钮、要滑动的动态页面，AI 就直接“间歇性失明”。

**这不叫访问网页，这叫读快报。**
真正的访问，应该是 AI 能自己输入账号密码，能避开弹窗，能在复杂的管理后台帮你修改设置。**Browserbase Skills** 做的就是这件事。

---

## 2. 核心逻辑：为什么 Browserbase 敢叫“Skills”？

### 底层逻辑本质：
它不是一个简单的爬虫，它是一个 **“浏览器代理层” (Headless Browser Agent)**。
核心在于它把浏览器的每一个操作（点击、输入、等待、解析 DOM）都封装成了 Claude 能听懂的 **Function Calling (函数调用)**。

Claude 只需要思考：“我要点那个‘登录’按钮”，Browserbase 就会在云端浏览器里真的点下去，并把截图和结果返回给 Claude。

```markdown
4. **目标导向**: 每次跳转页面前，请先自问：“这一步对最终目标的贡献是什么？”
```
