### 一、 到底是个啥神仙项目？（一句话：AI 界的“万能全家桶”路由）

简单来说，**9router 就是一个让你的 Claude Code、Cursor、Cline 彻底“无限续杯”的超级网关**。

以前你用 AI 编程，最怕两件事：一是 **Token 贵得肉疼**，二是 **用着用着就提示“达到限制” (Rate Limit)**。
现在有了 9router，它就像一个超级智能的“流量调度中心”。它背后连接了 40 多个免费和付费的 API 提供商。一个挂了？自动跳下一个。这个贵了？自动帮你找那个便宜的。
它甚至能帮你 **节省 40% 的 Token 消耗**（通过 RTK 压缩技术）。

---

### 二、 为什么会有这个项目？（痛点暴击：终结“被模型卡脖子”的焦虑）

为什么我们需要 9router？因为 AI 开发者有三个不可调和的矛盾：

1.  **钱包跟不上脑子**：想用 Claude 3.5 Sonnet，但官方 API 太贵。
2.  **网络不稳**：直连官方 API 经常抽风，导致代码写一半卡死。
3.  **厂商跑路/封号**：如果你只绑死一家供应商，它一封号你就瘫痪。

**9router 的底层逻辑：**
它实现了一个 **“多路复用 + 自动热备”** 的架构。你只需要给 9router 发指令，它去跟背后的 40 多个小弟（提供商）沟通。对你来说，API 永远在线，永远免费（或极低成本）。

### 三、 怎么样运行运用项目？（三步走，实现 Token 自由）

不需要高深的代码知识，跟着我撸：

#### 第一步：安装网关（一键部署）
你可以本地跑，也可以直接用官方提供的公共端点：
```bash
# 本地部署
git clone https://github.com/decolua/9router
cd 9router
docker-compose up -d
```

#### 第二步：配置你的“小弟”（API Key 聚合）
在 `config.yaml` 里，把你从 OpenRouter、Groq、DeepSeek 或者各种免费渠道薅来的 API Key 全部丢进去。
```yaml
providers:
  - name: groq
    api_key: gsk_xxxx
  - name: deepseek
    api_key: sk_xxxx
```

#### 第三步：连接你的 IDE（丝滑替换）
在 Cursor 或 VS Code 的设置里，把 API URL 改成 `http://localhost:3000/v1`。
**完工！现在你的 AI 已经是不死之身了。**

### 四、 核心逻辑本质：为什么它能省钱还不限制？

它的核心逻辑可以总结为 **“动态降级与压缩”**：

1.  **RTK 压缩 (Token Reduction)**：它会自动优化 Prompt 结构，删掉冗余的系统提示词，在不降低智商的前提下，帮你省下 40% 的钱。
2.  **智能 Fallback**：如果 Claude 3.5 报错 429（频率限制），它会在毫秒级内无感切换到 DeepSeek 或 Gemini Pro，保证你写代码的手感不断。
3.  **负载均衡**：它会把请求平均分配到不同的 key 上，完美绕过单 key 的并发限制。

### 八、 避坑指南：不看后悔系列

1.  **供应商优先级**：不要把所有模型都设为同一个优先级。建议把 **DeepSeek** 设为高优先级（便宜好用），把 **Claude 3.5** 设为低优先级或手动确认，否则你一不小心就会把余额跑空。
2.  **长连接超时**：如果你在写超长代码，有些免费提供商可能会中途断开连接。**对策：** 开启 9router 的 `stream_retry` 功能，它能帮你自动续上断掉的输出。
3.  **Key 被泄露风险**：如果你部署的是公共端点且没加密码，别人扫到你的 IP 就能盗刷你的 Key。**必须：** 设置 `api_key` 认证！
