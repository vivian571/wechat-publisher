## 0. 快速认识这个“网页执行官”

### 📌 项目是什么？
**Browserbase Skills** 是一个专门为智能体（Agents）设计的网页浏览器操控工具包。它能把复杂的浏览器操作（如：点击、滚动、输入、处理弹窗）封装成简单的函数。当你在使用 Claude Code 或类似的 Agent 时，只要接入这个 Skills 包，AI 就能像真人一样，登录你的后台、爬取最新的数据，甚至帮你订一张机票。

### ❓ 为什么会有这个项目？
因为目前的 AI 虽然聪明，但它们是“瞎子”和“瘸子”。它们能告诉你怎么做，但没法替你去做。传统的爬虫工具又太死板，过不去验证码，处理不了动态页面。Browserbase Skills 的诞生是为了给 AI 提供一个 **“无头浏览器的云端化接口”**，让 AI 能在复杂的、动态的现代网页中自由穿梭。

### 🛠️ 怎么样运行运用项目？
1. **获取权限**：注册 Browserbase 获取 API Key。
2. **安装 SDK**：`npm install @browserbasehq/skills`。
3. **挂载技能**：将 `web_browse` 技能注入到你的 Claude 提示词上下文。
4. **下达指令**：直接说：“去亚马逊帮我对比一下这款相机的价格趋势，并截图发给我。”

## 2. 核心逻辑：DOM 树简化与视觉引导 (DOM Simplification)

### 底层逻辑本质：
Browserbase Skills 的本质是 **“将混乱的网页结构转化为 AI 可读的意图清单”**。
1. **语义化提取**：它会自动过滤掉网页上的广告和无用标签，只把核心的按钮、表单和文本传给 AI。
2. **视觉确认**：它支持实时截图回传，让 AI 能通过视觉确认操作是否正确。
3. **会话持久化**：它能保留 Cookie，这意味着 AI 可以像你一样，在登录状态下进行跨页面的复杂操作。
