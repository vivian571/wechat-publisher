### 二、 为什么会有这个项目？（痛点暴击：解决大模型的“断网症”与“只能动嘴病”）

为什么我们需要 `browserbase/skills`？因为传统的 AI 应用有三个致命痛点：

1.  **鱼的记忆（数据永远滞后）：** 平时我们直接在对话框里提问，一旦涉及到最新的热搜、刚刚发布的财报，大模型因为训练数据滞后，直接歇菜。
2.  **外挂太虚（假装在上网）：** 以前为了让 AI 联网，大家会用一些简单的搜索插件。但这种插件只能提取网页里的纯文字，一遇到动态加载的图表、需要点击才能展开的评论区，就原形毕露抓不到东西。
3.  **操作受限（只会看不会动）：** 扔给 AI 一个任务，比如“帮我订一张明天的机票”，它只能告诉你怎么订，绝对没法亲自上手帮你点确认。

**这个技能包的出世，就是来掀桌子的：**
*   **持久化视觉记忆：** 它把你看到的网页直接转化成 DOM 结构和“屏幕截图”双重信息“喂”给 AI。哪怕网页设计得再花里胡哨，AI 照样能一眼看穿哪是按钮哪是广告！
*   **内挂无敌（真实的动作控制）：** 它是真正**内置在云端浏览器里的鼠标和键盘**，原汤化原食，点击、滑动、拖拽，动作极快，而且像真人一样自然。
*   **边界锁死：** 它可以设置操作白名单，完美防止它乱点网页把你电脑搞中毒。

### 三、 核心逻辑与底层本质（大白话拆解：从“文本驱动”到“视觉交互驱动”）

**底层逻辑本质是什么？**
**是“视觉状态机（Visual State Machine）”与“工具调用（Tool-Calling）”的结合。**

*   **普通联网（文本导向）：** 核心是“你去找这段文字（Search this text）”。重点在**爬取**。页面一旦爬完，不管对错，任务就结束了。
*   **技能驱动（视觉导向）：** 核心是“你要操作这个界面达成什么状态（Interact with this UI）”。重点在**反馈**。它会不断检查当前的屏幕截图是不是目标页面。如果点错了，就点后退继续试；只有页面跳对了，才判定这一步完成。

就好像你让你妈帮你网上买个东西。
普通指令：“去淘宝买那双红鞋”。（如果页面弹了个广告挡住了，你妈就不知所措了）。
技能指令：“看着屏幕，把阻挡的 X 号点掉，在搜索框输入名字，找到第一个，点击结算”。（直到订单支付成功界面出现才算完）。

这就叫**内置的视觉纠错循环**，一种真正的高级 UI 自动化机制。

### 五、 避坑劝退指南（这四种情况，千万别用冲浪插件！）

好钢要用在刀刃上，以下情况强行用网页外挂，轻则浪费 Token，重则泄露资产：

1.  **杀鸡用牛刀（简单的 API 能查到的事）：** 比如“查一下今天的天气”。直接调天气 API 零点几秒就搞定了，非要让 Agent 打开墨迹天气的网页去看，大材小用又烧钱。
2.  **不说人话（毫无视觉标识的页面）：** 比如一个全是密密麻麻乱码、连个正常按钮都没有的网页。AI 眼睛再好使也看不懂，绝对会跑偏卡死。
3.  **需要你当裁判的感官体验任务：** 比如“打开 B 站帮我看看这个视频好不好看”。这种需要主观情绪判断的事，机器只能看看播放量，不适合扔给它自己判断。
4.  **自爆卡车（让 AI 代替你输密码转账）：** 比如“登录我的网银帮我给房东转账”。**千万别用！** 一旦它点错了小数点或者循环执行，后果就是灾难级的。

### 六、 价值千金的“核心自动冲浪模板”

正如前面所说，直接给外挂喂一句简单提示词会导致灾难（乱点广告、陷入死循环）。
我把让浏览器插件发挥出 100% 潜力的底层逻辑，整理成了一份**万能高价值交互提示词模板**。只要套用这个格式，AI 绝对不会迷路！

**👇 模板直接复制可用：**

```text
/goal 
【核心冲浪任务（Task）】
请帮我打开 [具体网页网址]，并完成 [某个复杂的交互操作，如：下载指定日期的报表]。

【作用域约束（Scope）】
请严格注意：只允许在 [该网站的主域名下] 进行点击，绝对不要点击任何第三方广告或外部链接！

【执行约束（Constraints）】
1. 必须使用 `browser_navigate` 和 `browser_click` 等标准工具动作。
2. 遇到 [弹窗或验证码阻挡] 时，请按照 [尝试关闭弹窗或请求人类协助] 的逻辑处理。

【完成判定标准（Done Condition）】
什么时候算交互完成？
当满足以下所有条件时，你才可以停止：
1. 页面成功跳转到了“下载成功”的状态页。
2. 你能获取到目标文件的下载链接或者页面截图。

【强制停止条件（Stop Condition & Budget）】
在以下情况下，请立即停止所有操作并向我报告：
1. 发现页面一直加载不出来（白屏）超过 3 次。
2. 同一个按钮点击后，页面状态毫无变化陷入死循环。
```
