# ConardLi/garden-skills：AI 编码助手的终极技能库
作为一名开发者，你是否曾经梦想有一天，机器可以帮你完成大部分的编码工作？今天，我们要介绍的项目就是一个让这个梦想成真的神奇工具：ConardLi/garden-skills。这个项目是一个为 AI 编码助手提供的技能库，包括四个核心技能：web-video-presentation、web-design-engineer、gpt-image-2 和 kb-retriever。

## 痛点引入
我们都知道，编码是一项非常耗时和枯燥的工作，尤其是当我们需要重复完成一些简单的任务时。然而，随着 AI 技术的发展，我们可以利用机器来帮助我们完成这些任务，从而提高我们的工作效率。然而，现有的 AI 编码助手往往缺乏足够的技能和能力，无法满足我们的需求。因此，ConardLi/garden-skills 这个项目就诞生了，旨在为 AI 编码助手提供一个丰富的技能库，帮助开发者提高工作效率。

## 核心拆解
ConardLi/garden-skills 提供了四个核心技能：
1. **web-video-presentation**：这个技能可以帮助你快速创建一个视频演示，使用 Vite、React 和 TypeScript。你可以使用这个技能来创建一个视频教程或是一场视频会议。
2. **web-design-engineer**：这个技能可以帮助你将 AI 编码助手作为一个前端设计师，强制执行设计系统和反模式 UI 块。你可以使用这个技能来创建一个美观的 UI。
3. **gpt-image-2**：这个技能可以帮助你生成图像和提示工程，支持本地、主机和顾问模式。你可以使用这个技能来创建一个图像或是一张海报。
4. **kb-retriever**：这个技能可以帮助你在本地知识库中检索信息，使用层次搜索来查找 PDF 和 Excel 文件。你可以使用这个技能来查找特定的信息。

## 实操指南
要使用 ConardLi/garden-skills，你需要按照以下步骤：
1. 安装 `npx skills add` 或者从 Claude Code 市场下载安装包。
2. 解压安装包并按照提示配置环境。
3. 在你的项目中导入相应的技能模块。
4. 使用相应的 API 调用技能。

```bash
# 安装
npx skills add

# 导入技能模块
import { webVideoPresentation } from 'garden-skills';

# 调用技能
const presentation = webVideoPresentation({
  title: '我的视频演示',
  content: '这是我的视频演示内容',
});
```
