## 0. 开启 AI 编程的“全自动驾驶”时代

### 📌 项目是什么？
**jcode** 是一个开源的代码生成智能体底座（Harness）。它不是一个简单的编辑器插件，而是一个让大语言模型（LLM）能够安全、高效地与你本地文件系统、终端和编译器进行深度交互的桥梁。它为 AI 程序员提供了一个“实体身躯”。

### ❓ 为什么会有这个项目？
因为“对话式编程”的效率已经到达瓶颈了。如果你还停留在手动复制 AI 代码的阶段，那你就落伍了。jcode 的诞生是为了解决 AI 无法自主执行复杂开发链条的问题。它让 AI 能够在一个闭环的环境里：写码、运行、报错、修 Bug，直到交付完全正确的结果。

### 🛠️ 怎么样运行运用项目？
1. **安装驱动**：通过 `pip install jcode-harness` 将核心引擎装进你的电脑。
2. **连接大脑**：在配置中挂载你的 LLM 密钥。
3. **极速发车**：直接在命令行输入 `jcode "重构当前的数据库模型为异步模式"`。jcode 会立即接管终端，自动读取文件、修改代码并运行测试，你只需要坐在椅子上看进度条。

## 1. 痛点：我们还在用“手动挡”模式玩 AI

目前的 AI 编程现状：
你给 AI 提个需求 -> 它吐出一堆 Markdown -> 你点复制 -> 回到 IDE -> 贴上去 -> 发现缺个包 -> 回去骂 AI -> 如此循环。

**这叫“人力外包”，不叫“自动化”。**
真正的自动化，应该是你只负责踩下“需求”这个油门，剩下的文件读取、代码重构、依赖安装、错误修复，全由底盘自动完成。**jcode** 就是那个高性能底盘。

通过 jcode，AI 不再只是在黑盒里算概率，它是在一个真实的、可观测的开发环境里进行“感知-行动-再感知”。

## 3. 手把手操作：给你的 AI 挂上“自动挡”

### Step 1：安装自动化底座
你需要安装 jcode 的核心驱动：
```bash
pip install jcode-harness
```

### Step 2：配置你的“动力总成”
在配置文件里接入你的模型 API（推荐使用响应极快的 1B/3B 模型做预处理，大模型做核心逻辑）。

### Step 3：一键发车
直接输入自然语言指令：
```bash
jcode "帮我把这个 Flask 项目改成 FastAPI，并加上 JWT 鉴权，最后跑通所有接口测试。"
```
**看好了，接下来是全自动时间。** 
它会自己遍历文件结构，自己安装新的依赖包，遇到报错自己看日志修复，直到所有测试绿灯通过。
