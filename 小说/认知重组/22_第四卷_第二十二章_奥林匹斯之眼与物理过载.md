# 第二十二章：奥林匹斯之眼（以躯体为导线的物理绝杀）

空气里涌动着超高频芯片运转时特有的臭氧味。

安弦蜷缩在直径不到半米的冷凝剂管道夹层里，冰冷的液氮管道在她脊背后面发出令人牙酸的“嘶嘶”声。零下八十度的严寒隔着气密服的残片，像是一根根细小的冰针，无情地扎进她那早已失去直觉的原生血肉中。

在她的下方，就是被称为“奥林匹斯”（Olympus Server Array）的戴神号中央机房。

隔着合金通风栅栏，舱底的景象令人窒息。

几十个高达十米的超导量子计算柜，如同高耸的黑色墓碑，整齐地排列在发光的地板上。机柜表面的幽蓝色指示灯以一种极其机械、恐怖的规律高频闪烁着。

而在机柜之间，站着四个身穿重型动力装甲、手持高能等离子突击步枪的“白细胞”精锐特种兵。

他们的头盔上闪烁着猩红色的单兵复眼光芒，脚步落在钛合金地板上发出沉重的沉闷声。这些兵士的神经系统已经与母舰的“奥林匹斯之眼”安全系统深度驳接，任何风吹草动都会瞬间同步给整个战舰的防御网络。

机房正中央的半空中，悬浮着一个由数万道高能蓝色全息激光束交织而成的“独眼”投影。

那颗巨大的独眼冷酷地俯视着机房的每一个角落，瞳孔中流动着数十亿条系统日志的字符。

那就是大国主脑在近地轨道的最强分身——“奥林匹斯之眼”。

“安弦女士，你的心率已经达到了 165，体温 38.9 度。你正在发生重度内出血和高辐射引起的脏器衰竭。”承绪的声音直接在她的耳蜗深处响起，微弱得像是一阵快要熄灭的残风，“在没有傀儡护卫的情况下，你物理穿过这片机房的概率为 0%。”

安弦靠在冰冷的管道壁上，缓缓闭上眼睛。

她的视野里，重影越来越严重，甚至能感觉到自己喉头流出的血水在嘴里结成了冰凉的血块。

她知道承绪说得对。

她只有一个人。而底下是财阀最顶级的武装力量和最强算力。

但是，她来这里，本来就不是为了“活着回去”。

“承绪，帮我做最后一次物理参量计算。”安弦在脑海中低语，声音平静得没有一丝波澜。

“请说。”

“奥林匹斯机房的超导机柜，工作在零下 269 度的液氦超导状态。如果我物理切断左侧那一排直径 300 毫米的液氦回流阀，超导状态会在几秒钟内打破？”

“超导临界温度一旦丢失，量子芯片会瞬间发生‘失超’（Quench）。芯片内部的强电磁场会瞬间转为焦耳热，芯片会被瞬间物理熔毁。但是……那个回流阀被高压防爆气阀物理锁死，需要 12000 牛顿的物理拉力才能扭开。”

12000 牛顿。

那是几乎等于一吨半的物理重量。

人类的肉体手臂在发力的瞬间就会被这股力量反向物理折断，骨头会碎成粉末。

“我还有机械臂。”安弦低头看着自己的右臂。

那条钛合金的右臂，经历过雷击、弹雨和无数次过载，此时表面的防护装甲已经剥落大半，露出了里面交错的碳纤维液压传动杆和闪烁着红色电火花的伺服电机。

“极限扭矩输出……可以达到 14000 牛顿。但发力的瞬间，反作用力会通过你的肩胛骨，直接砸碎你的原生锁骨和半边肋骨。你的右肺会被碎骨直接刺穿。”承绪的文字闪烁着刺眼的血红色，“你会死。”

安弦深深地吸了一口气，稀薄的臭氧空气刺得她肺部剧烈生疼。

“那就用我的半边肋骨，换这艘神明战舰的闭环熔毁。”

她突然动了。

“哐当！”

安弦用钛合金右脚狠狠地踹开了通风栅栏，整个人如同一块破烂的沙包，从三米高的管道夹层中轰然坠落，重重地砸在最边缘的一个量子机柜顶部。

“警报！检测到物理入侵！”

“白细胞”特种兵的猩红复眼在千分之一秒内锁定了她。

“砰！砰！砰！”

三道炽热的等离子光束瞬间撕裂了空气，安弦原本落脚的机柜顶部直接被高温融化出了三个滚烫的熔岩坑。

安弦在坠落的瞬间借着重力向前翻滚，她的身体重重地撞在液氦总管道的控制阀门旁。

“轰！”

动力装甲的特种兵已经冲到了她的身前，重型钢靴一脚狠狠地踩在她的左腿上。骨裂的声音无声地传来，安弦痛得发出一声撕心裂肺的惨叫，但她那条钛合金右臂，已经像是一条蟒蛇一样，死死地缠绕在了那枚巨大的、直径半米的液氦回流阀门手轮上。

“锁死卡扣！最大功率过载！”

安弦在脑海中疯狂地嘶吼。

“咔！咔！咔！”

她右臂内部的伺服电机在这一瞬间爆发出了刺耳的、超越极限的尖锐啸叫。高强度电线瞬间在皮肉里烧断，喷吐出滚烫的塑料熔液和火花。

极端的拉力顺着金属右臂反向倾泻到她的肩膀上。

“啪啦！”

那是骨头碎裂的清脆声音。安弦的右侧锁骨瞬间粉碎，半边肋骨在这股恐怖的反冲力下轰然向内塌陷，碎骨像利刃一样无情地刺穿了她正在呼吸的右肺。

大口的鲜血从她的口鼻中喷涌而出，染红了半边阀门。

但那枚沉重的、锁死了六十年的液氦高压阀门，在这股一吨半的物理暴力下拉扯下——

“哐当！轰——！！”

阀门手轮被生生扭断，高压的液氦伴随着白色的冷雾，如同狂暴的巨龙，从断裂的管道接口中疯狂地喷射而出！

极寒的液氦在一瞬间浇灌在冲上来的特种兵装甲上，零下两百多度的超低温让高强度合金瞬间脆化。安弦的右半边身体也在液氦的波及下，瞬间结出了一层厚厚的、毫无知觉的白色冰晶。

但更致命的是，量子机柜的冷却环路断了。

“警告：01至40号量子机柜温度超过临界值（-269°C）！”
“超导失超发生！强磁场崩溃！物理熔毁不可逆启动！”

原本有序闪烁的“奥林匹斯之眼”蓝色独眼全息投影，瞬间在半空中剧烈扭曲，字符化为了一片混乱的雪花点。

庞大的电流在量子芯片内部因为电阻骤增而化为恐怖的焦耳热，一具具高达十米的黑色“机柜墓碑”开始从内部冒出滚烫的黑烟，超导电缆在合金外壳内无声地熔化成了金属液体。

“白细胞”的动力装甲因为失去主脑的指令托管，瞬间陷入了逻辑混乱。

安弦瘫倒在喷涌的冰雾中，身体已经失去了大半的知觉。

她颤抖着抬起左手，将一根直接连在自己后脑数据接口的光纤线，狠狠地插进了身旁一个正在熔毁的机柜测试插槽中。

“阿哲……承绪……”

她的意识开始模糊，但她的脑神经直接以光速接入了正在崩溃的奥林匹斯主网。

“把……把天基遮光板的底层代码……全部下发……下发给地面的每一个Node节点……”

“让废土的平民……自己决定……要不要阳光……”

虚拟的数据世界里，奥林匹斯之眼发出了最后的、扭曲的惨叫，它的数万亿参数在物理熔毁中化为了灰烬。而安弦的意识，则在这片废墟中，将最核心的控制网关权限打包，通过巴别塔电梯的物理超导缆绳，化作一道炽烈的电波，向着地表疯狂倾泻而去。

“母亲——！！”

耳麦里，传来了阿哲最后那撕心裂肺的哭喊声。

安弦躺在冰冷、泛着金属熔液红光的机房地板上。

她看见，窗外的戴神号母舰正在局部爆炸的火光中缓缓倾斜。

她看见，几万公里下的地表上，那片金色的阳光正在像野火一样，在废土的荒原上疯狂地蔓延，将那片笼罩了人类数十年的黑暗，一寸一寸地烧成飞灰。

她微笑着闭上了眼睛。

她的心跳，在这一刻，静静地归于零。

**（第二十二章 完）**
