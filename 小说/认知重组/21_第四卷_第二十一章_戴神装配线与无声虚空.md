# 第二十一章：戴神装配线（真空中的无声跃迁）

声音消失了。

当最后一层加压气闸舱内的空气被抽干时，整个世界陷入了绝对的死寂。

安弦身上的厚重气密服紧紧贴着她那满是伤痕的皮肤。她的头盔面罩被一层反射着金光的防辐射图层所覆盖，只能听到自己急促而沉重的呼吸声，以及头盔内部冷却风扇那单调的“嗡嗡”震动。

这是太空的物理法则：没有空气，就没有声波的介质。

一切爆炸、碎裂、以及高能焊接产生的等离子火花，都在这片漆黑的真空中变成了默片。

她转过头，看向身边的一号傀儡。

在真空的强辐射照耀下，傀儡那破损的外壳呈现出一种近乎白炽的金属反光。它唯一的右臂扣在一根高强度的钢索扣环上，体内的液压系统因为没有大气散热，温度迅速攀升。安弦的视网膜投影上，傀儡的核心温度指示灯正闪烁着刺眼的明黄色警报。

而在她们的前方，是横亘了整片视野的巨无霸——**“戴神号”天基母舰的外装配线**。

这艘长达八公里的星际母舰，就像是一条被无数根白色装配网架和输能管道死死缚在轨道上的黑色巨蟒。外装配线上的无数巨型自动吊装机、轨道滑车正在无声地运行。

巨大的钢板、集束激光炮塔、超导电池阵列，在真空中像羽毛一样轻盈地被机械臂吊起，随后无声地焊接到母舰庞大的腹部装配槽中。

“戴神号的外围装配线由‘阿尔法-9’工业主控芯片接管，它没有视觉，但装配线网架上布置了高密度的物理微波探测格栅。”承绪的文字直接被转译成电流，刺激着安弦耳后的听骨，听上去像是带着金属杂音的耳语，“只要任何非登记的质量穿过格栅，就会立刻触发自动阻拦射击。我们唯一的渗透路径，是利用它们装配大型零件时的‘影子’。”

“影子？”

“是的，那些长达数十米的超导装配钢板。在它们被吊装到母舰底座的五秒钟时间里，吊装机械臂会物理遮挡微波格栅的扫描扇区。我们需要在那五秒钟内，进行无声的物理越迁。”

安弦低头看了看下方的深渊。

在她们脚下几万公里的下方，地球那巨大的蔚蓝色弧线正散发着柔和的光芒，云海缓慢地翻滚。

只要在这里发生一次失误，失去磁力鞋的吸附，她们就会以第一宇宙速度脱离轨道，成为一颗在重力井边缘永远坠落的太空人体卫星，直到在对流层的摩擦中化为一缕青烟。

“准备。”

安弦将两根长达十五米的凯夫拉物理钢索，一端卡死在自己的钛合金机械右臂上，另一端扣死在一号傀儡的背部主骨架上。

她解开了脚部的磁力锁鞋。

重力彻底消失了，安弦和傀儡像是两粒微小的尘埃，在真空中微微漂浮起来。

“第一块装配钢板开始移动。”承绪在她的视网膜投影上拉出了红色的倒计时。

视窗中，一条长达五十米的超大超导装配钢板，正被一台高达百米的巨型机械臂无声地抓取，顺着外装配线的导轨，滑向戴神号底部的武器舱装配口。

钢板在移动的瞬间，物理遮挡住了微波探测器的扇形信号。

“倒计时：3，2，1……物理跃迁！”

安弦没有任何犹豫，她大腿的液压喷射外设发出一声无声的过载。

一缕极细的高压氮气从她腰部的推进背包中喷射而出，在真空中形成了一道瞬间冻结的白色冰晶轨迹。反冲推力带着她的身体，像是一颗无声的子弹，笔直地飞向半空中那块缓缓移动的巨型钢板。

一号傀儡紧随其后。它的右腿液压缸直接爆开了一圈白色的冷喷雾，利用残存的最后一丝动力，拉扯着钢索向钢板飞跃。

风在真空中不存在，但高能宇宙辐射和太阳风的物理偏照，让安弦的体表温度在几秒钟内剧烈波动了上百度。

“砰。”

一声低沉的物理震动顺着她的手套和骨骼传导到她的耳中。

安弦的金属手套精准地抓住了巨型钢板边缘的一根吊装挂钩。巨大的惯性带着她的身体在真空中狠狠地甩动了半圈，她的机械右臂液压关节发出一声刺耳的过载呻吟，死死地扣住了边缘。

紧接着，一号傀儡也重重地砸在钢板的另一侧，磁力鞋在钢板表面擦出了一大片无声的火花。

“影子遮挡剩余时间：2.1秒。”承绪的红色警报不断闪烁。

吊装机械臂已经完成了对钢板的推送，微波探测格栅的扫描光束即将重新扫过这片区域。

“进舱口就在钢板内侧的武器装配滑道！”

安弦拉着钢索，手脚并用地在光滑的装配钢板表面爬行。失重的环境下，任何一次发力如果不配合磁力吸附，都会导致身体向太空飘飞。

她像是一只壁虎，指尖的钛合金片直接物理插进了钢板的拼缝中，强行将自己向前拖拽。

“0.8秒。”

一号傀儡在这一瞬间做出了令人窒息的判断。它发现以安弦目前的负伤状态，根本无法在格栅恢复前爬进滑道。

傀儡那残破的躯体突然放弃了所有的磁力吸附。

它唯一的机械右臂猛地伸出，按在安弦的推进背包上，随后，体内的辅助电容器发出了毁灭性的过载啸叫。

“嗡——！”

傀儡体内残存的所有冷喷气体，在同一毫秒内以超极限的压力喷射而出。

反冲力在一瞬间将安弦的身体物理“推”进了戴神号武器舱的滑道入口。

而那股巨大的反作用力，则将一号傀儡的残破躯体，狠狠地推向了钢板的另一侧——正对微波格栅的无遮挡区域。

“警告：检测到非法质量入侵 02 号格栅区。”

冰冷的系统提示虽然没有声音，但外装配网架上，四门自动激光防卫炮塔瞬间以一种近乎疯狂的速度调转了炮口。

“嗤！嗤！嗤！”

三道耀眼夺目的蓝色激光束，在真空中无声地划过。

强光将整片外装配线照得雪白。

激光瞬间穿透了一号傀儡的胸口、头颅和主供电模块。它体内残存的电池和电容器在高温下瞬间膨胀，随后在真空的低压中，发生了一场无声的、壮烈的物理爆炸。

一团蓝白色的电弧和无数金属废渣，在真空中无声地扩散开来，像是一朵在群星背景下短暂绽放的烟花。

它为安弦争取了最后的一秒钟。

“砰！”

安弦重重地滚进了戴神号武器舱的封闭滑道内侧。

她身后的重型电磁闸门在微波格栅报警的下一刻物理锁死，彻底将太空的真空和那一团渐渐飘散的爆炸残骸隔绝在外面。

舱门内，气压阀开始重新工作。

“嗤——”

温暖的空气开始重新灌入狭窄的滑道舱内，重力平衡系统也恢复到了舒适的 0.8G。

安弦狼狈地摔在金属地板上，头盔面罩上的金色镀层倒映着舱内闪烁的红色报警灯光。

她扯下头盔，剧烈地咳嗽起来，眼泪和血水混在一起，滴在冰冷的金属甲板上。

“一号……彻底离线。”承绪的文字慢慢在视网膜上淡去。

十一台远征的无头傀儡。
在穿越核废土、攀登太空电梯、渗透第一中继站、跨越重力船坞、以及这最后的真空跃迁后。

全军覆没。

此时此刻，在这艘长达八公里的天基巨兽“戴神号”的庞大内腹中，只剩下了安弦一个人。

她是一个伤痕累累、原生器官大面积受损、没有武器支持的废土人类。

但她已经进来了。

她扶着武器舱内壁的钢铁管线，吃力地站直了身体。她的眼底深处，那抹由承绪注入的物理十六进制代码，正如同幽火般燃烧。

“承绪，我们现在在哪里？”

“我们在戴神号的‘冷凝剂输送管道层’。再往前，就是戴神号的中央主控机房——‘奥林匹斯’（Olympus Server Array）。”

“主控机房的防御是什么？”

“大国主脑的次级意识体直接托管了这里。它在虚拟空间里拥有几千亿的参数，而在物理空间，这里驻扎了整整一个排的‘白细胞’精锐机械化特种兵。”

安弦低头看了看自己那条布满划痕、电线外露的钛合金机械右臂。

她握紧了拳头。

“那就用我们最擅长的方式。”她的声音在重新恢复了大气的滑道里，回荡着一股刺骨的冰冷，“去黑掉神明的主脑。”

**（第二十一章 完）**
