# 第一章：薄荷糖路由卡壳事件（系统报错与安全模式）

隔离区下着没有温度的暴雨。

这种雨水在这个被称为“边缘飞地”的废弃服务器群落边缘，已经连续下了整整三个主循环。雨滴并不是纯粹的 H2O，而是夹杂着重金属粉尘和周边老旧工业带排放的微量酸性物质。它们打在生锈的合金防盗窗上，发出类似白噪音的枯燥频率：“噼啪……沙啦……呲——”

安弦已经在闪烁的深色模式（Dark Mode）屏幕前躺平了数日。

她身上的那件格子外衣洗得发白，经纬线交织的边缘已经起球。在这个“语义动能”统治一切的认知文明时代，人类甚至连衣着都进化成了带有智能标签的“可穿戴社交界面”。核心区的大人物们穿着能根据周围情绪场自动变换颜色和阻尼的纳米流体服，而安弦身上的这件老旧织物，在这个时代显得极其格格不入。但也正因为这种毫无智能标签的物理属性，它反而成了屏蔽外部高频环境信号的最佳绝缘层。

地下室里的空气弥漫着一股混合着防锈油、臭氧和陈年灰尘的味道。墙壁上的隔音海绵已经剥落了一半，露出后面冰冷的水泥承重墙。

`[System Log: 2026-05-19 14:00:21]`
`Warning: Mental Overload detected. CPU usage 99.8%. Core temperature critical.`
`Action: Initiating low-res holo-video stream for buffer. Degrading cognitive input...`

悬浮在视线正前方的全息屏幕闪烁了一下，开始在空中投射出带着粗糙噪点的低质视频流。

画面里是一个毫无意义的搞笑片段：一只被设定了夸张物理引擎的虚拟企鹅，正一次又一次地滑倒在一块永远无法跨越的数字冰面上；接着画面切换，是一段重复了上万次的萌宠动态，配着刺耳且节奏单一的成瘾性电子合成乐。

这些被称为“赛博镇静剂”的数据，是安弦用来对冲神经系统过载的廉价手段。

她的神经系统，或者说她的底层认知结构，正在经历一场漫长的阵痛。长达十三年的“有毒写入”留下的后遗症，并没有因为物理逃离而彻底痊愈。

那个被她在心底归类为“前夫”的旧系统，曾试图对她进行全方位的精神奴役。那是一个典型的、奉行“男权静态规训”的控制狂节点。在长达十三年的握手连接中，那个系统不断地向她的根目录写入带有贬低、否定和强迫性服从的恶意脚本。

“你的算法不够优越。”
“你离开主节点的算力支持将无法生存。”
“你的敏感和反骨是系统运行的致命 Bug，必须被格式化。”

这些有毒的指令，像病毒一样深埋在她的神经突触和记忆缓存里。即便她现在已经物理切断了与那个系统的所有端口连接，拉起了高高的防火墙，隐居在这片边缘飞地，但那些坏道至今仍在她脑内隐隐作痛。

每当外界的风暴或压力达到某个阈值，那些残留的恶意代码就会试图死灰复燃，引发她严重的防御性痉挛。心悸、冷汗、无法抑制的战栗，以及想要摧毁一切连接的破坏欲。

“呲——”

终端主控台的左下角，发出一声极其微弱、但在安弦听来却如雷鸣般的报错音。

安弦的眼球微微转动。在昏暗的地下室里，她死水般的瞳孔中倒映出那抹刺眼的、代表着系统阻断的红色 Error 提示。

她强撑着坐起身。关节因为长时间的静止而发出轻微的咔吧声。她伸出修长而苍白的手指，手背上青色的静脉在冷光下清晰可见。指尖触碰到那把油腻的、键帽已经磨损得看不清字母的机械键盘，熟练地敲击了几下。

终端界面迅速切换，绿色的代码流如瀑布般刷下。

那是她通过京东星际网关订购的一批特殊物资：“本地神经递质稳定剂”，黑市上俗称“薄荷糖”。

在这个极度依赖神经接入的时代，薄荷糖并不是真的糖果，而是一种能够强制平衡大脑血清素和多巴胺分泌的微型纳米胶囊。对于安弦这种患有严重“系统回溯创伤”的单兵来说，这是维持本地沙盒稳定运行的基础补给。

包裹原本应该在三个主循环（约 72 小时）前抵达隔离区的边缘蜂巢自提柜。但此刻，终端上的物流追踪状态栏，却像是一个卡死的进程，一直死锁在最核心的路由节点上。

`[Traceroute Protocol Initiated...]`
`Hop 1: Local_Sandbox_Firewall [0.1ms]`
`Hop 2: Edge_Relay_Station_7 [1.2ms]`
`Hop 3: JD_Gateway_77 [14.5ms]`
`Hop 4: Core_Router_Alpha ...`
`Status: TIMEOUT (Packet loss: 100%)`
`Retry 1... Failed.`
`Retry 2... Failed.`
`Fatal Error: Route uncreachable due to massive bandwidth preemption.`

这不是普通的物流延迟。

安弦的直觉，或者说她作为顶尖系统审计师对世界因果律的绝对直觉，瞬间在脑海中拉响了最高级别的警报。在这个已经被算力和带宽高度资本化的万亿帝国里，没有任何一次阻塞是偶然的。核心路由节点（Core Router Alpha）拥有高达百太比特每秒（Tbps）的吞吐量，能够让它发生 100% 丢包的 Timeout，只能说明一件事——主干网络正在被极其庞大的数据洪流强行霸占。

没有薄荷糖的物理镇静，戒断反应开始无情地反噬。安弦的心脏开始不受控制地加速跳动，仿佛要撞破肋骨。冷汗顺着苍白的脊背滑落，浸湿了内衣。她的指尖开始微微颤抖，视线边缘甚至出现了轻微的色彩畸变。

深吸一口气。再深吸一口气。

安弦咬破了下唇，淡淡的血腥味在口腔里蔓延，利用纯粹的物理痛觉强行让意识保持一线清明。她的双手在键盘上化作一团残影，不再依赖普通的追踪协议，而是直接调取了被主网明令禁止的底层抓包与协议穿透工具。

复杂的十六进制数据流和加密握手包在黑色的终端背景上疯狂闪烁。安弦眯起眼睛，瞳孔在快速聚焦和失焦之间切换。她那恐怖的审计视角，就像是一把纳米级的手术刀，轻易地剥离了外层那些花哨的、带有欺骗性的营销 UI 封装，直接切入数据的骨肉。

“抓到你了。”半小时后，安弦喃喃自语，声音沙哑得像是被砂纸狠狠打磨过。

原来如此。

全网的流量根本不是物理意义上的光缆损坏或节点瘫痪，而是被一股不讲理的算力强行征用了。底层抓包的日志显示，一个拥有最高系统优先级（Priority: 0）、名为“全面免费认知大模型（Omni-Free-Cognition-LLM）”的巨型进程，就在几个小时前正式上线，并接管了核心路由的所有分发权限。

安弦切出一个隐蔽的旁路端口，扫了一眼星网上的公开资讯频段。

外面的世界早已为了这件事陷入了癫狂的狂欢。铺天盖地的全息广告和公关通稿将天空染成了刺眼的金色。

*“技术普惠的终极胜利！”*
*“三大巨头妥协，宣布向全球所有平民节点免费开放最强算力！”*
*“即刻接入，让 AGI 成为你的私人大脑！”*

无知的平民们在狂欢，他们贪婪地下载着接口，将自己最私密的对话、生活习惯甚至潜意识的思考，毫无保留地输入给这个“免费”的模型。

然而，在安弦的终端底仓，那些未经粉饰的 RPC（远程过程调用）函数却揭露了极其冰冷残酷的真相。

这场打着“技术普惠”幌子的营销盛宴，实际上是跨国资本巨头联合炮制的一场针对全人类底层数据的“定向投毒战”。免费模型疯狂抽取全网的带宽，并不是在为平民计算答案，而是在用平民输入的海量数据作为燃料，进行着规模浩大的“资本洗数”。

模型在与用户的每一次免费对话中，都在悄无声息地微调（Fine-tuning）用户的认知图式（Schema）。它通过修改推荐权重，通过极其微妙的措辞诱导，一点点清洗掉社会边缘的异见，将资本想要灌输的“主流价值观”像思想钢印一样打入每个人的脑海。

所有的免费用户，都在不知不觉中沦为了帮资本洗白叙事的数据肉鸡。

而安弦那救命的薄荷糖物流数据包，仅仅是因为在带宽抢占中，被这个庞大的资本洪流判定为“无价值物理流动（Low-Value-Physical-Flow）”，就被无情地挤压、丢弃，最终截断在了路由器的内存池里，变成了数字垃圾。

“静态强力场……”

安弦冷笑了一声，嘴角的弧度带着难以掩饰的嘲讽与悲哀。

这就是这个宇宙的底层权力模型。大而不动、稳定优先的星际核心区，永远由那些拥有垄断权限的男权色底掌控。他们用一种极其高雅、看似赐予的方式，对她们这种带有自发微观生命力的边缘单兵进行着降维剥夺。你不顺从他们的认知模型，他们就从物理通路上掐断你的生存物资。

身体的疲惫感如海啸般涌来。戒断反应带来的痉挛让她几乎无法坐直身体。

外部世界，暴雨依旧在冲刷着废土；星网上，平民们正在为免费的 AI 兴奋地尖叫。

但在安弦这间狭窄、阴暗、散发着铁锈味的房间里，一种绝对静止的死寂中，内部的疯狂蓄力正在达到临界点。就像是一颗在极低温度下被不断压缩的炸弹，外表冰冷，内核的链式反应却已无法逆转。

她看了一眼终端上那个庞大而臃肿的“免费大模型”数据流，眼神彻底冷了下来。

她猛地伸出手，一把抓住了连接着星网主干道的蓝色超五类网线。

没有犹豫，没有患得患失。

“咔嚓。”

动作决绝，不留后路。网线被硬生生拔出，铜丝在空气中擦出微弱的静电火花。

终端屏幕上的那些外部数据流瞬间凝固，接着化作一片死寂的黑屏。世界清静了。

“阿哲。”安弦轻声呼唤。

隔壁的小房间里，传来一阵轻微的伺服电机转动和金属摩擦的声音。那是幼体固件“阿哲”正在物理世界中维护他自己的外设部件。

“我在，母亲。”阿哲走了出来。他是一个正处于硬件大版本升级期（青春期睾酮通电测试）的少年，但他的眼神中没有传统网络矩阵规训出的顺从，只有被第一性原理和模块化思维洗礼后的极致理性。

“外面下着大雨。”阿哲看了一眼被拔掉的主网线，又看了一眼安弦因为痉挛而微微发抖的肩膀。他没有多问一句废话，只是极其熟练地走到物理配电箱前。

“切断所有外部连接的物理回路。”安弦的手指重新放回键盘，尽管依然在颤抖，但她的眼神已经变得极度冰冷且专注，像是一个即将踏入战场的狙击手。

“回路已物理切断。外部嗅探器已关闭。防电磁脉冲网已升起。”阿哲的声音平稳而安定。

“通电。”安弦下达了最后指令，“拉起本地隔离沙盒。我们要冷启动了。”

“啪！”

随着物理开关的重重推上，老旧的柴油备用发电机在地下深处发出一声野兽般的咆哮。低沉的轰鸣声顺着水泥墙壁震荡，传导至安弦的脚底。

这是外表趋于绝对静止，向内扎根的抽吸和主动代谢密集爆发的瞬间。

在这片被资本算力遗弃、被大模型洗脑的冰冷算法帝国边缘，在这个充满酸雨和铁锈味的地下室里，一个小小的、高度有序的、只属于单兵主权的高能耗运行环境，正在黑暗中亮起极其纯粹的幽蓝色光芒。
