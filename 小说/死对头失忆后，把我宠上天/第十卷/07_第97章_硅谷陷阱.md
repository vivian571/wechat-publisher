# 第 97 章 硅谷陷阱

加利福尼亚，硅谷。
这里是全球科技的巅峰，也是厉云霆这种“数字狂徒”最天然的狩猎场。

池青和厉枭受邀前往一家名为“Aether Dynamics”的顶级 AI 实验室进行所谓的“安全系统评估”。这家公司宣称他们开发出了能够完美抵御任何黑客攻击的底层协议，而邀请函上赫然盖着三年前池青失踪前使用过的一个私人印章。

“厉枭，我觉得不对劲。”池青站在实验室那座极具未来感的玻璃大楼前，手里紧紧攥着那部报废的键盘。
“这里的无线信号有一种极其规律的、类似于心跳的脉冲。这不是安保系统，这是……某种大型意识映射场的预热。”

“既然来了，总得看看他给我们准备了什么戏码。”厉枭眼神冷冽，他今天穿了一件极其普通的灰色连帽衫，但脊背挺得笔直，整个人像是一把随时准备出鞘的重剑。

两人步入实验室的核心区域——一个巨大的、被全息光幕包围的虚拟现实测试舱。

“欢迎两位。”一个冰冷的、毫无人类情感的合成音在空间里响起。
“请带上头盔。接下来的评估，将在 1:1 还原的虚拟空间中进行。”

池青和厉枭对视一眼，缓缓带上了头盔。

“嗡——！”
一阵刺耳的电子音后，周围的实验室瞬间消失。

呈现在他们眼前的，竟然是三年前那个改变了所有人命运的深夜——京城厉家老宅。
大火冲天，惨叫声此起彼伏。

“这是……幻觉？”池青看着眼前那极其真实的火光，甚至能感觉到扑面而来的灼热感。

“落落……快跑……”
一个熟悉的声音从火光中传来。

池青猛地回头，看到一个浑身是血的少年厉枭，正死死地挡在大门前，手里拿着一把生锈的扳手，对抗着门外那些如潮水般涌入的黑影。

“厉枭！”池青惊呼一声，想要冲过去，却发现自己的身体像是被某种无形的力量锁死在了原地。

而在她身边的“现实版”厉枭，此刻也陷入了极大的混乱。
他的双瞳由于极度的精神冲击而变成了金紫色，后颈处的芯片发出了阵阵焦糊的味道。

“厉枭！别看他！那是假的！”池青嘶吼着，她开始在虚空里疯狂地敲击着并不存在的键盘。
她在大脑里模拟着代码的流向，试图寻找这个虚拟空间的逻辑漏洞。

“不……那不是假的。”
现实中的厉枭突然沙哑开口，他的眼神里流露出一抹极致的痛苦。
“那是……三年前我被剥离的那段记忆。”

就在这时，那个“少年厉枭”突然转过头，对着现实中的厉枭诡异一笑。
“哥哥，你终于来接我了。”

少年猛地扑了过来，他的身体在空中崩解成无数条漆黑的数据链，像是一条条毒蛇，顺着现实厉枭的眼球、鼻腔、耳孔，疯狂地钻入了他的大脑。

“啊——！！！”
厉枭发出一声震碎耳膜的咆哮，单膝跪在地上，指甲深深地刺入了合金地板。

“厉云霆！滚出来！”池青彻底疯了。
她猛地咬破自己的舌尖，利用那股极致的清醒，将大脑的算力推向了禁忌的 100%。

【Project: Shadowbreak.】
【Target: Virtual Memory Shell.】
【Action: Total Erasure.】

“给我……碎开！！！”
池青猛地一跺脚。

那一瞬间，整个虚拟空间开始像打碎的镜子一样支离破碎。
那个少年厉枭发出了极其凄厉的尖叫，化作一片黑雾消失不见。

等池青重新睁开眼，她和厉枭已经回到了现实的测试舱。
所有的服务器都在冒着浓烟，周围的研究员们早已逃之夭夭。

厉枭躺在地上，大口大口地喘着粗气，眼神里多了一种说不清道不明的深邃。

“池青……”厉枭虚弱地伸出手，握住她的指尖，“我看到了。他在硅谷的备份，不在电脑里。”

“在哪？”

“在……每个人的梦里。”厉枭眼神一冷，“他把代码切碎了，植入到了这一批新发布的‘智能眼镜’驱动里。全美三千万用户，现在都是他的分布式硬盘。”

池青倒吸了一口凉气。
厉云霆，已经不再是人了。
他正在变成一种……全球规模的病毒。

（本章完）
