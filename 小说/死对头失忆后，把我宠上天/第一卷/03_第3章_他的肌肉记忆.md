# 第3章 他的肌肉记忆

城郊，废弃的工业区。
迈巴赫在雨中滑行，最终停在一个外表破败的厂房前。这里是池青众多安全屋中的一个，表面是个废弃仓库，实则地下有着世界上最顶尖的反侦察安保系统。

“下车。”池青熄火，语气冷淡。

厉枭解开安全带，推门下车。
高大的身躯在夜雨中更显修长挺拔，白衬衫上的血迹已经被雨水冲刷得有些发白，但他却像感觉不到疼痛一般，步伐稳健地跟在池青身后。

池青走到一扇生锈的铁门前，输入了一串极其复杂的六十四位动态密码。
厚重的金属门无声滑开，露出里面极具科技感的冷色调地下空间。

“进去左拐，洗手间在尽头，里面有医药箱。”池青把伞随手扔在一旁，“把自己弄干净。”

厉枭没动，他站在玄关处，目光像扫描仪一样环顾着四周。
到处都是巨大的服务器机柜、闪烁的指示灯，还有主控台上那三台相连的超大曲面屏。空气中没有一丝灰尘，冷酷得就像是没有温度的机器。

“未婚妻。”他突然开口，声音在这空荡的空间里显得格外低沉。
“你的品味，还挺别致。”

这绝对不是一个正常名媛该待的地方。哪家千金大小姐的安全屋里，装的不是高档珠宝和奢侈品，而是足以攻破五角大楼网络防御的顶级计算集群？

池青脱下湿漉漉的外套，露出里面黑色的紧身背心，勾勒出极度曼妙却充满爆发力的曲线。
她冷眼看着他：“厉先生，你失忆了，但不代表你变蠢了。收起你的好奇心，不该问的别问。”

厉枭看着她背影，眼眸微眯。
那种极其危险、想要靠近甚至征服的冲动再次涌了上来。他没再说话，转身走向洗手间。

池青走到主控台前，手指在键盘上飞速敲击。
屏幕上瞬间调出了方才盘山公路的监控画面。那辆撞毁的越野车已经被大火吞噬，厉家的善后部队显然已经抹平了痕迹。

就在她准备进一步追踪幕后黑手时，刺耳的红灯突然在整个地下室亮起！
【Warning! Intrusion Detected!】（警告！检测到入侵！）

池青脸色一变。
怎么可能？这里的物理防御系统连微型无人机都能击落，怎么会被人悄无声息地摸到了门外？

监控屏幕上切出了地面厂房的画面。
雨幕中，十几道黑影如同鬼魅般包围了厂房。他们全副武装，戴着夜视仪，手中的微冲装配着消音器，行动间没有发出半点声响。
这是世界顶级的雇佣兵团队！

“目标在地下，爆破组准备。”监控里传来雇佣兵队长冰冷的声音。

池青迅速拔出腰间的军刀，另一只手按下了自毁程序的倒计时。
她还没蠢到在这个狭小的地下空间里和十几把微冲硬拼，唯一的办法就是炸毁入口，从备用通道撤离。

“轰！”
沉闷的爆破声传来，第一道防爆门被炸开。

池青刚要转身，一只冰凉的大手突然扣住了她的手腕，将她猛地往后一拽。
池青整个人撞进了一个结实滚烫的胸膛。

是厉枭。
他不知道什么时候出来了，上半身赤裸着，肌肉线条贲张，每一块肌肉都蕴含着爆炸性的力量。他甚至连身上的水都没擦干，腹部的枪伤只是草草缠了一圈绷带，还在往外渗着血。

“别动。”他压低声音，下颌几乎贴在她的耳廓上，嗓音低沉得可怕。

“放手！他们是冲着你来的职业杀手！”池青挣扎了一下，却发现自己根本撼动不了他分毫。
这个男人的力量简直是个怪物。

“冲我来的？”厉枭冷笑了一声，那笑声里带着一种藐视一切的疯狂，“那就让他们有来无回。”

他松开池青的手腕，顺势夺过了她手里的军刀。
下一秒，他如同蛰伏在暗夜里的黑豹，猛地冲了出去。

第一名雇佣兵刚踏入地下室的门槛，甚至还没来得及扣动扳机。
厉枭的身影已经鬼魅般出现在他身侧。
没有花哨的动作，只有极其致命的杀戮效率。军刀在空气中划出一道冰冷的寒光，精准地切开了对方的颈动脉。

鲜血喷涌而出，雇佣兵连惨叫都没发出就倒了下去。

剩下的杀手迅速反应过来，密集的消音枪声瞬间响起。
但厉枭的速度太快了。他在枪林弹雨中穿梭，利用地形和视野盲区，仿佛每一颗子弹的轨迹都在他的计算之中。

夺枪，折腕，扭断脖子。
一套动作行云流水，没有任何多余的停顿。这是纯粹的肌肉记忆，是千百次生死搏杀中烙印在骨子里的本能。

池青站在监控屏幕前，看着画面里那个如同杀神降临的男人。
她自认身手不错，但跟眼前的厉枭比起来，依然有着不可逾越的差距。这个失忆的男人，危险程度远超她的想象。如果他恢复了记忆，自己真的能控制住他吗？

不到两分钟。
地上横七竖八地躺满了雇佣兵的尸体。

厉枭扔掉手里打空了子弹的微冲，随手抹了一把溅在侧脸上的鲜血。
浓重的血腥味在地下室里弥漫。

他转过身，一步步朝池青走来。
昏暗的灯光下，他赤裸的上半身布满了汗水和血迹，犹如从地狱爬出来的修罗，极具视觉冲击力。

池青下意识地后退了半步，手指扣住了腰间备用手枪的扳机。
他现在的状态极不稳定，谁也不知道这头嗜血的野兽会不会突然发狂。

厉枭走到她面前，停住。
他居高临下地看着她，眼底的杀戮戾气还没有完全褪去，黑得惊人。

可就在池青以为他要动手的时候，这个男人却突然低下头，像是一只打完架的大型犬，轻轻把额头抵在了她的肩膀上。

冰凉的触感和血腥味扑面而来。

“未婚妻。”他的声音不再是刚才的杀伐果断，反而透着一丝莫名其妙的委屈和撒娇，“他们弄脏了我的手。”
“还想伤你。”

池青僵在原地，扣在扳机上的手指微微发抖。
疯了。
这个男人，彻底疯了。
