# 第 85 章 倒塌的巨人

京城，厉氏大厦外围。
池青的号召像是一场燎原之火，瞬间席卷了整座城市。

原本眼神空洞的“信徒”们，此刻变成了最疯狂的反叛者。他们用肉身撞击着厚重的电子门，用简易的撬棍拆卸着发光的基站。

“轰——！”
位于西单的一座高达五十米的信号塔，在人群的疯狂拉扯和池青远程释放的“高频脉冲”下，发出一声极其凄厉的金属扭曲声，随后轰然倒塌。

“成了！第一个节点断了！”红毛在频道里疯狂庆祝，但他身后的背景音却全是大威力武器爆炸的轰鸣。

“别高兴太早！”池青的声音由于极度的疲惫而显得有些嘶哑，“厉云霆引爆了信号塔底部的液氮罐，他想用爆炸来阻止人群靠近！”

大屏幕上，另外三座围绕在厉氏大厦周围的巨型卫星塔正处于一种极其不稳定的红闪状态。一旦这些塔全部倒塌且发生爆炸，所产生的连锁反应将直接引爆地下的天然气管道。

到时候，整个京城中心区将不复存在。

“厉枭！听得到吗？！”池青对着耳麦大吼。

“听得到。我还在顶层。”
厉枭的声音在一片嘈杂中显得格外冷静，但池青能听到他剧烈的喘息声。
“厉云霆那个老狐狸想炸楼。”

“不行！你必须立刻下来！”

“跑不掉的。”厉枭站在摇摇欲坠的停机坪边缘，看着不远处正在缓缓倾斜的、那是京城最高的——“北极星”主塔。
“如果主塔砸下来，大厦的承重柱会瞬间崩断。池青，我看到大厦附近的那个塔吊了。你能接管它的权限吗？”

池青瞳孔微缩，瞬间明白了厉枭的意图。
“你要用塔吊去接住那座信号塔？厉枭，你疯了！那是几万吨的钢铁！”

“没让你接住。”厉枭眼神狠戾，“我要你控制塔吊的摇臂，在信号塔倒塌的一瞬间，给它一个反向的推力，让它砸向西侧的厉氏指挥部，而不是大厦本体！”

“给我十秒钟！”
池青猛地低头，指尖在键盘上敲出了一段暴力破解代码。

【Industrial Link: Tower Crane 04.】
【Status: Remote Access Authorized.】

“接管了！”池青大吼，“厉枭，我需要一个物理坐标的引导！我看不清那个塔的倾角！”

“我就是坐标。”
厉枭突然做了一个极其疯狂的动作。
他猛地从顶层跳下，手里抓着一根用来固定的钢索，整个人像是一只在风暴中穿梭的雄鹰，稳稳地落在了那个巨大的塔吊操作台上。

“厉枭！！！”池青的尖叫声撕裂了频道。

“开机！”厉枭忍着浑身骨折般的剧痛，猛地拉动了物理操纵杆。

与此同时，池青的代码精准入场。
塔吊那长达百米的巨大摇臂，在这一刻爆发出了一阵令人牙酸的轰鸣声，它带着千吨之力，在空中划过一道完美的弧线。

“轰隆隆——！”
“北极星”主塔在这一秒彻底断裂。
就在它即将砸向厉氏大厦、将男女主彻底掩埋的那一瞬间，塔吊的摇臂猛地撞击在了塔尖上。

巨大的反作用力让整个大地都颤抖了一下。
信号塔像是一根被击中的保龄球瓶，在空中生生改变了方向，带着漫天的火光和电弧，狠狠地砸进了不远处那栋装满了厉云霆核心武装力量的指挥部。

“轰！！！”
巨大的蘑菇云在京城的中心升起。

厉枭被巨大的冲击波直接掀飞，重重地摔在塔吊的货舱里，大口大口地吐着鲜血，但他看着那栋化为废墟的指挥部，嘴角却勾起一抹残忍而快意的笑。

“厉云霆……你的王座……塌了。”

（本章完）
