# 第 81 章 最后的倒计时

厉氏大厦顶层，雷云压顶。
整座京城像是一只被按在案板上的巨兽，在淡紫色的电子雾霭中发出阵阵垂死的哀鸣。

池青坐在一楼大厅被炸毁的咨询台后，十指在纯金键盘上疯狂起舞。她的周围，是几十个背靠背架着冲锋枪的影卫，以及正在不断回拨数据、试图稳住全城电力节点的少年黑客团。

“厉枭，还有六十分钟。”
池青抬头看向站在大厅正中央、手中握着黑金权杖的男人。

厉枭此时浑身浴血，左肩的伤口由于刚才在三里屯的激战而再次崩裂，鲜血顺着玄黑色的战术背心滴落在洁白的大理石地面上。但他那双眸子，却清亮得让人不敢直视。

“六十分钟，厉云霆就要让这整座城市彻底‘格式化’？”厉枭冷笑一声，权杖重重地顿在地面，发出一声极其沉闷的金属撞击声。

“不只是格式化。”池青的声音由于极度的焦虑而显得有些尖锐，“他启动了所有物理电网的过载协议。一旦倒计时归零，全京城所有的变压器都会同时爆炸。到时候，这里就不是数字牢笼，而是人间炼狱。”

【System Countdown: 59:59】
【Status: Self-destruction protocol active.】

大屏幕上，血红色的数字正在无情地跳动。

“厉总，外面的信徒已经疯了！”陈戈冲进大厅，额角带着血迹，“他们由于芯片回路被烧毁，现在处于极其严重的‘狂暴状态’，正在疯狂冲击大厦的防线！”

“那就让他们冲进来。”厉枭眼神狠戾，“陈戈，把一楼到八十楼所有的电子锁全部打开。既然厉云霆想要毁了这里，那我就请这全城的‘受害者’，亲自上楼去问候他。”

“厉枭……”池青担忧地看着他。

“别怕。”厉枭走过来，在那张由于熬夜而显得苍白的小脸上狠狠亲了一下，带着一股浓烈的硝烟与铁锈味，“你去 88 层的机房，接管总控。我去顶层，把那个老疯子亲手拎下来。”

他顿了顿，眼神里闪过一抹极其深刻的疯狂：
“池青，我发现了一件事。厉云霆留下的那个自毁秘钥，就在我脑子里的这块芯片里。”

池青猛地攥紧了他的衣领：“你说什么？！”

“他想让我亲手按下那个按钮，想让我成为毁掉这文明的罪人。”厉枭自嘲地勾了勾唇角，“但我告诉他，这世界上，只有你，能拿走我的任何东西。”

他从兜里掏出一枚极其轻便的无线连接器，强行插进了池青的键盘接口。

“如果到了最后一秒我还没下来，你就强行黑进我的芯片，取走那个秘钥。”厉枭盯着她的眼睛，一字一顿地说道，“别犹豫，池青。这是 Shadow 的使命。”

池青泪如泉涌，却倔强地咬着唇，重重地点了点头。

“出发。”
厉枭猛地转身，权杖一横，身形如同一道黑色的闪电，直接冲进了通往顶层的专用电梯井。

这一刻，最后的博弈，正式进入了读秒阶段。

（本章完）
