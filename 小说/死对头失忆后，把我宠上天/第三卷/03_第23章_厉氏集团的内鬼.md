# 第 23 章 厉氏集团的“内鬼”

厉氏集团大厦，八十八层。
天刚蒙蒙亮，整栋大楼却已经被一股极其压抑的气氛笼罩。

池青昨晚从 302 号弯道九死一生逃回公寓后，甚至来不及处理身上的伤口，就直接黑进了厉氏集团的后台监控。
厉枭没有回来。
他的手机处于信号屏蔽状态。

“该死。”池青修长的手指在键盘上敲得飞快，眼底布满了血丝。
她在追踪那个面具男的信号，却发现对方的路径最终竟然指向了厉氏集团的内部核心。

突然，屏幕上跳出一个血红色的警报：
【Security Breach: Level S. Financial Cluster Offline.】（安全漏洞：S级。金融集群掉线。）

厉氏集团负责全球结算的服务器，在这一瞬间被植入了一种极其阴毒的木马病毒。
只要再过五分钟，整个厉家的资金链就会彻底瘫痪。

“居然敢在这种时候动手。”
池青顾不得自己还没愈合的伤口，直接拿上平板，披了一件风衣就往公司赶。

总裁办内，已经乱成了一锅粥。
“怎么回事？防火墙为什么一点反应都没有？！”
“内鬼！一定是内部权限被盗了！”

技术部的几十个专家此时像是一群没头的苍蝇，在电脑前疯狂敲击，却根本阻挡不了那些代码的疯狂吞噬。

“让开。”
一道清冷而充满威压的声音在门口响起。

所有人转头，看到池青沉着脸走进来。她虽然脸色苍白，但眼神却犀利得像是一把尖刀。

“池小姐，现在不是胡闹的时候，厉总不在，我们必须……”
“我说，让开。”池青直接推开技术总监，坐在了主控位上。

她没有解释，指尖在键盘上敲击出了一串极其复杂的特定频率。
那是属于“影子女王”的绝对权限。

【Shadow Protocol: Overdrive.】

随着这一行字符的跳动，原本已经溃不成军的防火墙，在瞬间重组，化作了一道道密不透风的数字高墙。
那些病毒代码像是在瞬间撞上了钢板，开始疯狂反弹。

“天呐……这手速……”技术部的专家们看呆了。
他们从来没见过这种破译手法，简直是在和上帝玩魔方。

池青没有理会他们的惊愕。
她盯着屏幕上一个极其隐蔽的数据溢出点，嘴角勾起一抹冰冷的弧度。
“抓到你了。”

她并没有急着删除病毒，而是写了一个极其微小的“追踪钩子”，顺着对方的返回链路，直接黑进了对方的物理终端。

屏幕一闪。
一张极其清晰的抓拍图片跳了出来。

那是一个穿着厉氏集团高级助理制服的人，此刻正躲在负一层的配电房里，手里拿着一个便携式入侵器。

而那张脸，让在场所有的元老都倒吸了一口凉气。
“陈特助？！这怎么可能？！”

陈戈，那个一直跟在厉枭身边，被视为最信任的私人助理。

“没有什么是不可能的。”池青收起平板，站起身，由于起身太猛，腹部的伤口裂开，染红了腰间的白衬衫。
她却连眉头都没皱一下，冷冷看向技术总监：“带人去负一层，抓人。另外，告诉厉承泽，这一局，他输得底掉。”

就在这时，办公室的大门被人猛地推开。

厉枭带着一身尚未散去的硝烟和血气，大步流星地走进来。
他那身昂贵的西装已经破烂不堪，额头上缠着渗血的绷带，整个人像是一尊刚从炼狱里爬出来的魔神。

他一眼就看到了主控位上的池青，以及她腰间那一抹刺眼的血红。

“谁准你来公司的？”
厉枭大步冲上前，大手死死按住她的肩膀，语气暴戾却藏不住那股快要溢出来的颤抖。

池青看着他。
看着这个为了引出内鬼，不惜以身为饵，在山顶孤军奋战的疯子。

“我不来，你这三十亿的家底就真的没了。”池青有些虚弱地笑了笑，身子晃了晃，软软地倒在了他怀里。

厉枭一把横抱起她，对着身后还没反应过来的保镖怒吼：
“陈戈交到处刑堂，萧家所有的产业，今晚我要看到它们全部破产！”

他低头，看着怀里已经陷入昏迷的池青。
在那张常年冷静的脸上，第一次露出了名为绝望的深情。

“池青，你还没告诉我真相，我不准你死。”

（本章完）
