# 第 39 章 Zero 的二次讯号

厉家别苑，书房。
落地窗外大雨瓢泼，冲刷着那些刚刚染上的血迹。

池青坐在一张宽大的单人沙发里，手里紧紧攥着那个刚从快递盒里拆出来的纯黑色硬盘。盒子上没有任何寄件信息，唯有封口处贴着一张血红色的曼陀罗贴纸。

厉枭站在她身后，双手撑在沙发靠背上，眼神阴鸷。
刚才在车里听到的那个声音，成了压垮骆驼的最后一根稻草。

“接上吧。”厉枭嗓音低沉，“既然 Zero 已经把钩子甩到了家门口，我们就看看他到底想钓什么鱼。”

池青深吸一口气，指尖有些颤抖地将硬盘插入了那台被厉枭重新加固过的电脑。

【Encryption Level: Zero.】（加密等级：零。）
【Identity Verified: Shadow.】（身份验证：影子。）

屏幕亮起。
一段极其模糊、伴随着强烈底噪的监控画面跳了出来。

那是欧洲某个私人疗养院的顶层。
画面中，一个面色惨白、靠呼吸机维持生命的女人正躺在病床上。虽然由于长年患病而显得极其消瘦，但那眉宇间透出的冷傲与坚韧，却和池青如出一辙。

“妈妈……”池青的眼泪瞬间夺眶而出，趴在屏幕前想要伸手去触摸那个虚幻的身影。

画面里的女人似乎感觉到了什么，艰难地侧过头，对着镜头张了张嘴。
【落落……快跑……】
【别来……曼陀罗计划……是假的……】

“刺啦——！”
画面在一瞬间崩碎，取而代之的是 Zero 那张像素化的、带着一丝极其变态愉悦的骷髅脸。

【影子，看来这个‘见面礼’你很满意。】
【既然你想救她，那就带着厉枭手里的那份‘North Star’最终密钥，来参加明晚在公海举行的‘暗网晚宴’。】
【如果十二小时内我看不到人，这张病床上的呼吸机，会由我亲自关掉。】

“Zero！你这个疯子！”池青对着屏幕嘶吼。

“不仅是疯子，还是个天才。”厉枭盯着屏幕上的倒计时，嘴角勾起一抹残忍的笑意。
他转身，从书桌的最底层抽屉里拿出了一个散发着幽蓝光芒的 U 盘。

“你要去？”池青猛地转头，“厉枭，那是厉氏集团所有海外基站的权限！一旦交出去，京城的金融系统会彻底崩溃！”

“我说了，只要能救你母亲，这厉家，毁了就毁了。”厉枭走过来，大手扣住池青的后脑勺，强迫她对上自己的视线。

他的眼神里没有一丝一毫的犹豫，只有一种近乎自毁的深情：
“池青，三年前我弄丢了你。这一次，我绝不会再让你输掉唯一的家人。”

“可你会死的。”池青抓着他的衣领，泪流满面，“Zero 那里有几百个雇佣兵，还有最顶尖的黑客团队。你去了就是送死。”

“死在你手里和死在他手里，对我来说没区别。”厉枭低头，在那张由于哭泣而微微发抖的唇瓣上狠狠咬了一下。
“但池青，记住。如果你敢在公海上丢下我逃跑……我就真的把这京城，变成一个死城。”

他松开手，转身开始联系海外的死士部队。

池青看着他的背影，心中那股一直被压抑着的、名为“爱”的情绪，在这一刻终于如同洪水决堤般，彻底淹没了所有的理智。

她坐回电脑前，眼神在那一瞬变得极其狠戾。
【Zero，既然你想玩大的，那我就用你教我的技术，亲手把你送进地狱。】

她悄悄打开了一个从未启用过的隐藏分区。
那是她三年前为了防止 Zero 彻底失控而预留的一个“自毁后门”。

【Project: Mandrake. Activation Code Required.】
【Password: Li Xiao.】

密码，竟然是他的名字。

原来，在那三年的每一个深夜，当她以为自己是在躲避厉枭的追杀时，她的潜意识里，唯一的出口，一直都是他。

（本章完）
