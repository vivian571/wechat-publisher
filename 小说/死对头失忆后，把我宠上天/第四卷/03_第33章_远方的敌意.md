# 第 33 章 远方的敌意

京城，厉氏别苑的花园。
尽管是深秋，这里的草木依然繁茂得有些诡异。

池青被获准在花园里散步，但身后跟着四个寸步不离的顶级保镖。
她身上穿着一件米色的风衣，手腕上那只银色的镯子在阳光下反射着冷光——那不仅仅是首饰，更是厉枭亲自设计的信号阻断器。

“池小姐，罗斯家族的凯瑟琳小姐求见大少爷，现在已经在偏厅等着了。”林叔走到池青身后，语气虽然恭敬，但眼神里却透着一种看戏的揶揄，“大少爷还在开跨国会议，吩咐让您先代为接待。”

池青停下脚步，修长的指尖折断了一枝枯萎的红玫瑰。
代为接待？
厉枭这是想让她当个活靶子，去试探这位远方来客的深浅。

偏厅内。
一个穿着一身极其嚣张的火红色套装、金发碧眼的漂亮女人正坐在主位上，漫不经心地打量着墙上的名画。
那是索罗斯家族的继承人，凯瑟琳。

“你就是那个让枭神魂颠倒的‘东方影子’？”凯瑟琳转过头，碧绿的眸子里满是毫不掩饰的敌意与轻蔑。
她的中文发音极其标准，却带着一股高高在上的贵族腔调。

池青走进厅内，姿态优雅地坐到了凯瑟琳对面。
“我是池青。凯瑟琳小姐远道而来，如果是为了公事，请等厉总会议结束。如果是为了私事……我这儿暂时不接受探监。”

凯瑟琳愣了一下，随即发出一声不屑的冷笑。
“探监？池青，你很有幽默感。但你要知道，在欧洲，枭是我们家族最看重的合伙人。如果不是因为三年前那场愚蠢的意外，他现在已经是我的丈夫了。”

她从爱马仕手袋里掏出一叠照片，指尖轻弹，照片在红木桌面上依次排开。
“这些，是三年前你在暗网和 Zero 交易的记录。只要我把这些交给厉家的老太爷，你觉得，你还能在这个别苑里待多久？”

池青扫了一眼照片。
那是她最隐秘的过去，甚至连厉枭都没查到这么细。

“凯瑟琳小姐既然有这些照片，为什么不直接去找老太爷？”池青神色淡然，甚至亲手为对方倒了一杯红茶，“跑来跟我显摆，只能说明一件事——你在厉枭那儿，连开口的机会都没有。”

凯瑟琳的脸色瞬间沉了下去。
“你！池青，你别以为枭现在护着你，你就真的能成为厉家主母。你母亲叶宁当年在欧洲做的事，可是让索罗斯家族损失了整整十个亿。这笔账，我们还没算完。”

叶宁。
又是这个名字。

池青端着茶杯的手指微微颤了颤，但脸上的表情却滴水不漏。
“我母亲的事，我自会查清楚。不劳凯瑟琳小姐操心。”

“查清楚？”凯瑟琳突然凑近，眼神里闪过一抹极其阴狠的光，“你以为你母亲是真的失踪了吗？池青，看看这张照片吧。”

她从那一叠照片的最底层，抽出了一张泛黄的、明显有些年头的抓拍照。

照片里，一个温婉的东方女性正坐在轮椅上，背后是漫无边际的北欧雪原。而在她的身侧，站着一个戴着银色面具的男人。

池青的瞳孔在那一瞬间剧烈收缩。
那是母亲！
三年前，有人告诉她母亲已经死于空难，可这张照片的背景时间显示……是两个月前！

“想要这张照片的完整坐标吗？”凯瑟琳伸出手，指甲涂成了如鲜血般的红，“只要你今晚帮我打开厉枭书房里的那个‘North Star’保险柜，我就告诉你你母亲在哪。”

池青看着那张照片，心口剧烈地起伏着。
这是陷阱。
赤裸裸的、诱使她背叛厉枭的陷阱。

“凯瑟琳小姐，这种老掉牙的策反手段，你可以拿去对付厉承泽。”池青突然站起身，将那杯热气腾腾的红茶直接泼在了那些照片上。

“你！”凯瑟琳惊叫着跳起来。

“滚出厉宅。”池青居高临下地俯视着她，眼神冷酷得像是一台机器，“另外，告诉 Zero。想要利用我，他还没那个资格。”

池青转身离去。
直到回到卧室，关上房门，她才脱力地滑落在地，双手死死地抓着那张被她刚才顺手藏进袖口的、带血的照片残片。

母亲还没死。
但她竟然在 Zero 的手里。

“池青，你到底在瞒着我什么？”
厉枭的声音突然在阳台响起。

他不知什么时候已经结束了会议，正站在阴影里，眼神复杂而深沉地盯着她。

池青猛地将照片碎片攥进手心，由于用力，指尖被纸张边缘割破，渗出了点点血迹。

“没什么。”
她站起来，迎着他的目光，眼神里全是倔强与决绝。

（本章完）
