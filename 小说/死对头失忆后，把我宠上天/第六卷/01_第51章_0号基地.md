# 第 51 章 0 号基地

京城北郊，地下百米。
这里是一座被彻底与世隔绝的钢铁堡垒——0 号基地。

池青坐在一张宽大得有些离谱的真皮沙发上，眼神空洞地看着面前那堵巨大的、由特种合金打造的墙壁。就在十分钟前，厉枭亲手收走了她所有的电子设备，甚至连她耳垂上那枚藏有微型发射器的耳钉，也被他用一种近乎粗暴的方式强行摘下。

“在这里，你不需要网络。”
厉枭的声音在空旷的室内回荡，带着一种极其强烈的侵略性。他手里拎着两件刚从恒温箱里拿出来的睡裙，一件是墨绿色的真丝，一件是纯黑色的绸缎。

“选一件。”厉枭走上前，修长的指尖划过池青苍白的侧脸，嗓音低沉得像是在叹息，“既然你说你要用全世界的秩序换我的命，那我就成全你。从今天起，你就是这 0 号基地里，唯一的‘主神’。”

池青没有选，只是冷冷地看着他：“厉枭，你把我关在这里，和把我杀了有什么区别？”

“区别在于，杀掉你，我会疼一辈子。”厉枭俯身，在那张让他恨之入骨又爱入骨髓的唇瓣上狠狠咬了一口。
“而把你关在这里，我每天都能看到你，闻到你的味道，甚至……听到你在绝望中喊我的名字。”

他强行将那件墨绿色的丝绸睡袍披在池青身上。那极其丝滑的质感贴在皮肤上，却让池青感觉到一种如毒蛇爬行般的冰冷。

“厉枭，你觉得这能关得住 Shadow 吗？”池青嘲讽地笑了笑。

“在这里，没有 Shadow，只有我的妻子。”厉枭猛地将她打横抱起，走向那张占地极广、由防弹纤维打造的床榻。
他动作粗鲁而狂野，完全没有了往日的温柔。在这一片死寂的地下空间里，这种极致的占有欲显得尤为病态和疯狂。

“唔……”池青发出一声吃痛的低呼，双手死死地抵住他的胸膛。

厉枭停下动作，眼神里燃起一股极其可怕的红火。
“池青，你三年前拿走那三十亿的时候，有没有想过，我也曾这样绝望地想要留住你？”

池青沉默。
这种沉默在厉枭眼里就是最残忍的拒绝。

他猛地扯掉领带，将她的双手交叉并拢，熟练地捆在了床头的合金扶手上。

“在这里，除了我，没人能看到你穿成这样。”厉枭凑在她耳边，声音由于极度的欲望和恨意而变得沙哑，“我会让你慢慢想起，到底谁才是你真正的‘主人’。”

就在厉枭俯身想要彻底占有她的时候，基地的内部警报器突然发出了一阵急促的蓝光。
那是空气过滤系统遭遇异物入侵的信号。

“该死。”
厉枭低咒一声，猛地起身，眼神在一瞬间恢复了属于暴君的冷静。

他看了一眼被绑在床上的池青，眼神复杂而深沉：“乖乖待在这儿。如果让我发现你动了什么逃跑的念头，我就让池家所有人，在今晚之后彻底消失。”

他大步走出房间，沉重的合金门轰然锁死。

池青靠在冰冷的合金扶手上，眼神里却闪过一抹极其锐利的冷静。
她并没有试图挣脱领带，而是闭上眼，耳朵贴在床沿，通过那极其微弱的震动，在脑海里勾勒着基地的内部结构。

【厉枭，你以为收走我的电脑，我就黑不进你的世界了吗？】
【这个世界上，只要有震动，就有信息。】

她开始用手腕有节奏地敲击着合金扶手。
一下，两下。
那是属于 Shadow 的物理入侵频率。

而在监控室里，厉枭看着屏幕上那个虽然被绑着、却依然显得不可一世的女人，拳头死死地攥紧，骨节泛白。

他知道。
这场名为“囚禁”的博弈，他已经输了一半。

（本章完）
