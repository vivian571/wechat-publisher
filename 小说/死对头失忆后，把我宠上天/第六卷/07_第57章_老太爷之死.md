# 第 57 章 老太爷之死

0 号基地的医疗舱内，幽蓝色的生命维持光束在池青苍白的脸上缓缓扫过。

厉枭就坐在床边的阴影里，像一尊石化的雕像。他手里紧紧攥着池青的那只手，指节因为过度用力而泛着青白。

三年前的那场大火，在他的记忆碎片里疯狂叫嚣。他第一次清晰地“看”到了父亲厉云霆被那个老人亲手推入火海的瞬间——那是他所有噩梦的源头，也是他失忆前拼死想要挖掘的真相。

就在这时，控制室的红灯疯狂闪烁，刺耳的警报声撕裂了基地的死寂。

“厉总，出事了。”陈戈的声音通过扩音器传进来，带着前所未有的惊恐，“京城……京城那边炸锅了。”

厉枭眼神一凛，缓缓松开池青的手，替她盖好被子，起步走向控制室。

大屏幕上，静安居——那个厉家权力的巅峰象征，此时已经被重重警戒线封锁。

“就在十分钟前，老太爷厉震廷在静安居暴毙。”陈戈调出一张现场传回的模糊照片，手都在抖，“现场……极其惨烈。”

厉枭盯着屏幕。照片里，那个曾经不可一世的老人倒在血泊中，双目圆睁，仿佛在临死前看到了什么极其恐怖的东西。

“死因呢？”厉枭冷声问。

“一刀封喉。而且……”陈戈咽了一口唾沫，点开了另一张特写，“凶器被留在了现场。是三年前，池小姐在边境任务中丢失的那把‘暗影’军刀。上面……全是您的指纹。”

控制室内陷入了死一般的沉浸。

这意味着，全天下的人都会认为，厉枭为了夺权，不仅囚禁了影子的继承人，还亲手弑杀了亲祖父。

“呵。”厉枭忽然低笑出声，那笑声在空旷的基地里回荡，透着一股令人毛骨悚然的癫狂，“一刀封喉？那老头子倒是走得痛快。”

“厉总，现在外面全是在通缉您的消息。厉痕已经接管了家族董事会，宣布剥夺您的继承权，并悬赏十亿买您的头。”陈戈急切地问，“我们要不要发声明澄清？那把刀明明三年前就丢了，指纹肯定也是伪造的……”

“澄清？”厉枭转过身，火光映射在他的眼底，像是有两团幽火在燃烧，“为什么要澄清？”

他大步走到控制台前，双手撑在桌面，目光如炬：“既然他们都说我是弑亲的暴君，那我就坐实这个名号。告诉厉痕，让他守好那把交椅。因为——我亲手去拿的时候，那上面不准有一丝血迹以外的脏东西。”

就在这时，医疗舱的方向传来了细微的声响。

厉枭猛地回头，看见池青不知何时已经醒了。她撑着虚弱的身体，正死死地盯着屏幕上那把熟悉的军刀。

“那是我的刀。”池青的声音沙哑得厉害，眼神中透着一股深不见底的寒意，“厉枭，这是一个局。一个专门为我们两个准备的死局。”

厉枭走到她面前，单膝跪地，平视着她的眼睛，语气竟然温柔得诡异：

“我知道。所以，从现在开始，除了深渊，我们无路可退了。”

窗外，0 号基地上方的雷达阵列在狂风中疯狂旋转。一场足以席回全球金融与权力的风暴，正式拉开了帷幕。
