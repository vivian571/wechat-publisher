## 三、 怎么做？（协议化生存的详细操作步骤）

别去磨洋工写长文档。
跟着这套架构师级别的三步走，为你的人工智能安装神经系统。

### 第一步：搭建本地 API 网关 (The Gateway)
你手里的模型再强，不能和其他工具说话，它就是个哑巴。
**操作细节**：
1. 使用 LM Studio 或 Ollama 开启本地服务。
2. 暴露端口（例如 `1234` 或 `11434`）。
3. 确保你的 `config.yaml` 中配置了正确的 `BASE_URL`。
这叫 **Infrastructure Alignment (基础设施对齐)**。

### 第二步：挂载 MCP 插件 (Protocol Mounting)
让 AI 拥有“手脚”。
**实战步骤**：
1. 找到对应的 MCP Server（比如处理文件的库、处理 GitHub 的库）。
2. 在你的 Agent 配置文件中（如 `hermes_config`）注入协议头。
3. 授权。让 AI 获得特定的读取或写入权限。
从此以后，它不再只是“建议你改代码”，它会直接“通过协议修改代码”。

### 第三步：定义权限边界掩码 (Permission Masking)
霸主不能失去对火力的控制。
**操作逻辑**：
利用系统级的 `Environment Variable` (环境变量) 设置熔断机制。
规定哪些数字员工只能读数据，哪些可以执行 `run_command`。
这叫 **Sandboxed Authority (沙盒化授权)**。
