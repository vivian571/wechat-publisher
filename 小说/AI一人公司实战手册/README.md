## 二、工业化写作核心 Prompt 库

### 1. 🔧 写作主Prompt（直接复制用）
```text
你是一名顶级AI创业顾问 + 技术架构师。

请按照以下结构，写一章《AI一人公司》书籍内容：

【章节标题】：
{{章节名称}}

【目标读者】：
0基础到进阶，希望用AI赚钱的人

【写作要求】：
- 逻辑极清晰
- 强实操
- 不空谈
- 每一部分必须有具体方法

【输出结构】：
1. 是什么（本质定义）
2. 为什么重要（商业价值）
3. 怎么做（分步骤）
4. 实战案例（真实可执行）
5. 工作流拆解（流程图级别描述）
6. 自动化实现（工具 / Agent / Prompt）
7. 常见错误
8. 总结 + 升级路径

【额外要求】：
- 给出至少1个“可复制Prompt”
- 给出一个“自动化流程设计”
```

### 2. 🔁 案例生成 Prompt
```text
请为以下主题生成一个“可以直接赚钱”的案例：

主题：{{章节}}

要求：
- 有具体场景
- 有执行步骤
- 有变现路径
- 不要抽象
```

### 3. 🤖 工作流设计 Prompt
```text
请将“{{某个系统}}”拆解为一个完整的Agent工作流：

要求：
- 用状态机描述（状态 + 转移条件）
- 给出每一步的输入输出
- 指定每一步可以用的AI工具
```

## 三、自动化写书系统（Agent架构预研）

这是一个串行管道（Pipeline）代理架构：
`选题Agent` → `目录生成Agent` → `章节生成Agent` → `案例增强Agent` → `技术补全Agent` → `审校Agent` → `排版Agent`

* **选题Agent**: 输入趋势/需求，输出爆款章节主题。
* **目录Agent**: 自动扩展章节子结构。
* **写作Agent**: 按上述通用模板生成完整章节初稿。
* **案例Agent**: 强化内容的“可赚钱性”和实操度。
* **技术Agent**: 补充 Prompt、自动化脚本和工具链。
* **审核Agent**: 检查内容是否空洞及可执行性。

## 四、MVP 执行计划（最小跑通闭环）

❗**核心法则：先完成闭环，再谈体系；先赚到钱，再优化结构。**

* **Day 1**: 专注完成 **第4章：《内容生产引擎》**。使用主Prompt生成正文、案例和工作流。
* **Day 2**: 将第一天写好的第4章内容，拆解转化为3篇可直接发布的公众号文章。
* **Day 3**: 审读、优化，并再次驱动 Agent 生成。
* **Result**: 一周内产出 10+ 篇干货文章，建立初步的体系闭环并进入发布流程。
