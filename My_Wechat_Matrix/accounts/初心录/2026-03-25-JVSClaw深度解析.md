## 🧠 黑科技原理：为什么 JS 才是 OpenClaw 的“天作之合”？
别问，问就是“架构优势”。

### 大白话拆解：咖啡店的服务员模型
- **Python (多线程模型)**：像一个“每个服务员同一时间只能服务一张桌”的咖啡店。如果一个客人思考人生一小时，这个服务员就得干等一小时，其他桌的客人只能干瞪眼。这就是“同步阻塞”。
- **JavaScript (单线程 + 事件循环)**：像一个“只有一个超级服务员，但他同时给 100 张桌子点单”的咖啡店。他给 A 桌点完单，立刻去 B 桌，厨房出餐了，他再把餐送到对应的桌子。他永远在忙，从不空等。这就是 **Node.js 的“非阻塞 I/O 事件循环”**。

对于 OpenClaw 这种需要频繁调用外部 API、读写文件、等待模型响应的 I/O 密集型应用，JS 的架构优势是碾压性的。

## 🛠️ 保姆级实操：3 分钟用 JS 写出你的第一个 OpenClaw 插件

### 第一步：环境准备 (告别 Python 依赖地狱)
```bash
# 创建项目目录
mkdir my-js-plugin && cd my-js-plugin

# 初始化 Node.js 项目
npm init -y

# 安装 OpenClaw 官方 JS SDK
npm install @openclaw/sdk
```

### 第二步：创建插件入口文件 `index.js`
```javascript
const { tool } = require('@openclaw/sdk');

// 定义一个可以被 OpenClaw 调用的工具
const getWeather = tool(
  async ({ city }) => {
    // 非阻塞地调用外部天气 API
    const response = await fetch(`https://api.weather.com/v1/today?city=${city}`);
    const data = await response.json();
    return `今天 ${city} 的天气是：${data.weather}`;
  },
  {
    name: 'getWeather',
    description: '获取指定城市的天气信息',
    input: {
      type: 'object',
      properties: {
        city: { type: 'string', description: '城市名称' },
      },
      required: ['city'],
    },
  }
);

module.exports = { getWeather };
```

### 第三步：创建插件描述文件 `plugin.json`
```json
{
  "name": "js-weather-plugin",
  "version": "1.0.0",
  "description": "一个用 JavaScript 编写的天气查询插件",
  "runtime": "nodejs",
  "entry": "index.js"
}
```
把这个文件夹放到 OpenClaw 的 `plugins` 目录下，重启 OpenClaw，你就可以在 AI 对话中调用 `getWeather` 工具了！
