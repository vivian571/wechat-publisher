【保姆级实操：3 步打造你的数字大脑】

第一步：宿舍搭建（部署环境）

建议直接使用 Docker 部署，简单粗暴。在你的服务器上创建一个文件夹，运行以下指令：

```bash
git clone https://github.com/onyx-dot-app/onyx.git
cd onyx/deployment/docker-compose
docker compose up -d
```

等待 5 分钟，访问你的服务器 3000 端口，你会看到一个深邃且极具未来感的界面。

第二步：插上光纤（配置 Connector）

在后台管理界面找到 Connectors 模块。以飞书（Lark）为例：

你只需要填入飞书开放平台的 App ID 和 Secret。
如果是 GitHub，直接授权你的个人访问令牌。

这时候，你会看到 Onyx 的后台开始疯狂闪烁。那是它正在把你过去几年的知识“嚼碎”了吐进向量数据库。

第三步：开启“战情室”（Deep Research）

不要像对待普通机器人那样问它问题。

在输入框左侧点击“Research”模式，输入：
“复盘 2025 年 Q4 所有的技术架构变更，并找出它们与今年 Q1 线上事故的潜在关联。”

这时候，你会看到 AI 像个高级审计员一样，有条不紊地列出参考文件、引用段落和逻辑推导。

【爆款提示词模块：Onyx 的“灵魂分信员”】

如果你已经部署好了，用下面这段“工业级 Prompt”来调教它，能让它的精准度提升 200%：

```markdown
# Role: 全域知识库审计专家

# Constraints:
1. 你的答案必须基于 [Onyx_Internal_Knolwedge] 提供的检索片段。
2. 如果检索到的信息存在冲突，必须标注出来，并询问我哪个版本为准。
3. 严格禁止“基于常识猜测”。如果 Onyx 数据库里没有，直接回复 [Knowledge_Gap_Alert]。

# Strategy:
采用“引用先导”逻辑。每一段结论后面必须紧跟检索到的源文件名称和行号，例如 (Ref: 2025_Audit_Report.pdf#L125)。

# Output:
1. 核心结论（一句话暴击）。
2. 事实支撑点（列表输出）。
3. 归档索引（标注来源）。
```
