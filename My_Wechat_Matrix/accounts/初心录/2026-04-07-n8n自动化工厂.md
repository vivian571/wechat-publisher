【保姆级实操：3 步打造你的流水线】

第一步：宿舍搭建（部署环境）

建议直接使用 Docker 部署，简单粗暴。在你的服务器上创建一个文件夹，运行指令：

```bash
docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n:latest-ai
```

等待 5 分钟，访问你的服务器 5678 端口，你会看到一个极具科技感、像电影黑客帝国一样的可视化界面。
