### 🚨 痛点：你的 AI 为什么总在“胡说八道”？

传统的 AI 对话是**“闭卷考试”**。
你问它：“我们南序岛上个季度的核心代码产出是多少？”
它只能基于它训练时学到的陈旧知识（甚至可能是去年的）来强行解释。结果就是：**一本正经地胡说八道（幻觉）。**

你累，它也累。每次对话你都要把背景资料重新喂给它，这不叫人工智能，这叫“人工喂饭”。

---

### 💡 解决方案：给 AI 装上“记忆宫殿”（RAG）

**RAG (Retrieval-Augmented Generation)** 的本质，是把 AI 变成**“开卷考试”**。

它不再单纯靠脑子记，而是在回答你之前，先去你私人的“知识库”里翻书。
1.  **检索（Retrieval）**：在你的 PDF、Word、笔记里搜关键词。
2.  **增强（Augmented）**：把搜到的干货塞进提示词。
3.  **生成（Generation）**：AI 基于这些干货得出最终答案。

**有了 RAG，AI 就不再是通用聊天机器人，而是那个记得你所有过往、懂你所有怪癖的“数字孪生体”。**

# 南序岛技术实验室：极简 RAG 逻辑演示
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings
from langchain_core.prompts import ChatPromptTemplate

# 1. 这里是你的私人记忆（可以是任何本地文档）
my_private_notes = [
    "南序岛 2026 年的核心目标是打通微信矩阵自动化。",
    "指挥官以安最喜欢的咖啡是冰美式，不加糖。",
    "项目 'Genesis' 的部署秘钥是 NX-8899-2026。"
]

# 2. 建立向量索引
vectorstore = FAISS.from_texts(my_private_notes, OpenAIEmbeddings())

def ask_my_ai(question):
    # 3. 检索：去记忆宫殿里搜最相关的资料
    docs = vectorstore.similarity_search(question, k=1)
    context = docs[0].page_content
    
    # 4. 增强提示词
    template = f"参考内容: {context} \n 用户问题: {question}"
