## 项目上手使用：如何快速获得“工业能力”？

### 快速上手 3 步走

1. **一键强制更新**：
   如果你之前装过旧版，请先铲除，再重新注能：
   ```bash
   npm uninstall -g @mastra/kit
   npm install -g @mastra/kit@latest
   ```

2. **初始化新核心**：
   在你的项目根目录运行，它会自动生成新的架构文件：
   ```bash
   mastra init --blueprint industrial-v2
   ```

3. **激活“工业模式”**：
   不要直接用默认指令！去 `config.yaml` 里开启 `enforce_safety_sandbox: true`。

### 高频问题修复方案
- **UI 无法启动？**：请检查你的二进制文件是否被 macOS 系统拦截，手动去系统设置里点击“仍要打开”。
- **模型响应变慢？**：这是因为开启了双层审计，可以在配置里将 `audit_level` 调至 `balanced`。
