## 🛠️ 分模块硬核拆解

### 1. 插件系统底层重构
这一次，官方直接废弃了旧版的动态链接库加载方式。插件现在运行在独立的轻量级容器中，这意味着单个插件的崩溃将不再导致整个 OpenClaw 平台宕机。这种“一刀切”的解耦，是迈向生产级稳定性的关键一步。

### 2. 生产级安全加固
在 v2026.3.22-beta.1 中，安全性被提升到了前所未有的高度。所有 API 调用现在都经过加密隧道，并且新增了“权限最小化”策略。未经授权的插件将无法读取任何本地环境变量。

### 3. Agent 工作流升级
全新的工作流引擎支持“条件分支”和“循环递归”。现在的 OpenClaw 不再是一个只会顺序执行的机器人，而是一个具备判断力的逻辑引擎。

## 📦 项目上手使用 + 常见问题解决方案

### 快速上手步骤
```bash
# 克隆并切换到最新分支
git clone https://github.com/openclaw/openclaw.git
cd openclaw
git checkout v2026.3.22-beta.1

# 使用全新的安装脚本
./install.sh --mode production
```

### 高频问题修复
- **UI 文件缺失**：如果发现 `script/ui.js` 丢失，请运行 `npm run build:ui` 重新编译。
- **插件不兼容**：目前只能手动更新插件代码以适配新的 `ClawContext` 接口。
- **环境报错**：确保 Node.js 版本在 20.x 以上，且已安装 `pnpm`。

### 版本回滚指南
```bash
# 如果新版无法运行，请迅速回滚到稳定版
git checkout tags/v2025.12.30-stable
npm install
npm run start
```
