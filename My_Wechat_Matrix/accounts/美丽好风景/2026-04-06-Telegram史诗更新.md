## 硬核拆解：这一刀到底切在了哪里？

### 1. 架构解耦：逻辑更稳、输出更狠
以前的 tdesktop 在处理大规模群组消息时，偶尔会出现“转圈圈”的 UI 假死。
现在的 **v6.7.x**，实现了 UI 线程与长连接任务的完全物理隔离。这意味着什么？这意味着即便你正在下载一个 2G 的 4K 视频，你的聊天界面依然如丝般顺滑。这种稳定性，是 Telegram 统治地位的护城河！

### 2. 本地 AI 摘要（Summarization）
我们都受够了 500+ 未读消息的焦虑。tdesktop 这次引入了 **Context-Aware Summary**。
它会根据这 500 条消息的上下文，自动生成 3 条核心摘要。最关键的是，这个过程完全在你的本地 CPU 跑，一条数据都不会传给第三方服务器。这就是为什么更新后的 tdesktop 显得“更懂隐私”的底层秘密。

## 项目上手使用：如何快速获得“次世代体验”？

### 快速上手 3 步走

1. **一键强制更新**：
   官方 GitHub 或内建更新器检测。
   ```bash
   # 如果你是编译控
   git checkout tags/v6.7.x-stable
   ./Prepare.py && ./Build.py
   ```

2. **激活“AI 助理”**：
   在设置 -> 隐私与安全 -> 实验性功能中开启 `Active Local Intelligence`。
   首次开启会下载约 800MB 的模型权重，请保持网络通畅。

3. **快捷交互测试**：
   在任何长文本对话框右键点击，选择“Generate Summary”。

### 高频问题修复方案
- **翻译不出来？**：请检查你的下载是否完整，或者尝试在模型设置里重置缓存。
- **语音转文字报错？**：这是因为 ffmpeg 依赖库版本冲突，建议使用官方提供的全量安装包。
