## 🛠 怎么用？3 步组建你的无人区特战队

跟着做。这可能在关键时刻救你的命。

### 1. 强制本地化部署

在一块告诉 SSD 硬盘里部署环境：

```bash
npx install openclaw-core --local-only
```

这行代码意味着剥离所有对外界的依赖。

### 2. 挂载“极端环境”工具包

把你的离线卫星地图和《野外生存手册》PDF 路径全部喂给它。

