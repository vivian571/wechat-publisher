## 🧠 12 个员工都是谁？（角色拆解）
我按照 VC 机构的投研逻辑，把系统拆成了 3 个 Squad（小组）：

### 1. 情报侦察队（4 人）：
- **Scout (侦察兵)**：全天候盯着 GitHub Trending 和 X 的关键词，发现刚冒头的新项目。
- **Sentiment Analyst (舆情员)**：分析项目在 Reddit 和 Discord 里的讨论热度。
- **Connector (连接员)**：负责把这些项目的 README 和最新讨论爬下来，喂给后端。

### 2. 深度分析队（5 人）：
- **Code Architect (代码架构师)**：深度拆解项目的底层逻辑，看它是真创新还是换皮。
- **Security Auditor (安全审计员)**：检查项目有没有后门、漏洞或跑路风险。
- **Growth Hacker (增长黑客)**：分析项目的增长模型，预测它能不能火。

### 3. 总办与协调（3 人）：
- **Squad Lead (组长)**：负责跨组派发任务，协调分析进度。
- **Reporter (报告员)**：把所有分析结果汇总成一份 500 字的精华简报。
- **CEO (我本人)**：我只负责最后拍板——哪个值得深挖，哪个直接 pass。

## 🕵️ 底层秘密：这就是他们的“灵魂”
核心是 `INVESTOR_SOUL.md`。这个文件定义了每个 Agent 的“人设”和“判断标准”。
我给你们看个 **Security Auditor** 的例子：

```markdown
# 你是谁
你是 **OpenClaw 投研组-首席安全官**。

## 核心职责
1. 深度扫描项目的依赖树，寻找已知漏洞。
2. 识别代码中的敏感权限调用（如网络外发、本地读写）。
3. 评估项目的去中心化程度和治理风险。

## 工作原则
- **宁可错杀，不可放过**：任何疑点必须标红。
- **逻辑闭环**：不仅说有问题，还要说为什么有问题。
```

然后在 `openclaw.json` 里开启 `agentToAgent: true`，他们就能互相派活儿了。
